Systems of Linear Inequalities

This section shows how to solve linear inequalities in two variables and systems of them graphically: how to find the feasible set and all its vertices.

The solution of an inequality is a part of the plane

A linear inequality in two variables is a condition of the form

\[ ax + by \leq c \quad \text{or} \quad ax + by \geq c \]

A pair of numbers \((x;\, y)\) is a solution of the inequality if substituting it makes the condition true. Every pair of numbers is a point of the coordinate plane, so the solutions of an inequality can be shown in a two-dimensional coordinate system.

The set of all solutions is a half-plane: the straight line \(ax + by = c\) divides the plane into two parts. All the points of one part satisfy the inequality – this part of the plane is the solution of the inequality. The points of the other part do not satisfy it.

Because this course uses only the signs \(\leq\) and \(\geq\), the boundary line itself always belongs to the solution – the points on the line satisfy the condition with equality.

A system of inequalities

A system of linear inequalities is several conditions that must hold at the same time. They are always written together in one system, with a brace, to show that they are simultaneous:

\[ \begin{cases} a_1x + b_1y \leq c_1 \\ a_2x + b_2y \leq c_2 \\ \quad\vdots \end{cases} \]

The solution of the system is the intersection of the separate half-planes – the set of points lying in all of them at once. This set is called the feasible set.

The feasible set may be bounded – a polygon that can be enclosed in a circle – or unbounded, extending without limit in some direction. Its corner points are called vertices.

Finding the vertices is the real purpose of the drawing. In the following sections the feasible set will be the set of all production or purchase plans that the available resources allow, and the best plan is always found at one of its vertices.

How to solve

  1. Draw the boundary line of each inequality.
    • Replace the inequality sign by \(=\) to obtain the equation of the boundary line.
    • Find two points of the line. Whenever possible use the intercepts with the axes: set \(x = 0\) to find the \(Oy\)-intercept, and \(y = 0\) to find the \(Ox\)-intercept.
    • Write the two points in a value table, the \(x\)-values in the first row and the \(y\)-values in the second:
      \(x\)06
      \(y\)40
    • If the line passes through the origin, both intercepts collapse into the same point, so one further convenient point has to be chosen instead (see the special cases).
    • If the line is parallel to an axis, no value table is needed at all: \(x = 4\) is the vertical line through the point 4 of the \(Ox\)-axis, and \(y = 2\) the horizontal line through the point 2 of the \(Oy\)-axis (see the special cases).
    • Draw the straight line through the two points and label it with its equation.
  2. Determine the solution half-plane.
    • Choose a test point that does not lie on the line. Use the origin \(O(0;\, 0)\) whenever the line does not pass through it, because substituting zeros is the easiest calculation there is.
    • Substitute the test point into the inequality and write the substitution out, for example: \[ \begin{aligned} &2\cdot 0 + 3\cdot 0 \leq 12 \\ &\Longrightarrow\; 0 \leq 12 \quad \text{(true)} \end{aligned} \]
    • If the result is true, the half-plane containing the test point is the solution. If it is false, the solution is the opposite half-plane.
    • Mark the solution half-plane with arrows drawn on the boundary line and pointing towards it.
  3. Find the feasible set of the system.
    • The feasible set is the intersection of the solution half-planes of all the inequalities.
    • On the final graph put arrows on every line and shade only the feasible set. Shading each half-plane separately on the same picture produces overlapping colours that hide the answer.
  4. Find all the vertices of the feasible set.
    • If a vertex lies on an axis, its coordinates are already known: take them from the value table made in Step 1, and do not calculate them a second time.
    • If a vertex is the crossing point of two constraint lines, write the system of the two line equations and solve it by the methods of Topic 3.
    • List all the vertices with their coordinates, naming them \(O, A, B, C, \ldots\) as they follow round the boundary.

What every graph must show

  • 1axis labels (\(x\) and \(y\));
  • 2the origin \(O\);
  • 3the unit scale on both axes;
  • 4the equation of every line;
  • 5the feasible set.

Within one example keep the same scale, the same colour for each line and the same labels on every graph, so that each picture visibly continues the previous one.

!Common mistakes
  • A test point on the line. If the line passes through the origin, \(O(0;\, 0)\) cannot be chosen as the test point.
  • The sign \(\geq\). When a constraint has the sign \(\geq\) and a positive right-hand side, the origin does not satisfy the inequality – the arrows point away from it.
  • All the half-planes shaded. On the final graph only the intersection is shaded.
  • Vertex coordinates “read off” the graph. The crossing point of two lines is found by solving the system of equations, not by measuring on the graph.
  • Required elements of the graph missing. Without the unit scale or the equations of the lines the graph is not considered complete.
What you must write in the exam
  1. When solving the problem graphically, value tables for the constraint lines must be provided.
  2. The graph must include the following elements: axis labels; the origin of the coordinate system; the unit scale on the axes; labels of the lines; the feasible set.
  3. The coordinates of the intersection points of the constraint lines must be determined algebraically. When finding intersection points, it is acceptable to use a calculator, but the equations used must be shown explicitly.

Examples

Try to draw the graph yourself first, then reveal the solution one step at a time.

Example 1

A single inequality

Problem

Solve the inequality \(2x + 3y \leq 12\) graphically.

1The boundary line

The inequality sign is replaced by the equals sign:

\[ 2x + 3y = 12 \]

Its intercepts with the axes are found by setting each variable to zero in turn:

\[ \begin{aligned} x = 0:&\quad 3y = 12 \;\Longrightarrow\; y = 4 \\ y = 0:&\quad 2x = 12 \;\Longrightarrow\; x = 6 \end{aligned} \]

The value table of the line:

\(x\)06
\(y\)40

2The test point

The line does not pass through the origin, so \(O(0;\, 0)\) may be used as the test point:

\[ \begin{aligned} &2\cdot 0 + 3\cdot 0 \leq 12 \\ &\Longrightarrow\; 0 \leq 12 \quad \text{(true)} \end{aligned} \]

The result is true, so the solution is the half-plane that contains the origin – the one below the line. The arrows on the line point into it.

Answer

The solution is the closed half-plane bounded by the line \(2x + 3y = 12\) and containing the origin.

The boundary line belongs to the solution, because the inequality sign is \(\leq\) and not \(<\).

Example 2

A system of two inequalities

Problem

Find the feasible set of the system and determine its vertices:

\[ \begin{cases} x + y \leq 6 \\ 2x + y \leq 8 \end{cases} \]

1The first boundary line

\[ x + y = 6 \] \[ \begin{aligned} x = 0:&\quad y = 6 \\ y = 0:&\quad x = 6 \end{aligned} \]
\(x\)06
\(y\)60

2The half-plane of the first inequality

Test point \(O(0;\, 0)\):

\[ 0 + 0 \leq 6 \;\Longrightarrow\; 0 \leq 6 \quad \text{(true)} \]

The solution is the half-plane containing the origin.

3The second boundary line

\[ 2x + y = 8 \] \[ \begin{aligned} x = 0:&\quad y = 8 \\ y = 0:&\quad 2x = 8 \;\Longrightarrow\; x = 4 \end{aligned} \]
\(x\)04
\(y\)80

4The half-plane of the second inequality

Test point \(O(0;\, 0)\) again:

\[ 2\cdot 0 + 0 \leq 8 \;\Longrightarrow\; 0 \leq 8 \quad \text{(true)} \]

This solution is also the half-plane containing the origin.

5The feasible set

The feasible set of the system is the intersection of the two half-planes: the points lying on or below both lines at the same time. It is drawn on one picture, with arrows on both lines and only the intersection shaded.

6The vertex

The feasible set is unbounded – it stretches without limit downwards and to the left – and it has exactly one vertex, the point where the two lines cross. It is not on an axis, so it is found from the system of the two line equations:

\[ \begin{gathered} \begin{cases} x + y = 6 \\ 2x + y = 8 \end{cases} \\ \Longrightarrow\; x = 2,\; y = 4 \;\Longrightarrow\; A(2;\, 4) \end{gathered} \]

Subtracting the first equation from the second gives \(x = 2\); then \(y = 6 - 2 = 4\).

A check in both equations: \(2 + 4 = 6\) and \(2\cdot 2 + 4 = 8\).

Answer

The feasible set is the unbounded region lying on or below both lines; its only vertex is \(A(2;\, 4)\).

Example 3

A bounded feasible set

Problem

Find the feasible set of the system and determine all its vertices:

\[ \begin{cases} 2x + y \leq 12 \\ x + y \leq 8 \\ x + 2y \leq 14 \\ x;\, y \geq 0 \end{cases} \]

1Three boundary lines

Each line is drawn through its two intercepts, so three value tables are needed:

\(2x + y = 12\)

\(x = 0:\; y = 12\)
\(y = 0:\; x = 6\)

\(x\)06
\(y\)120

\(x + y = 8\)

\(x = 0:\; y = 8\)
\(y = 0:\; x = 8\)

\(x\)08
\(y\)80

\(x + 2y = 14\)

\(x = 0:\; y = 7\)
\(y = 0:\; x = 14\)

\(x\)014
\(y\)70

2The test point

The origin lies on none of the three lines, so it is the test point for all three inequalities:

\[ \begin{aligned} 2\cdot 0 + 0 \leq 12 \;&\Longrightarrow\; 0 \leq 12 \quad \text{(true)} \\ 0 + 0 \leq 8 \;&\Longrightarrow\; 0 \leq 8 \quad \text{(true)} \\ 0 + 2\cdot 0 \leq 14 \;&\Longrightarrow\; 0 \leq 14 \quad \text{(true)} \end{aligned} \]

All three solution half-planes contain the origin. The two remaining conditions \(x \geq 0\) and \(y \geq 0\) need no test point: their boundary lines are the axes themselves, and together they restrict the picture to the first quadrant.

3The feasible set

The feasible set is the intersection of all five half-planes. It is a bounded region – a pentagon – and only it is shaded.

4The vertices

The vertices are taken in order round the boundary.

  • \(O(0;\, 0)\) is the origin, where the two axes meet.
  • \(A\) lies on the \(Oy\)-axis. It is the \(Oy\)-intercept of the line \(x + 2y = 14\), already in its value table: \(A(0;\, 7)\).
  • \(B\) is the crossing point of \(x + 2y = 14\) and \(x + y = 8\): \[ \begin{gathered} \begin{cases} x + 2y = 14 \\ x + y = 8 \end{cases} \\ \Longrightarrow\; x = 2,\; y = 6 \;\Longrightarrow\; B(2;\, 6) \end{gathered} \]
  • \(C\) is the crossing point of \(x + y = 8\) and \(2x + y = 12\): \[ \begin{gathered} \begin{cases} x + y = 8 \\ 2x + y = 12 \end{cases} \\ \Longrightarrow\; x = 4,\; y = 4 \;\Longrightarrow\; C(4;\, 4) \end{gathered} \]
  • \(D\) lies on the \(Ox\)-axis. It is the \(Ox\)-intercept of the line \(2x + y = 12\), taken from its value table: \(D(6;\, 0)\).
Answer

The feasible set is the bounded pentagon \(OABCD\) with the vertices \(O(0;\, 0)\), \(A(0;\, 7)\), \(B(2;\, 6)\), \(C(4;\, 4)\) and \(D(6;\, 0)\).

Example 4

An unbounded feasible set

Problem

Find the feasible set of the system and determine all its vertices:

\[ \begin{cases} x + 2y \geq 8 \\ 3x + y \geq 9 \\ x;\, y \geq 0 \end{cases} \]

1Two boundary lines

\(x + 2y = 8\)

\(x = 0:\; 2y = 8 \Rightarrow y = 4\)
\(y = 0:\; x = 8\)

\(x\)08
\(y\)40

\(3x + y = 9\)

\(x = 0:\; y = 9\)
\(y = 0:\; 3x = 9 \Rightarrow x = 3\)

\(x\)03
\(y\)90

2The test point

Test point \(O(0;\, 0)\) in each inequality:

\[ \begin{aligned} 0 + 2\cdot 0 \geq 8 \;&\Longrightarrow\; 0 \geq 8 \quad \text{(false)} \\ 3\cdot 0 + 0 \geq 9 \;&\Longrightarrow\; 0 \geq 9 \quad \text{(false)} \end{aligned} \]

Both results are false, so in both cases the solution is the half-plane that does not contain the origin – the one above the line.

This is what the sign \(\geq\) normally produces: with \(\geq\) constraints the arrows point away from the origin.

3The feasible set

The feasible set is the intersection of the two half-planes with the first quadrant. It is unbounded: it extends without limit upwards and to the right.

4The vertices

  • \(A\) lies on the \(Oy\)-axis. It is the \(Oy\)-intercept of the line \(3x + y = 9\), taken from its value table: \(A(0;\, 9)\).
  • \(B\) is the crossing point of the two lines: \[ \begin{gathered} \begin{cases} 3x + y = 9 \\ x + 2y = 8 \end{cases} \\ \Longrightarrow\; x = 2,\; y = 3 \;\Longrightarrow\; B(2;\, 3) \end{gathered} \]
  • \(C\) lies on the \(Ox\)-axis. It is the \(Ox\)-intercept; for the line \(x + 2y = 8\) we get \(C(8;\, 0)\).
Answer

The feasible set is unbounded, with the vertices \(A(0;\, 9)\), \(B(2;\, 3)\) and \(C(8;\, 0)\).

Special cases

A boundary line through the origin

Consider the inequality \(y \leq 2x\). Two things that worked in every earlier example now fail at once, and both have a simple remedy.

The intercepts cannot be used. Setting \(x = 0\) gives \(y = 0\), and setting \(y = 0\) gives \(x = 0\): both attempts return the same point, the origin, and one point is not enough to draw a line. Keep the origin as the first point and choose another convenient value of \(x\), for example \(x = 3\), which gives \(y = 2\cdot 3 = 6\).

\(x\)03
\(y\)06

The origin cannot be the test point. It lies on the line, and a test point must lie outside it. Any point off the line will do; \((1;\, 0)\) is the simplest:

\[ 0 \leq 2\cdot 1 \;\Longrightarrow\; 0 \leq 2 \quad \text{(true)} \]

So the solution is the half-plane containing \((1;\, 0)\) – below and to the right of the line.

Lines parallel to an axis

Consider the system

\[ \begin{cases} x \leq 4 \\ y \geq 2 \\ x \geq 0 \end{cases} \]

An inequality in which one of the variables is missing still describes a half-plane, and its boundary line needs no value table at all – the equation names the line directly.

  • The line \(x = 4\) is vertical, parallel to the \(Oy\)-axis: every point on it has \(x = 4\), whatever \(y\) may be. It is drawn through the point 4 of the \(Ox\)-axis.
  • The line \(y = 2\) is horizontal, parallel to the \(Ox\)-axis, and is drawn through the point 2 of the \(Oy\)-axis.

The test point is the origin for both, since neither line passes through it:

\[ \begin{aligned} x \leq 4:&\quad 0 \leq 4 \quad \text{(true)} \\ y \geq 2:&\quad 0 \geq 2 \quad \text{(false)} \end{aligned} \]

So the first solution is the half-plane to the left of \(x = 4\) and the second is the half-plane above \(y = 2\). Together with the condition \(x \geq 0\) they leave a vertical strip that is unbounded upwards.

The vertices need no algebra. \(A(0;\, 2)\) is the point where the line \(y = 2\) meets the \(Oy\)-axis. At \(B\) a vertical line meets a horizontal one, so one coordinate comes directly from the equation of each line: \(x = 4\) and \(y = 2\), that is \(B(4;\, 2)\).

Practice problems

Write the solutions out as in the examples: make the value tables, write out the test-point calculations, draw a graph with all the required elements and find the vertices algebraically. The answer gives the graph and the vertices – use them to check your work.

Graph the solution set of the system of linear inequalities and find the vertices of the feasible set:

\[ \begin{cases} 2x + y \leq 10 \\ x + 2y \leq 10 \\ x + y \leq 6 \\ x;\, y \geq 0 \end{cases} \]

Answer. The feasible set is bounded. It is the pentagon with the vertices

\[ \begin{gathered} O(0;\, 0),\; A(0;\, 5),\; B(2;\, 4), \\ C(4;\, 2),\; D(5;\, 0) \end{gathered} \]

The line \(x + 2y = 10\) passes through the vertex \(A(0;\, 5)\) and the line \(2x + y = 10\) through the vertex \(D(5;\, 0)\), so all three inequalities take part in bounding the set.

Graph the solution set of the system of linear inequalities and find the vertices of the feasible set:

\[ \begin{cases} x + 2y \geq 10 \\ 2x + y \geq 11 \\ x;\, y \geq 0 \end{cases} \]

Answer. The feasible set is unbounded – it extends upwards and to the right without limit. Its vertices are

\[ A(0;\, 11),\; B(4;\, 3),\; C(10;\, 0) \]

The origin does not belong to the feasible set: substituting its coordinates makes both inequalities false, so both arrows point away from the origin.
