Absolute Extrema

In this section we look for the largest and the smallest value of a function over the whole specified interval: the greatest profit during a season, the lowest average cost within a production range, or the highest value of an asset over a specified period.

Absolute extrema

An absolute extremum is the largest or smallest value of a function over its entire relevant domain or interval. In applications, this may be the greatest profit during a season, the lowest average cost within a production range, or the highest value of an asset over a specified period. The task is to compare all possible candidates within that range.

The absolute maximum is the largest function value on the interval, and the absolute minimum is the smallest. A relative extremum involves comparison with nearby values; an absolute extremum involves comparison with every value on the specified interval.

A relative maximum inside the interval may be lower than the function value at an endpoint. Keep these distinctions in mind:

  • a relative extremum need not be an absolute extremum;
  • an absolute extremum may occur at an endpoint, even if the function does not change direction there;
  • the candidate list must include all interior critical points and both endpoints. Compare the function values at these candidates to identify the absolute extrema.

The closed-interval method

A closed interval \([a,\, b]\) includes both endpoints. If a function is continuous throughout this interval, it attains both an absolute maximum and an absolute minimum there.

For a function \(f(x)\) continuous on a closed interval \([a,\, b]\), each absolute extremum occurs either at an interior critical point or at an endpoint, \(a\) or \(b\).

The examples below have finitely many interior critical points, so the candidates form a finite list.

An absolute extremum in the interior is also a relative extremum, so it must occur at a critical point. Endpoints must be checked separately because the largest or smallest value may occur where the specified interval ends. A derivative need not exist at an endpoint for the function to be continuous there.

You do not need to classify each critical point using the first-derivative test. Evaluate the original function at all retained critical points and both endpoints, then compare the values. Include every candidate, even if it would not give a relative extremum.

How to solve

  1. Define the variable, the quantity being studied and the closed interval specified in the problem. Construct the function if necessary: revenue is \(R(x) = p\cdot x\); profit is \(P(x) = R(x) - TC(x)\); average cost is total cost divided by the relevant quantity. Check that the function is continuous throughout the interval before applying this method.
  2. Differentiate the function. If the derivative is a polynomial, retain its standard polynomial form. Simplify other expressions as needed while preserving the original domain restrictions.
  3. Find the critical points: solve \(f'(x) = 0\) and check where the derivative does not exist while the function is defined. Keep only critical points strictly inside the specified interval. Values outside the interval are discarded; endpoints are included separately.
  4. Evaluate the original function at every retained critical point and at both endpoints. Use function values, rather than derivative values, for this comparison.
  5. Compare the candidate values. The largest is the absolute maximum and the smallest is the absolute minimum. State the requested values, where they occur and their units. If a value occurs at more than one candidate, report every corresponding location.
!Common mistakes
  • Forgotten endpoints. The largest or smallest value may occur at an endpoint, even if the function does not change direction there.
  • Relative instead of absolute. The function value at a relative maximum may be lower than the value at an endpoint.
  • Critical points outside the interval. Discard them – only the critical points inside the interval and both endpoints are compared.
  • Derivative values instead of function values. Use the values of the original function for the comparison.
  • An incomplete answer. State both the value and the point where it occurs, with their units.

Examples

Example 1

Seasonal profit of a seaside hotel

Problem A seaside hotel is open for a six-month season. Its monthly profit, in thousands of euros, \(t\) months after the season opens is
\[ P(t) = 2t^3 - 21t^2 + 60t + 40,\quad 0 \leq t \leq 6 \]
Find when monthly profit is largest and smallest during the season, and calculate both values.

1The derivative

The polynomial is continuous throughout the stated closed interval. Differentiate each term:

\[ P'(t) = 6t^2 - 42t + 60 \]

2The critical points

The derivative exists everywhere. Set \(P'(t) = 0\) and solve the quadratic using its discriminant:

\[ 6t^2 - 42t + 60 = 0 \] \[ \begin{aligned} D &= (-42)^2 - 4\cdot 6\cdot 60 \\ &= 1764 - 1440 = 324 \\ \sqrt{D} &= 18 \end{aligned} \] \[ \begin{gathered} t_1 = \frac{42 - 18}{2\cdot 6} = \frac{24}{12} = 2 \\ t_2 = \frac{42 + 18}{2\cdot 6} = \frac{60}{12} = 5 \end{gathered} \]

Both roots lie strictly inside \([0,\, 6]\), so retain both.

3The values

Evaluate the original profit function at both interior critical points and both endpoints. This gives four candidates:

\[ \begin{aligned} P(0) &= 40 \\ P(2) &= 16 - 84 + 120 + 40 = 92 \\ P(5) &= 250 - 525 + 300 + 40 = 65 \\ P(6) &= 432 - 756 + 360 + 40 = 76 \end{aligned} \]
\(t\)\(0\)\(2\)\(5\)\(6\)
\(P(t)\)\(40\)\(92\)\(65\)\(76\)
Answer Maximum monthly profit: 92 thousand euros two months after the season opens. Minimum monthly profit: 40 thousand euros at the start of the season.
Example 2

Market value of a vintage car

Problem A vintage car is bought and restored. Its market value, in thousands of euros, \(t\) years after the restoration is \[ V(t) = t^3 - 9t^2 + 24t + 10,\quad 0 \leq t \leq 6 \] The owner intends to sell within six years. Find when market value is largest and smallest over that period, and calculate both values.

1The derivative

The polynomial is continuous on the specified interval. Differentiate term by term:

\[ V'(t) = 3t^2 - 18t + 24 \]

2The critical points

Set the derivative equal to zero and solve the quadratic using its discriminant. Both roots lie inside the specified interval:

\[ 3t^2 - 18t + 24 = 0 \] \[ \begin{aligned} D &= (-18)^2 - 4\cdot 3\cdot 24 \\ &= 324 - 288 = 36 \\ \sqrt{D} &= 6 \end{aligned} \] \[ \begin{gathered} t_1 = \frac{18 - 6}{2\cdot 3} = \frac{12}{6} = 2 \\ t_2 = \frac{18 + 6}{2\cdot 3} = \frac{24}{6} = 4 \end{gathered} \]

3The values

Substitute the two interior critical points and both endpoints into the original value function:

\[ \begin{aligned} V(0) &= 10 \\ V(2) &= 8 - 36 + 48 + 10 = 30 \\ V(4) &= 64 - 144 + 96 + 10 = 26 \\ V(6) &= 216 - 324 + 144 + 10 = 46 \end{aligned} \]
\(t\)\(0\)\(2\)\(4\)\(6\)
\(V(t)\)\(10\)\(30\)\(26\)\(46\)
Answer Maximum market value: 46 thousand euros after six years. Minimum market value: 10 thousand euros immediately after restoration.
Example 3

Average cost in a limited production range

Problem A plant can produce between 200 and 600 units a day. The average cost of one unit, in euros, is \[ \begin{gathered} ATC(x) = 0.05x + 10 + \frac{1620}{x}, \\ 200 \leq x \leq 600 \end{gathered} \] where \(x\) is the number of units produced per day. Find the daily output at which average cost is lowest and highest, and calculate both costs.

1The derivative

The function is continuous throughout the stated production range because output is positive. Rewrite the reciprocal term as a negative power, then apply the power rule:

\[ ATC(x) = 0.05x + 10 + 1620x^{-1} \] \[ \begin{aligned} ATC'(x) &= 0.05 - 1620x^{-2} \\ &= 0.05 - \frac{1620}{x^2} \end{aligned} \]

2The critical points

The derivative exists throughout the production range. Set it equal to zero, clear the nonzero denominator, and solve the resulting quadratic using its discriminant:

\[ 0.05 - \frac{1620}{x^2} = 0 \;\Longrightarrow\; x^2 - 32400 = 0 \] \[ D = 0^2 - 4\cdot 1\cdot(-32400) = 129600 > 0 \] \[ \begin{gathered} x_{1.2} = \frac{-0 \pm \sqrt{129600}}{2} = \pm 180 \\ \Longrightarrow\; x_1 = -180;\quad x_2 = 180 \end{gathered} \]

Neither root is retained. The root \(x = -180\) is a negative output, and \(x = 180\) lies outside \([200,\, 600]\). There are therefore no interior critical points in the permitted range. Only the two endpoints remain as candidates.

3The values

Evaluate average cost at the two permitted endpoints:

\[ \begin{gathered} ATC(200) = 10 + 10 + 8.1 = 28.1 \\ ATC(600) = 30 + 10 + 2.7 = 42.7 \end{gathered} \]
\(x\)\(200\)\(600\)
\(ATC(x)\)\(28.1\)\(42.7\)
Answer Minimum average cost: 28.10 euros per unit at 200 units per day. Maximum average cost: 42.70 euros per unit at 600 units per day.
Example 4

Profit from making chairs

Problem A workshop can make up to 400 chairs a week. The price at which \(x\) chairs a week can be sold is \[ p = -0.1x + 80 \] euros, and the weekly total cost is \[ TC(x) = 0.02x^2 + 20x + 3000 \] euros. Find the largest and smallest weekly profit within the workshop’s production capacity and the output at which each occurs.

1The quantity

Multiply quantity by unit price to obtain revenue. Then subtract the entire total cost function and combine like terms. The permitted output runs from zero to the weekly capacity:

\[ \begin{aligned} R(x) &= p\cdot x = (-0.1x + 80)x \\ &= -0.1x^2 + 80x \end{aligned} \] \[ \begin{aligned} P(x) &= R(x) - TC(x) \\ &= -0.1x^2 + 80x \\ &\phantom{=}\; - 0.02x^2 - 20x - 3000 \\ &= -0.12x^2 + 60x - 3000, \\ &\phantom{=}\; 0 \leq x \leq 400 \end{aligned} \]

2The derivative

The profit function is continuous throughout the stated interval. Differentiate its simplified polynomial form:

\[ P'(x) = -0.24x + 60 \]

3The critical point

Set the derivative equal to zero and solve the linear equation:

\[ \begin{aligned} &-0.24x + 60 = 0 \\ \Longrightarrow\;& 0.24x = 60 \\ \Longrightarrow\;& x = \frac{60}{0.24} = 250 \end{aligned} \]

This solution lies strictly inside \([0,\, 400]\), so retain it.

4The values

Evaluate the original profit function at the interior critical point and both endpoints:

\[ \begin{aligned} P(0) &= -3000 \\ P(250) &= -0.12\cdot 62500 + 15000 - 3000 \\ &= -7500 + 12000 = 4500 \\ P(400) &= -0.12\cdot 160000 + 24000 - 3000 \\ &= -19200 + 21000 = 1800 \end{aligned} \]
\(x\)\(0\)\(250\)\(400\)
\(P(x)\)\(-3000\)\(4500\)\(1800\)
Answer Maximum weekly profit: 4500 euros at 250 chairs per week. Minimum weekly profit: \(-3000\) euros at zero output.
Example 5

Orders during an advertising campaign

Problem The daily number of orders received by an online shop \(t\) days after the start of a ten-day promotional campaign is \[ N(t) = 200te^{-0.2t} + 50,\quad 0 \leq t \leq 10 \] orders. Find when the daily number of orders is largest and smallest during the campaign, and calculate both values.

1The derivative

The function is continuous throughout the stated closed interval. Apply the product rule to the first term. For its exponential factor, use the chain rule with inner derivative \(-0.2\). The constant term has derivative zero:

\[ \begin{aligned} N'(t) &= 200e^{-0.2t} \\ &\phantom{=}\; + 200t\cdot e^{-0.2t}\cdot(-0.2) \\ &= 200e^{-0.2t}(1 - 0.2t) \end{aligned} \]

2The critical point

The derivative exists throughout the interval. The exponential factor is always positive, so only the factor in brackets can make the product zero:

\[ 1 - 0.2t = 0 \;\Longrightarrow\; t = 5 \]

This critical point lies inside \([0,\, 10]\).

3The values

Evaluate the original order function at the critical point and both endpoints. Use unrounded values for the calculation and round the final order counts:

\[ \begin{aligned} N(0) &= 50 \\ N(5) &= 1000e^{-1} + 50 \approx 417.9 \\ N(10) &= 2000e^{-2} + 50 \approx 320.7 \end{aligned} \]
\(t\)\(0\)\(5\)\(10\)
\(N(t)\)\(50\)\(\approx 417.9\)\(\approx 320.7\)
Answer Most orders: approximately 418 per day, five days after the campaign starts. Fewest orders: 50 per day at the start.
Example 6

When to sell a plot of woodland

Problem A plot of woodland can be sold at any time within the next forty years. Its present value, in euros, if it is sold \(t\) years from now is
\[ V(t) = 100000e^{0.4\sqrt{t} - 0.04t},\quad 0 \leq t \leq 40 \]
Find the sale time that gives the largest present value within the stated period, and calculate that value.

1The derivative

The function is continuous on the whole closed interval, including its endpoints. For positive time, use the chain rule on the exponential. Rewrite \(\sqrt{t} = t^{0.5}\); the square root has derivative \(\dfrac{1}{2\sqrt{t}}\). Differentiate the full exponent, then multiply by the original exponential:

\[ \begin{aligned} V'(t) &= 100000e^{0.4\sqrt{t} - 0.04t}\cdot\left(\frac{0.4}{2\sqrt{t}} - 0.04\right) \\ &= 100000e^{0.4\sqrt{t} - 0.04t}\cdot\left(\frac{0.2}{\sqrt{t}} - 0.04\right) \end{aligned} \]

2The critical point

For positive time, the exponential factor is always positive. Set the expression in brackets equal to zero, isolate the square root, then square both sides:

\[ \begin{aligned} &\frac{0.2}{\sqrt{t}} - 0.04 = 0 \\ \Longrightarrow\;& \sqrt{t} = \frac{0.2}{0.04} = 5 \\ \Longrightarrow\;& t = 25 \end{aligned} \]

At \(t = 0\), the derivative formula contains \(\sqrt{t}\) in the denominator, so there is no finite derivative. The original function is still defined and continuous there. Since \(t = 0\) is an endpoint, its function value must be included in the comparison.

3The values

Evaluate the original present-value function at the interior critical point and both endpoints:

\[ \begin{aligned} V(0) &= 100000e^0 = 100000 \\ V(25) &= 100000e^{2 - 1} \\ &= 100000e \approx 271828 \\ V(40) &= 100000e^{0.4\sqrt{40} - 1.6} \\ &\approx 100000e^{0.9298} \approx 253406 \end{aligned} \]
\(t\)\(0\)\(25\)\(40\)
\(V(t)\)\(100000\)\(\approx 271828\)\(\approx 253406\)
Answer The largest present value is approximately 271 828 euros, obtained by selling the plot 25 years from now.

Practice problems

Write the solutions out as in the examples: the derivative, the critical points inside the interval, the function values at the critical points and at the endpoints, the comparison and the answer. The answer gives the derivatives, the candidates and the final results – use them to check your work.

A seasonal business is open for ten months. Its monthly profit, in thousands of euros, \(t\) months after the season opens is

\[ P(t) = t^3 - 15t^2 + 48t + 100,\quad 0 \leq t \leq 10 \]

When is the profit largest, when is it smallest, and how large is it in each case?

The derivative:

\[ P'(t) = 3t^2 - 30t + 48 \]

The critical points:

\[ \begin{aligned} D &= (-30)^2 - 4\cdot 3\cdot 48 \\ &= 900 - 576 = 324 \\ \sqrt{D} &= 18 \end{aligned} \] \[ \begin{gathered} t_1 = \frac{30 - 18}{2\cdot 3} = 2 \\ t_2 = \frac{30 + 18}{2\cdot 3} = 8 \end{gathered} \]

Answer. The candidates are \(t = 0;\ 2;\ 8;\ 10\), and the values are \(P(0) = 100\), \(P(2) = 144\), \(P(8) = 36\), \(P(10) = 80\). The profit is largest two months after the start of the season, 144 thousand euros, and smallest eight months after the start, 36 thousand euros.

A workshop can make between 100 and 400 units a week. The price at which \(x\) units a week can be sold is

\[ p = 300 - 10\sqrt{x} \]

euros, the variable cost is 60 euros a unit and the fixed costs are 2000 euros a week. What is the largest weekly profit the workshop can make, and what is the smallest?

The objective function:

\[ R(x) = p\cdot x = 300x - 10x^{\frac{3}{2}} \] \[ \begin{aligned} P(x) &= R(x) - TC(x) \\ &= 240x - 10x^{\frac{3}{2}} - 2000, \\ &\phantom{=}\; 100 \leq x \leq 400 \end{aligned} \]

The derivative:

\[ P'(x) = 240 - 15\sqrt{x} \]

Answer. The only critical point is \(\sqrt{x} = 16\) \(\;\Longrightarrow\; x = 256\), and it lies inside the range, so the candidates are \(x = 100;\ 256;\ 400\) with the values \(P(100) = 12000\), \(P(256) = 18480\), \(P(400) = 14000\). The largest weekly profit is 18 480 euros, at 256 units a week, and the smallest is 12 000 euros, at 100 units a week.

An online shop runs a twelve-day campaign. On day \(t\) of the campaign it receives

\[ N(t) = 150te^{-0.25t} + 30,\quad 0 \leq t \leq 12 \]

orders. When is the number of orders largest, when is it smallest, and how many orders are there?

The derivative (the product rule, with the chain rule inside):

\[ \begin{aligned} N'(t) &= 150e^{-0.25t} \\ &\phantom{=}\; + 150t\cdot e^{-0.25t}\cdot(-0.25) \\ &= 150e^{-0.25t}(1 - 0.25t) \end{aligned} \]

Answer. The only critical point is \(t = 4\), so the candidates are \(t = 0;\ 4;\ 12\) with the values \(N(0) = 30\), \(N(4) \approx 250.7\), \(N(12) \approx 119.6\). The shop receives the most orders four days after the start of the campaign, about 251, and the fewest at the start of the campaign, 30.

A pond is stocked with fish. The expected yield, in kilograms, \(t\) weeks after the stocking is

\[ E(t) = \frac{4000t}{t^2 + 100} + 50,\quad 0 \leq t \leq 30 \]

When is the expected yield largest, when is it smallest, and how large is it in each case?

The derivative (the quotient rule):

\[ \begin{aligned} E'(t) &= \frac{4000(t^2 + 100) - 4000t\cdot 2t}{(t^2 + 100)^2} \\ &= \frac{4000(100 - t^2)}{(t^2 + 100)^2} \end{aligned} \]

Answer. The only critical point inside the range is \(t = 10\) (the root \(t = -10\) is discarded), so the candidates are \(t = 0;\ 10;\ 30\) with the values \(E(0) = 50\), \(E(10) = 250\), \(E(30) = 170\). The expected yield is largest ten weeks after stocking, 250 kilograms, and smallest at the stocking, 50 kilograms.
