The Constant Multiple, Sum and Difference Rules

In this section you will find examples of calculating derivatives with the constant multiple rule, the sum and difference rule and the table of derivatives of the elementary functions, together with practice problems. Try to solve each problem yourself first, then reveal the solution one step at a time.

The rules used

The constant multiple rule

\[ \big(c\, u(x)\big)' = c\, u'(x) \]

The sum and difference rule

\[ \big(u(x) \pm v(x)\big)' = u'(x) \pm v'(x) \]

The derivatives of the elementary functions are listed in the table of derivatives, and the rules are explained in the constant multiple rule and sum and difference rule cards on the Topic 6 page.

Examples

Example 1

A polynomial

Problem Find \(f'(x)\) if \(f(x) = 5x^4 - 3x^2 + 7x - 2\).

1The rules

The function consists of four terms, so differentiate the four terms separately (the sum and difference rule). For the first three terms, keep each coefficient (the constant multiple rule) and apply the power rule. The final term is constant, so its derivative is zero.

2Differentiation

\[ \begin{aligned} f'(x) &= (5x^4)' - (3x^2)' + (7x)' - (2)' \\ &= 5\cdot 4x^3 - 3\cdot 2x + 7\cdot 1 - 0 \\ &= 20x^3 - 6x + 7 \end{aligned} \]
Answer \[ f'(x) = 20x^3 - 6x + 7 \]
Example 2

A root, a logarithm and an exponential function

Problem Find \(f'(x)\) if \(f(x) = 2\sqrt{x} + 5\ln x - 3e^x\).

1The rules

Differentiate each term separately (the sum and difference rule), keeping its constant coefficient (the constant multiple rule). Use the table of derivatives for the square root, logarithmic and exponential derivatives.

2Differentiation

\[ \begin{aligned} f'(x) &= 2\cdot\frac{1}{2\sqrt{x}} + 5\cdot\frac{1}{x} - 3e^x \\ &= \frac{1}{\sqrt{x}} + \frac{5}{x} - 3e^x \end{aligned} \]
Answer \[ f'(x) = \frac{1}{\sqrt{x}} + \frac{5}{x} - 3e^x \]
Example 3

A negative power and trigonometric functions

Problem Find \(f'(x)\) if \(f(x) = \dfrac{4}{x^3} + 3\sin x - 2\cos x\).

1The rules

The first term has a constant numerator and a power of \(x\) in the denominator. Rewrite it as a negative power and apply the power rule. For the remaining terms, use the sine and cosine derivatives from the table.

2Rewriting

\[ \frac{4}{x^3} = 4x^{-3} \]

3Differentiation

\[ \begin{aligned} f'(x) &= 4\cdot(-3)x^{-4} + 3\cos x \\ &\phantom{=}\; - 2\cdot(-\sin x) \\ &= -12x^{-4} + 3\cos x + 2\sin x \\ &= -\frac{12}{x^4} + 3\cos x + 2\sin x \end{aligned} \]

Finally, rewrite the negative power as a fraction. Either form of the derivative is valid.

Answer \[ f'(x) = -\frac{12}{x^4} + 3\cos x + 2\sin x \]

Practice problems

Write the solutions out as in the examples: identify the structure of the function, choose the rule, differentiate and simplify the result. Then check your answer.

Find \(f'(x)\) if \(f(x) = 4x^5 - 6x^3 + 2x - 9\).

\(f'(x) = 20x^4 - 18x^2 + 2\)

Find \(f'(x)\) if \(f(x) = 3\sqrt{x} - \dfrac{7}{x} + 2\cdot 3^x\).

\(f'(x) = \dfrac{3}{2\sqrt{x}} + \dfrac{7}{x^2} + 2\cdot 3^x\ln 3\)

Find \(f'(x)\) if \(f(x) = 5\ln x + 4\cos x - \dfrac{x^4}{2}\).

\(f'(x) = \dfrac{5}{x} - 4\sin x - 2x^3\)
