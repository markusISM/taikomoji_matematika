Second Order Partial Derivatives

In this section you will find examples of calculating second order partial derivatives, together with practice problems. Try to solve each problem yourself first, then reveal the solution one step at a time.

  • Rules
  • Examples
  • Practice

The rules used

The partial derivatives \(z'_x\) and \(z'_y\) of a function \(z = f(x;\,y)\) are functions of \(x\) and \(y\) themselves, so each of them can be differentiated again, with respect to \(x\) or with respect to \(y\). This gives four second order partial derivatives:

\[ \begin{aligned} z''_{xx} &= (z'_x)'_x = \frac{\partial^2 z}{\partial x^2} \\[8pt] z''_{xy} &= (z'_x)'_y = \frac{\partial^2 z}{\partial x\,\partial y} \\[8pt] z''_{yx} &= (z'_y)'_x = \frac{\partial^2 z}{\partial y\,\partial x} \\[8pt] z''_{yy} &= (z'_y)'_y = \frac{\partial^2 z}{\partial y^2} \end{aligned} \]

The two letters of the subscript are read from left to right: \(z''_{xy}\) means that the function is differentiated first with respect to \(x\) and then with respect to \(y\).

The derivatives \(z''_{xy}\) and \(z''_{yx}\) are called the mixed partial derivatives. If the mixed partial derivatives of \(z = f(x;\,y)\) are continuous in a neighbourhood of a point, they are equal at that point:

\[ z''_{xy} = z''_{yx} \]

Calculating both of them is therefore a check of the whole work. The method of calculation is the same as before, and no new rules are needed: the same rules are used as for first order partial derivatives (the basic rules, the product rule, the quotient rule and the chain rule).

The steps of the calculation

  1. Find \(z'_x\) and \(z'_y\).
  2. Differentiate \(z'_x\) with respect to \(x\) to get \(z''_{xx}\), and with respect to \(y\) to get \(z''_{xy}\).
  3. Differentiate \(z'_y\) with respect to \(x\) to get \(z''_{yx}\), and with respect to \(y\) to get \(z''_{yy}\).
  4. Compare the two mixed partial derivatives.

Examples

Example 1

A polynomial

Problem Find the second order partial derivatives of the function \(z = x^3y^2 - 4x^2y + 5y^3\).

1The first order partial derivatives

\[ \begin{aligned} z'_x &= 3x^2y^2 - 8xy \\ z'_y &= 2x^3y - 4x^2 + 15y^2 \end{aligned} \]

2Differentiating \(z'_x\)

The derivative \(z'_x\) is differentiated with respect to \(x\) and then with respect to \(y\):

\[ \begin{aligned} z''_{xx} &= 6xy^2 - 8y \\ z''_{xy} &= 6x^2y - 8x \end{aligned} \]

3Differentiating \(z'_y\)

The derivative \(z'_y\) is differentiated in the same two ways. With respect to \(x\) its last term \(15y^2\) gives 0, and with respect to \(y\) its middle term \(4x^2\) gives 0:

\[ \begin{aligned} z''_{yx} &= 6x^2y - 8x \\ z''_{yy} &= 2x^3 + 30y \end{aligned} \]

4The check

The mixed partial derivatives are equal: \(z''_{xy} = z''_{yx} = 6x^2y - 8x\).

Answer \[ \begin{aligned} z''_{xx} &= 6xy^2 - 8y \\ z''_{xy} &= z''_{yx} = 6x^2y - 8x \\ z''_{yy} &= 2x^3 + 30y \end{aligned} \]
Example 2

A fraction

Problem Find the second order partial derivatives of the function \(z = \dfrac{x^2}{y}\).

1The first order partial derivatives

The function is written as \(z = x^2y^{-1}\), so that both variables stand in powers. The first order partial derivatives:

\[ \begin{aligned} z'_x &= 2xy^{-1} = \frac{2x}{y} \\[6pt] z'_y &= x^2\cdot(-1)y^{-2} = -\frac{x^2}{y^2} \end{aligned} \]

2Differentiating \(z'_x\)

From \(z'_x = 2xy^{-1}\):

\[ \begin{aligned} z''_{xx} &= 2y^{-1} = \frac{2}{y} \\[6pt] z''_{xy} &= 2x\cdot(-1)y^{-2} = -\frac{2x}{y^2} \end{aligned} \]

3Differentiating \(z'_y\)

From \(z'_y = -x^2y^{-2}\):

\[ \begin{aligned} z''_{yx} &= -2xy^{-2} = -\frac{2x}{y^2} \\[6pt] z''_{yy} &= -x^2\cdot(-2)y^{-3} = \frac{2x^2}{y^3} \end{aligned} \]

4The check

The mixed partial derivatives are equal: \(z''_{xy} = z''_{yx} = -\dfrac{2x}{y^2}\).

Answer \[ \begin{aligned} z''_{xx} &= \frac{2}{y} \\[8pt] z''_{xy} &= z''_{yx} = -\frac{2x}{y^2} \\[8pt] z''_{yy} &= \frac{2x^2}{y^3} \end{aligned} \]
Example 3

An exponential function: the product rule is needed

Problem Find the second order partial derivatives of the function \(z = e^{x^2y}\).

1The first order partial derivatives

The first order partial derivatives are found by the chain rule. The inner function is \(u = x^2y\), with \(u'_x = 2xy\) and \(u'_y = x^2\):

\[ \begin{aligned} z'_x &= 2xye^{x^2y} \\ z'_y &= x^2e^{x^2y} \end{aligned} \]

Each of them is a product of two factors, so the product rule may be needed for the second order derivatives.

2Differentiating \(z'_x\)

Both factors, \(2xy\) and \(e^{x^2y}\), contain \(x\) and both contain \(y\), so the product rule is needed in both cases. The derivatives of the factors with respect to \(x\) are \(2y\) and \(2xye^{x^2y}\); with respect to \(y\) they are \(2x\) and \(x^2e^{x^2y}\):

\[ \begin{aligned} z''_{xx} &= 2ye^{x^2y} + 2xy\cdot 2xye^{x^2y} \\ &= e^{x^2y}(2y + 4x^2y^2) \\[8pt] z''_{xy} &= 2xe^{x^2y} + 2xy\cdot x^2e^{x^2y} \\ &= e^{x^2y}(2x + 2x^3y) \end{aligned} \]

3Differentiating \(z'_y\)

With respect to \(x\) both factors, \(x^2\) and \(e^{x^2y}\), contain the variable, and their derivatives are \(2x\) and \(2xye^{x^2y}\). With respect to \(y\) the factor \(x^2\) is a constant multiplier, so the product rule is not needed:

\[ \begin{aligned} z''_{yx} &= 2xe^{x^2y} + x^2\cdot 2xye^{x^2y} \\ &= e^{x^2y}(2x + 2x^3y) \\[8pt] z''_{yy} &= x^2\cdot x^2e^{x^2y} = x^4e^{x^2y} \end{aligned} \]

4The check

The mixed partial derivatives are equal: \(z''_{xy} = z''_{yx} = e^{x^2y}(2x + 2x^3y)\).

Answer \[ \begin{aligned} z''_{xx} &= e^{x^2y}(2y + 4x^2y^2) \\ z''_{xy} &= z''_{yx} = e^{x^2y}(2x + 2x^3y) \\ z''_{yy} &= x^4e^{x^2y} \end{aligned} \]

Practice problems

Write the solutions out as in the examples: find the first order partial derivatives, differentiate each of them with respect to both variables and compare the mixed partial derivatives. Then check your answer.

Find the second order partial derivatives of the function \(z = x^4 - 3x^2y^2 + 2y^3\).

\(z'_x = 4x^3 - 6xy^2\);   \(z'_y = -6x^2y + 6y^2\)

\(z''_{xx} = 12x^2 - 6y^2\);   \(z''_{xy} = z''_{yx} = -12xy\);   \(z''_{yy} = -6x^2 + 12y\)

Find the second order partial derivatives of the function \(z = 2x^3y - xy^4 + 5x\).

\(z'_x = 6x^2y - y^4 + 5\);   \(z'_y = 2x^3 - 4xy^3\)

\(z''_{xx} = 12xy\);   \(z''_{xy} = z''_{yx} = 6x^2 - 4y^3\);   \(z''_{yy} = -12xy^2\)

Find the second order partial derivatives of the function \(z = \dfrac{y}{x}\).

\(z'_x = -\dfrac{y}{x^2}\);   \(z'_y = \dfrac{1}{x}\)

\(z''_{xx} = \dfrac{2y}{x^3}\);   \(z''_{xy} = z''_{yx} = -\dfrac{1}{x^2}\);   \(z''_{yy} = 0\)

Find the second order partial derivatives of the function \(z = e^{3x - 2y}\).

\(z'_x = 3e^{3x - 2y}\);   \(z'_y = -2e^{3x - 2y}\)

\(z''_{xx} = 9e^{3x - 2y}\);   \(z''_{xy} = z''_{yx} = -6e^{3x - 2y}\);   \(z''_{yy} = 4e^{3x - 2y}\)

Find the second order partial derivatives of the function \(z = \ln(x + y^2)\).

\(z'_x = \dfrac{1}{x + y^2}\);   \(z'_y = \dfrac{2y}{x + y^2}\)

\(z''_{xx} = -\dfrac{1}{(x + y^2)^2}\);   \(z''_{xy} = z''_{yx} = -\dfrac{2y}{(x + y^2)^2}\);   \(z''_{yy} = \dfrac{2x - 2y^2}{(x + y^2)^2}\)

Find the second order partial derivatives of the function \(z = x\cdot e^{xy}\).

\(z'_x = e^{xy}(1 + xy)\);   \(z'_y = x^2e^{xy}\)

\(z''_{xx} = e^{xy}(2y + xy^2)\);   \(z''_{xy} = z''_{yx} = e^{xy}(2x + x^2y)\);   \(z''_{yy} = x^3e^{xy}\)
