The Marginal Rate of Technical Substitution

This section looks at how a firm can replace one input with another without changing its output. It is the same question that a consumer faces when choosing a basket of goods, only a production function is used instead of a utility function.

Isoquants and the marginal rate of technical substitution

A firm faces a question similar to that of a consumer, for whom the marginal rate of substitution shows how much of one good the consumer is willing to give up for an additional unit of another good. The production function \(Q = f(x;\,y)\) gives the output.

The level curve \(f(x;\,y) = C\) of a production function, called an isoquant, joins all the combinations of inputs that give the same output.

If the amount of the first input increases by one unit, the output increases by approximately \(Q'_x\). To keep the output unchanged, the amount of the second input is reduced: when it decreases by one unit, the output changes by approximately \(-Q'_y\), and when it changes by \(\Delta y\) – by approximately \(Q'_y\cdot\Delta y\). The changes offset each other when

\[ Q'_x\cdot 1 + Q'_y\cdot\Delta y = 0 \;\;\Longrightarrow\;\; \Delta y = -\frac{Q'_x}{Q'_y} \]
\[ \begin{gathered} Q'_x\cdot 1 + Q'_y\cdot\Delta y = 0 \\[4pt] \Downarrow \\[4pt] \Delta y = -\frac{Q'_x}{Q'_y} \end{gathered} \]

This change is the marginal rate of technical substitution:

\[ MRTS = -\frac{Q'_x}{Q'_y} \]

It equals the slope of the isoquant. Its absolute value shows how much of the second input one additional unit of the first input can replace, with the output unchanged. When the inputs are labour and capital, \(MRTS = -\frac{MPL}{MPK}\): \(|MRTS|\) is the amount of capital that one additional worker can replace or, the other way round, the amount of capital needed to replace one worker.

The figure shows the isoquants of the production function \(Q = xy\). Its marginal products are \(Q'_x = y\) and \(Q'_y = x\), so \(MRTS = -\frac{y}{x}\). When point A is moved to the right with the slider, \(|MRTS|\) decreases: the more of the first input is used, the less of the second input one more unit of it can replace.

The interpretation

If \(MRTS(x_0;\,y_0) = -m\), then with the inputs \((x_0;\,y_0)\) one additional unit of the first input can replace approximately \(m\) units of the second input, with the output unchanged.

When the first input does not increase by one unit

If the amount of the first input changes by \(\Delta x\) units, for example decreases by one unit (\(\Delta x = -1\)), the change in the amount of the second input that keeps the same output is approximately

\[ \Delta y \approx MRTS\cdot\Delta x \]

When \(\Delta x = -1\), \(\Delta y\) is positive: the smaller amount of the first input is compensated by an additional amount of the second input (see Examples 2 and 3).

How to solve

A problem may ask for the MRTS and its interpretation directly. The same thing may also be asked in other words: how much of one input is needed to replace one unit of another input. Then the input whose amount changes by one unit is the first variable \(x\), and the input that compensates this change is the second variable \(y\).

  1. Write the function. Decide which input changes by one unit and which one compensates this change.
  2. Find the two partial derivatives – the marginal products.
  3. Write the ratio with the minus sign: \(MRTS = -\frac{Q'_x}{Q'_y}\). Common factors cancel, so it is often easier to simplify the fraction before substituting the numbers.
  4. Substitute the given amounts of the inputs. If the amount of the first input changes by \(\Delta x\) units, calculate \(\Delta y \approx MRTS\cdot\Delta x\).
  5. Interpret the result with the wording of the interpretation.
!Common mistakes
  • The variables mixed up. The input that changes by one unit is the first variable \(x\), and the input that compensates is the second one, \(y\). In the question “how many robot hours are needed to replace one operator hour” it is the operator hours that change by one unit.
  • The ratio turned upside down. \(MRTS = -\frac{Q'_x}{Q'_y}\): the numerator is the marginal product of the input that changes by one unit.
  • A negative amount given in the interpretation. When \(MRTS = -m\), one additional unit of the first input can replace approximately \(m\) units of the second input.
  • The direction of the change ignored. When the amount of the first input decreases (\(\Delta x = -1\)), the compensating change \(\Delta y \approx MRTS\cdot\Delta x\) is positive – more of the second input is needed.
  • The ratio not simplified. Common factors, for example equal denominators or the bracket of a CES function, cancel, and the calculation becomes simpler.

Examples

Try to solve the problem yourself first, then reveal the solution one step at a time.

Example 1

Workers and capital

Problem A firm’s monthly output is \(Q(x;\,y) = 24x^{0.75}y^{0.25}\) units, where \(x\) is the number of workers and \(y\) is the capital in thousands of euros. The firm employs 30 workers and uses 50 thousand euros of capital. Find the marginal rate of technical substitution and interpret the result.

1The marginal products

This is a Cobb-Douglas production function, and the power rule gives

\[ \begin{aligned} MPL &= 0.75\cdot 24x^{-0.25}y^{0.25} = 18x^{-0.25}y^{0.25} \\ MPK &= 0.25\cdot 24x^{0.75}y^{-0.75} = 6x^{0.75}y^{-0.75} \end{aligned} \]
\[ \begin{aligned} MPL &= 18x^{-0.25}y^{0.25} \\ MPK &= 6x^{0.75}y^{-0.75} \end{aligned} \]

2MRTS

As for a Cobb-Douglas utility function, the powers combine into \(\frac{y}{x}\):

\[ MRTS = -\frac{18x^{-0.25}y^{0.25}}{6x^{0.75}y^{-0.75}} = -3\cdot\frac{y}{x} \]
\[ \begin{aligned} MRTS &= -\frac{18x^{-0.25}y^{0.25}}{6x^{0.75}y^{-0.75}} \\[6pt] &= -3\cdot\frac{y}{x} \end{aligned} \]
\[ MRTS(30;\,50) = -3\cdot\frac{50}{30} = -5 \]
Answer

The MRTS is \(-5\): with 30 workers and 50 thousand euros of capital, one additional worker can replace approximately 5 thousand euros of capital, with the output unchanged.

Example 2

Bakers and assistants

Problem A bakery bakes \[ Q(x;\,y) = 3x^2 + 2xy + y^2 \] loaves of bread a day, where \(x\) is the number of bakers’ hours and \(y\) is the number of assistants’ hours. Today 10 bakers’ hours and 30 assistants’ hours are planned, but one baker has to leave an hour early. How many additional assistants’ hours are needed to keep the output unchanged?

1What is asked

The bakers’ hours change by one hour, and the assistants’ hours compensate this change. So \(x\) is the number of bakers’ hours, and one hour fewer means \(\Delta x = -1\).

2The marginal products

\[ \begin{aligned} Q'_x &= 6x + 2y; &\qquad Q'_x(10;\,30) &= 60 + 60 = 120 \\ Q'_y &= 2x + 2y; &\qquad Q'_y(10;\,30) &= 20 + 60 = 80 \end{aligned} \]
\[ \begin{aligned} Q'_x &= 6x + 2y \\ Q'_y &= 2x + 2y \\[6pt] Q'_x(10;\,30) &= 60 + 60 = 120 \\ Q'_y(10;\,30) &= 20 + 60 = 80 \end{aligned} \]

3The MRTS and the change

\[ \begin{aligned} MRTS &= -\frac{120}{80} = -1.5 \\[6pt] \Delta y &\approx MRTS\cdot\Delta x = (-1.5)\cdot(-1) = 1.5 \end{aligned} \]

One bakers’ hour fewer lowers the output by approximately 120 loaves, and an additional assistants’ hour raises it by approximately 80 loaves.

Answer

Approximately 1.5 additional assistants’ hours are needed.

Example 3

Operators and robots

Problem A workshop produces \[ Q(x;\,y) = \frac{100xy}{2x + y} \] parts a day, where \(x\) is the number of operator hours and \(y\) is the number of robot hours. The workshop uses 20 operator hours and 40 robot hours a day. How many robot hours are needed to replace one operator hour, so that the output does not change?

1The marginal products

The quotient rule is used with \(u = 100xy\) and \(v = 2x + y\). With respect to \(x\): \(u'_x = 100y\), \(v'_x = 2\); with respect to \(y\): \(u'_y = 100x\), \(v'_y = 1\).

\[ \begin{aligned} Q'_x &= \frac{100y(2x + y) - 100xy\cdot 2}{(2x + y)^2} = \frac{100y^2}{(2x + y)^2} \\[8pt] Q'_y &= \frac{100x(2x + y) - 100xy\cdot 1}{(2x + y)^2} = \frac{200x^2}{(2x + y)^2} \end{aligned} \]
\[ \begin{aligned} Q'_x &= \frac{100y(2x + y) - 100xy\cdot 2}{(2x + y)^2} \\[6pt] &= \frac{100y^2}{(2x + y)^2} \\[10pt] Q'_y &= \frac{100x(2x + y) - 100xy\cdot 1}{(2x + y)^2} \\[6pt] &= \frac{200x^2}{(2x + y)^2} \end{aligned} \]

2MRTS

The two derivatives have the same denominator, and it cancels:

\[ \begin{aligned} MRTS &= -\frac{100y^2}{200x^2} = -\frac{y^2}{2x^2} \\[6pt] MRTS(20;\,40) &= -\frac{1600}{800} = -2 \end{aligned} \]

3The change

Replacing one operator hour means \(\Delta x = -1\):

\[ \Delta y \approx MRTS\cdot\Delta x = (-2)\cdot(-1) = 2 \]
Answer

Approximately 2 robot hours are needed to replace one operator hour.

Example 4

Machines and workers

Problem The daily output of a packaging plant is given by the CES production function \[ Q(x;\,y) = 50\left[0.4x^{-1} + 0.6y^{-1}\right]^{-1} \] where \(x\) is the number of packaging machines and \(y\) is the number of workers. The plant has 10 machines and 30 workers. Find the marginal rate of technical substitution and interpret the result.

1The marginal products

The function is a composite function: the inner function is the expression in the brackets, and the outer function is the power with the exponent \(-1\). The partial derivatives of the inner function are \(-0.4x^{-2}\) and \(-0.6y^{-2}\). The power form of the chain rule gives

\[ \begin{aligned} Q'_x &= 50\cdot(-1)\left[0.4x^{-1} + 0.6y^{-1}\right]^{-2}\cdot\left(-0.4x^{-2}\right) = 20x^{-2}\left[0.4x^{-1} + 0.6y^{-1}\right]^{-2} \\[8pt] Q'_y &= 50\cdot(-1)\left[0.4x^{-1} + 0.6y^{-1}\right]^{-2}\cdot\left(-0.6y^{-2}\right) = 30y^{-2}\left[0.4x^{-1} + 0.6y^{-1}\right]^{-2} \end{aligned} \]
\[ \begin{aligned} Q'_x &= 50\cdot(-1)\left[0.4x^{-1} + 0.6y^{-1}\right]^{-2} \\ &\phantom{=}\;\cdot\left(-0.4x^{-2}\right) \\ &= 20x^{-2}\left[0.4x^{-1} + 0.6y^{-1}\right]^{-2} \\[10pt] Q'_y &= 50\cdot(-1)\left[0.4x^{-1} + 0.6y^{-1}\right]^{-2} \\ &\phantom{=}\;\cdot\left(-0.6y^{-2}\right) \\ &= 30y^{-2}\left[0.4x^{-1} + 0.6y^{-1}\right]^{-2} \end{aligned} \]

2MRTS

The power of the expression in the brackets is a factor of both marginal products, so it cancels:

\[ MRTS = -\frac{20x^{-2}\left[0.4x^{-1} + 0.6y^{-1}\right]^{-2}}{30y^{-2}\left[0.4x^{-1} + 0.6y^{-1}\right]^{-2}} = -\frac{20x^{-2}}{30y^{-2}} = -\frac{2}{3}\cdot\left(\frac{y}{x}\right)^2 \]
\[ \begin{aligned} MRTS &= -\frac{20x^{-2}\left[0.4x^{-1} + 0.6y^{-1}\right]^{-2}}{30y^{-2}\left[0.4x^{-1} + 0.6y^{-1}\right]^{-2}} \\[8pt] &= -\frac{20x^{-2}}{30y^{-2}} = -\frac{2}{3}\cdot\left(\frac{y}{x}\right)^2 \end{aligned} \]
\[ MRTS(10;\,30) = -\frac{2}{3}\cdot 3^2 = -6 \]
Answer

The MRTS is \(-6\): with 10 machines and 30 workers, one additional machine can replace approximately 6 workers, with the output unchanged.

Practice problems

Write the solutions out as in the examples: find the marginal products, write the MRTS and simplify it, substitute the given amounts of the inputs and interpret the result. The answer gives the intermediate results and the interpretation – use them to check your work.

A workshop produces

\[ Q(x;\,y) = 50x^{0.4}y^{0.6} \]

units of output a day, where \(x\) is the number of workers and \(y\) is the number of machine hours. Find the marginal rate of technical substitution when 20 workers and 60 machine hours are used. Interpret the result.

The marginal products:

\[ \begin{aligned} Q'_x &= 20x^{-0.6}y^{0.6} \\ Q'_y &= 30x^{0.4}y^{-0.4} \end{aligned} \]

The MRTS:

\[ MRTS = -\frac{Q'_x}{Q'_y} = -\frac{20x^{-0.6}y^{0.6}}{30x^{0.4}y^{-0.4}} = -\frac{2y}{3x} \]
\[ \begin{aligned} MRTS &= -\frac{20x^{-0.6}y^{0.6}}{30x^{0.4}y^{-0.4}} \\[6pt] &= -\frac{2y}{3x} \end{aligned} \]
\[ MRTS(20;\,60) = -\frac{120}{60} = -2 \]

Answer. The MRTS is \(-2\): with 20 workers and 60 machine hours, one additional worker can replace approximately 2 machine hours, with the output unchanged.

A warehouse with \(x\) robots and \(y\) workers handles

\[ Q(x;\,y) = 100\left[0.5x^{-0.5} + 0.5y^{-0.5}\right]^{-2} \]

pallets a day. The warehouse has 16 robots and 36 workers. Approximately how many workers can one additional robot replace, so that the number of pallets handled does not change?

The marginal products (the chain rule):

\[ \begin{aligned} Q'_x &= 100\cdot(-2)\left[0.5x^{-0.5} + 0.5y^{-0.5}\right]^{-3}\cdot\left(-0.25x^{-1.5}\right) \\ &= 50\left[0.5x^{-0.5} + 0.5y^{-0.5}\right]^{-3}x^{-1.5} \\[10pt] Q'_y &= 100\cdot(-2)\left[0.5x^{-0.5} + 0.5y^{-0.5}\right]^{-3}\cdot\left(-0.25y^{-1.5}\right) \\ &= 50\left[0.5x^{-0.5} + 0.5y^{-0.5}\right]^{-3}y^{-1.5} \end{aligned} \]
\[ \begin{aligned} Q'_x &= 100\cdot(-2)\left[0.5x^{-0.5} + 0.5y^{-0.5}\right]^{-3} \\ &\phantom{=}\;\cdot\left(-0.25x^{-1.5}\right) \\ &= 50\left[0.5x^{-0.5} + 0.5y^{-0.5}\right]^{-3}x^{-1.5} \\[10pt] Q'_y &= 100\cdot(-2)\left[0.5x^{-0.5} + 0.5y^{-0.5}\right]^{-3} \\ &\phantom{=}\;\cdot\left(-0.25y^{-1.5}\right) \\ &= 50\left[0.5x^{-0.5} + 0.5y^{-0.5}\right]^{-3}y^{-1.5} \end{aligned} \]

The MRTS and the change (the common factor \(50\left[0.5x^{-0.5} + 0.5y^{-0.5}\right]^{-3}\) cancels):

\[ \begin{aligned} MRTS &= -\frac{x^{-1.5}}{y^{-1.5}} = -\left(\frac{y}{x}\right)^{1.5} \\[6pt] MRTS(16;\,36) &= -\left(\frac{9}{4}\right)^{1.5} = -\left(\frac{3}{2}\right)^3 = -3.375 \\[6pt] \Delta y &\approx MRTS\cdot\Delta x = (-3.375)\cdot 1 = -3.375 \end{aligned} \]
\[ \begin{aligned} MRTS &= -\frac{x^{-1.5}}{y^{-1.5}} \\[4pt] &= -\left(\frac{y}{x}\right)^{1.5} \\[6pt] MRTS(16;\,36) &= -\left(\frac{9}{4}\right)^{1.5} \\[4pt] &= -\left(\frac{3}{2}\right)^3 = -3.375 \\[6pt] \Delta y &\approx MRTS\cdot\Delta x \\ &= (-3.375)\cdot 1 = -3.375 \end{aligned} \]

Answer. One additional robot can replace approximately 3.375 workers.
