Topic 8 · Calculating partial derivatives · Section 1

Basic Rules for Partial Derivatives

In this section you will find examples of calculating partial derivatives in which the variable that is not differentiated is treated as a constant, together with practice problems. Try to solve each problem yourself first, then reveal the solution one step at a time.

  • Rules
  • Examples
  • Practice

The rules used

To find \(z'_x\), treat \(y\) as a constant and differentiate with respect to \(x\). To find \(z'_y\), treat \(x\) as a constant and differentiate with respect to \(y\). No new rules of differentiation are needed: a constant can stand in a formula as a separate term or as a factor, and the rule for each of these cases is already known.

\[ (c)' = 0;\qquad \big(c\cdot u(x)\big)' = c\cdot u'(x) \]
1A term without the variable

A term that does not contain the variable of differentiation is a constant, so its derivative is 0.

  • \((4y^2)'_x = 0\)
  • \((\ln y)'_x = 0;\quad (7)'_x = 0\)
2A factor without the variable

A factor that does not contain the variable of differentiation is a constant multiplier. It stays where it is, and only the rest of the term is differentiated.

  • \((x^2y)'_x = 2x\cdot y\)
  • \((x^2y)'_y = x^2\cdot 1 = x^2\)
3Roots and fractions as powers

Before differentiating, write roots and fractions as powers:

  • \(\sqrt[n]{x^m} = x^{\frac{m}{n}};\quad \dfrac{1}{x^n} = x^{-n}\)

The derivatives of the elementary functions are given in the table of derivatives of Topic 6. More about how a partial derivative is calculated can be found in the cards “How a partial derivative is calculated” and “The steps of the calculation” on the Topic 8 page.

Examples

Example 1

One variable in each term

Problem Find the first order partial derivatives of the function \(z = 3x^2 + 5y^3 - 4x + 7y - 2\).

1With respect to \(x\)

Here \(y\) is a constant. The terms \(5y^3\), \(7y\) and \(2\) do not contain \(x\), so their derivatives are 0. The other two terms are differentiated by the power rule:

\[ \begin{aligned} z'_x &= (3x^2)'_x + (5y^3)'_x - (4x)'_x \\ &\phantom{=}\; + (7y)'_x - (2)'_x \\ &= 6x + 0 - 4 + 0 - 0 = 6x - 4 \end{aligned} \]

2With respect to \(y\)

Now \(x\) is a constant. The terms \(3x^2\), \(4x\) and \(2\) do not contain \(y\):

\[ z'_y = 0 + 15y^2 - 0 + 7 - 0 = 15y^2 + 7 \]
Answer \[ \begin{aligned} z'_x &= 6x - 4 \\ z'_y &= 15y^2 + 7 \end{aligned} \]
Example 2

Terms with both variables

Problem Find the first order partial derivatives of the function \(z = 4x^3y^2 - 5xy^4 + 2x - 6y\).

1With respect to \(x\)

In the first term \(4y^2\) is a constant multiplier and the derivative of \(x^3\) is \(3x^2\), so the term gives \(4y^2\cdot 3x^2 = 12x^2y^2\). In the second term \(5y^4\) is the constant multiplier of \(x\); since the derivative of \(x\) is 1, \(5y^4\) remains after the minus sign. The third term gives 2, and the last one does not contain \(x\):

\[ \begin{aligned} z'_x &= 4y^2\cdot 3x^2 - 5y^4\cdot 1 + 2 - 0 \\ &= 12x^2y^2 - 5y^4 + 2 \end{aligned} \]

2With respect to \(y\)

In the first term \(4x^3\) is the constant multiplier of \(y^2\), so the term gives \(4x^3\cdot 2y = 8x^3y\). In the second term \(5x\) is the constant multiplier of \(y^4\), so after the minus sign the term gives \(5x\cdot 4y^3 = 20xy^3\). The third term does not contain \(y\), and the last one is differentiated as a linear function:

\[ \begin{aligned} z'_y &= 4x^3\cdot 2y - 5x\cdot 4y^3 + 0 - 6 \\ &= 8x^3y - 20xy^3 - 6 \end{aligned} \]
Answer \[ \begin{aligned} z'_x &= 12x^2y^2 - 5y^4 + 2 \\ z'_y &= 8x^3y - 20xy^3 - 6 \end{aligned} \]
Example 3

A root and a fraction

Problem Find the first order partial derivatives of the function \(z = 8\sqrt{x}\cdot y^3 + \dfrac{x^2}{y}\).

1Rewriting

Roots and fractions are written as powers first, by the rules \(\sqrt[n]{x^m} = x^{\frac{m}{n}}\) and \(\dfrac{1}{x^n} = x^{-n}\):

\[ z = 8x^{\frac{1}{2}}y^3 + x^2y^{-1} \]

2With respect to \(x\)

The multipliers \(8y^3\) and \(y^{-1}\) are constants, and the powers of \(x\) are differentiated:

\[ \begin{aligned} z'_x &= 8y^3\cdot \frac{1}{2}x^{-\frac{1}{2}} + y^{-1}\cdot 2x \\ &= \frac{4y^3}{\sqrt{x}} + \frac{2x}{y} \end{aligned} \]

3With respect to \(y\)

The multipliers \(8x^{\frac{1}{2}}\) and \(x^2\) are constants, and the powers of \(y\) are differentiated:

\[ \begin{aligned} z'_y &= 8x^{\frac{1}{2}}\cdot 3y^2 + x^2\cdot(-1)y^{-2} \\ &= 24\sqrt{x}\cdot y^2 - \frac{x^2}{y^2} \end{aligned} \]

The second term of the function is a fraction, but the quotient rule was not needed. With respect to \(x\) its denominator is a constant, and with respect to \(y\) its numerator is a constant, so in both cases the term can be written as a constant multiplied by a power.

Answer \[ \begin{aligned} z'_x &= \frac{4y^3}{\sqrt{x}} + \frac{2x}{y} \\ z'_y &= 24\sqrt{x}\cdot y^2 - \frac{x^2}{y^2} \end{aligned} \]
Example 4

Powers with decimal exponents

Problem Find the first order partial derivatives of the function \(z = 12x^{0.25}y^{0.75}\).

1With respect to \(x\)

The factor \(12y^{0.75}\) is a constant multiplier. The power rule is applied to \(x^{0.25}\), and the exponent becomes \(0.25 - 1 = -0.75\):

\[ \begin{aligned} z'_x &= 12y^{0.75}\cdot 0.25x^{-0.75} \\ &= 3x^{-0.75}y^{0.75} \end{aligned} \]

2With respect to \(y\)

The factor \(12x^{0.25}\) is a constant multiplier. The power rule is applied to \(y^{0.75}\), and the exponent becomes \(0.75 - 1 = -0.25\):

\[ \begin{aligned} z'_y &= 12x^{0.25}\cdot 0.75y^{-0.25} \\ &= 9x^{0.25}y^{-0.25} \end{aligned} \]
Answer \[ \begin{aligned} z'_x &= 3x^{-0.75}y^{0.75} \\ z'_y &= 9x^{0.25}y^{-0.25} \end{aligned} \]
Example 5

The values of the partial derivatives at a point

Problem Find \(f'_x(2;\,1)\) and \(f'_y(2;\,1)\) for the function \(f(x;\,y) = x^3 - 2x^2y + 3y^2\).

1The partial derivatives

The derivatives are found first, term by term as in Example 2:

\[ \begin{aligned} f'_x(x;\,y) &= 3x^2 - 4xy \\ f'_y(x;\,y) &= -2x^2 + 6y \end{aligned} \]

2The values at the point

The point is substituted into the finished derivatives, never into the function before it is differentiated:

\[ \begin{aligned} f'_x(2;\,1) &= 3\cdot 2^2 - 4\cdot 2\cdot 1 \\ &= 12 - 8 = 4 \\[6pt] f'_y(2;\,1) &= -2\cdot 2^2 + 6\cdot 1 \\ &= -8 + 6 = -2 \end{aligned} \]
Answer \[ \begin{aligned} f'_x(2;\,1) &= 4 \\ f'_y(2;\,1) &= -2 \end{aligned} \]

At the point \((2;\,1)\), if \(x\) increases by one unit and \(y\) stays equal to 1, the value of the function increases by approximately 4. If \(y\) increases by one unit and \(x\) stays equal to 2, it decreases by approximately 2.

Practice problems

Write the solutions out as in the examples: choose the variable, decide which terms and factors are constants, differentiate and simplify the result. Then check your answer.

Find the first order partial derivatives of the function \(z = 5x^2 - 3y^4 + 2x - 9y + 4\).

\(z'_x = 10x + 2\);   \(z'_y = -12y^3 - 9\)

Find the first order partial derivatives of the function \(z = 2x^4y - 7x^2y^3 + 3y\).

\(z'_x = 8x^3y - 14xy^3\);   \(z'_y = 2x^4 - 21x^2y^2 + 3\)

Find the first order partial derivatives of the function \(z = x^3y^2 + 4xy - 6x + y^2\).

\(z'_x = 3x^2y^2 + 4y - 6\);   \(z'_y = 2x^3y + 4x + 2y\)

Find the first order partial derivatives of the function \(z = 6\sqrt{x}\cdot y^2 - \dfrac{3x}{y}\).

\(z'_x = \dfrac{3y^2}{\sqrt{x}} - \dfrac{3}{y}\);   \(z'_y = 12\sqrt{x}\cdot y + \dfrac{3x}{y^2}\)

Find the first order partial derivatives of the function \(z = \dfrac{4y}{x^2} - \dfrac{x^3}{y}\).

\(z'_x = -\dfrac{8y}{x^3} - \dfrac{3x^2}{y}\);   \(z'_y = \dfrac{4}{x^2} + \dfrac{x^3}{y^2}\)

Find the first order partial derivatives of the function \(z = 20x^{0.4}y^{0.6}\).

\(z'_x = 8x^{-0.6}y^{0.6}\);   \(z'_y = 12x^{0.4}y^{-0.4}\)

Find the first order partial derivatives of the function \(z = 3x^2e^y + y\ln x\).

\(z'_x = 6xe^y + \dfrac{y}{x}\);   \(z'_y = 3x^2e^y + \ln x\)

Find the first order partial derivatives of the function \(z = 9\sqrt[3]{x^2}\cdot y - 2y^4\).

\(z'_x = \dfrac{6y}{\sqrt[3]{x}}\);   \(z'_y = 9\sqrt[3]{x^2} - 8y^3\)

Find the values of the first order partial derivatives of the function \(f(x;\,y) = x^3 + 2xy^2 - 5y\) at the point \((1;\,2)\).

\(f'_x(x;\,y) = 3x^2 + 2y^2\);   \(f'_y(x;\,y) = 4xy - 5\)

\(f'_x(1;\,2) = 11\);   \(f'_y(1;\,2) = 3\)
