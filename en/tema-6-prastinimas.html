Simplifying Before Differentiating

In this section you will find examples of calculating derivatives in which it is convenient to simplify the function before differentiating, together with practice problems. Try to solve each problem yourself first, then reveal the solution one step at a time.

  • Rules
  • Examples
  • Practice

The rules used

The examples use the following transformations:

  • for a fraction whose denominator is a single term, divide each term of the numerator by the denominator: \(\dfrac{a + b}{c} = \dfrac{a}{c} + \dfrac{b}{c}\), \(c \neq 0\);
  • the logarithm of a power: \(\ln(x^k) = k\ln x\), \(x > 0\);
  • the product of powers with the same base: \(e^a\cdot e^b = e^{a + b}\);
  • the square of a binomial: \((a + b)^2 = a^2 + 2ab + b^2\).

After transforming the function, preserve the original domain restrictions. The table of derivatives and the rules are given on the Topic 6 page.

Examples

Before choosing a differentiation rule, check whether algebra can simplify the function. Cancelling common factors or using logarithm and exponent laws may reduce the number of steps. Preserve the original domain restrictions. Expanding a high power is usually less efficient than applying the chain rule directly.

Example 1

A fraction that can be simplified

Problem Find \(f'(x)\) if \(f(x) = \dfrac{x^3 + 4x^2 - x}{x}\).

1Simplifying

Every term in the numerator contains \(x\). Divide each term by the denominator to obtain a polynomial:

\[ \begin{aligned} f(x) &= \frac{x^3}{x} + \frac{4x^2}{x} - \frac{x}{x} \\ &= x^2 + 4x - 1,\quad x \neq 0 \end{aligned} \]

2Differentiation

Use the sum rule and the power rule:

\[ f'(x) = 2x + 4 \]

The quotient rule gives the same result but requires more algebra. The derivative is valid only on the domain of the original function, which excludes zero.

Answer \[ f'(x) = 2x + 4,\quad x \neq 0 \]
Example 2

The logarithm of a power

Problem Find \(f'(x)\) if \(f(x) = \ln(x^3)\).

1Simplifying

The chain rule applies, but the logarithm power law gives a shorter calculation. Rewrite the logarithm of a power as a constant multiple of a logarithm. The original function requires \(x > 0\).

\[ f(x) = \ln(x^3) = 3\ln x \]

2Differentiation

Use the constant multiple rule:

\[ f'(x) = 3\cdot\frac{1}{x} = \frac{3}{x} \]

3Check

The chain rule confirms the same result:

\[ f'(x) = \frac{1}{x^3}\cdot 3x^2 = \frac{3x^2}{x^3} = \frac{3}{x} \]

Similarly, the exponent law rewrites \(e^x\cdot e^{3x}\) as \(e^{4x}\), whose derivative is \(4e^{4x}\). Simplifying first avoids the product rule in this case.

Answer \[ f'(x) = \frac{3}{x} \]
Example 3

The square of a binomial

Problem Find \(f'(x)\) if \(f(x) = (2x + 1)^2\).

1First method – the chain rule

For the chain rule, the inner function is \(u(x) = 2x + 1\), whose derivative is \(u'(x) = 2\):

\[ \begin{aligned} f'(x) &= 2(2x + 1)\cdot 2 \\ &= 4(2x + 1) = 8x + 4 \end{aligned} \]

2Second method – expanding the square

Alternatively, expand the square before differentiating:

\[ \begin{gathered} f(x) = 4x^2 + 4x + 1 \\ \Longrightarrow\; f'(x) = 8x + 4 \end{gathered} \]

3Which method to choose

For a square, both methods are short. For \((x^2 + 1)^5\), however, expanding a fifth power requires substantially more algebra, whereas the chain rule directly gives

\[ \begin{aligned} \big((x^2 + 1)^5\big)' &= 5(x^2 + 1)^4\cdot 2x \\ &= 10x(x^2 + 1)^4 \end{aligned} \]

In such cases, keep the expression in its factored form and use the chain rule.

Answer \[ f'(x) = 8x + 4 \]

Practice problems

Write the solutions out as in the examples: identify the structure of the function, choose the rule, differentiate and simplify the result. Then check your answer.

Find \(f'(x)\) if \(f(x) = \dfrac{8x^4 + 6x^3 - 2x}{2x}\).

After simplifying, \(f(x) = 4x^3 + 3x^2 - 1\), \(x \neq 0\); \(f'(x) = 12x^2 + 6x\)
