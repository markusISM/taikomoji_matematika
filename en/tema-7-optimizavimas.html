Optimization

The second derivative test

In the previous topic the extrema of a function were found with the sign chart of the first derivative: a critical point at which \(f'(x)\) changes from positive to negative is a maximum point, and a change from negative to positive gives a minimum point. The second derivative gives the same answer in a shorter way, because it shows the shape of the curve at the critical point itself. No sign chart is needed then.

The critical points are found as before. They are the values \(x = c\) of the domain at which

\[ \begin{gathered} f'(c) = 0\quad\text{or} \\ f'(c)\ \text{does not exist} \end{gathered} \]

The test is then applied to each of them separately.

The second derivative test. Let \(x = c\) be a critical point of a function \(y = f(x)\). Then:
  • if \(f''(c) < 0\), then \(x = c\) is a relative maximum point;
  • if \(f''(c) > 0\), then \(x = c\) is a relative minimum point;
  • if \(f''(c) = 0\), the test gives no answer.

The reason is the meaning of the second derivative. If \(f''(c) < 0\), the curve is concave near \(x = c\), and a point with a horizontal tangent line on a concave curve is a top. If \(f''(c) > 0\), the curve is convex near \(x = c\), so such a point is the lowest among the nearby points.

When the test gives no answer

If \(f''(c) = 0\), the second derivative does not show the type of the point: it may be a maximum, a minimum, or neither. The same is true when \(f''(c)\) does not exist. In these cases the critical point is examined with the sign chart of \(f'\), as in the previous topic.

The type of the critical point and the answer to the problem

In applied problems it is enough to find the sign of the second derivative at the critical point: a negative sign shows the largest value of the quantity, and a positive sign the smallest.

Writing the objective function

In many applied problems the function to be optimized is not given. The problem gives the information from which it has to be built. The function whose value has to be made as large or as small as possible is called the objective function. Four situations cover most of the economic problems of this section.

1Revenue from a demand function
  • \(R(x) = p\cdot x\)

A demand function gives the price \(p\) at which \(x\) units can be sold. The revenue is the price multiplied by the quantity sold. Before multiplying, the price \(p\) is written as a function of \(x\), so that the revenue is a function of one variable.

2Profit from a demand function and a cost function
  • \(P(x) = R(x) - TC(x)\)
  • \(P(x) = p\cdot x - TC(x)\)

The profit is the revenue minus the total cost. Both parts have to be written as functions of the same variable \(x\). The brackets around the cost have to be opened carefully, because every term of the cost changes its sign.

3Profit from a production function
  • \(P(x) = p\cdot Q(x) - w\cdot x\)

A production function \(Q(x)\) gives the output of a firm when it uses \(x\) units of an input: workers, machine hours or raw materials. The output is sold at a fixed price of \(p\) euros a unit, and a unit of the input costs \(w\) euros. The first term is the revenue, the second is the cost of the input. If the firm also has a fixed cost \(F\), it is subtracted as well.

4Average cost
  • \(ATC(x) = \dfrac{TC(x)}{x}\)

The average cost is the total cost of \(x\) units divided by the number of units. Each term of the total cost is divided by \(x\) separately. The function obtained this way is easier to differentiate.

How to solve

  1. Explain what the variable \(x\) means and on which interval its values can vary. The quantity of a good, the number of workers and the number of hours cannot be negative.
  2. Write the objective function using the objective function formulas. Open the brackets and collect like terms.
  3. Differentiate. Solve \(f'(x) = 0\) and find the points where \(f'(x)\) does not exist. These are the critical points. Drop the points that do not belong to the interval of the problem.
  4. Differentiate again and substitute the critical point into \(f''(x)\). A negative value shows a maximum, a positive value a minimum. If the value is zero, use the sign chart of \(f'\).
  5. Answer the questions of the problem: give the value of \(x\) and, if asked, the price, the output, the revenue, the profit or the cost.

If the first derivative is a rational function

Write it as a single fraction and set it equal to zero. A fraction is zero only when its numerator is zero and its denominator is not, so the equation is replaced by a system:

\[ \frac{u(x)}{v(x)} = 0 \;\Longleftrightarrow\; \begin{cases} u(x) = 0 \\ v(x) \neq 0 \end{cases} \]

The second condition has to be checked as well: a value at which the denominator is zero does not belong to the domain of the function, so it cannot be a solution.

!Common mistakes
  • The critical point is found by setting the second derivative equal to zero. Critical points come from \(f'(x) = 0\) (or from the points where \(f'(x)\) does not exist). The equation \(f''(x) = 0\) gives possible inflection points, not extrema. Here the second derivative is used only to find the type of the critical point.
  • \(f''(c) = 0\) is taken as the answer. In that case the test gives no answer – the critical point has to be examined with the sign chart of \(f'\).
  • The brackets around the cost are opened carelessly. When the total cost is subtracted, every term of it changes its sign.
  • The denominator is not checked. A value at which the denominator is zero cannot be a critical point.
  • Negative solutions are not dropped. A quantity, a number of workers or a number of hours cannot be negative.

Examples

Try to solve the problem yourself first, then reveal the solution one step at a time.

Example 1

The largest weekly revenue

Problem A company sells \(x\) units of a product a week. The weekly demand function is \[ p = -0.04x + 60 \] euros a unit.
  1. Find the number of units that gives the largest revenue. Use the second derivative test, if possible.
  2. Find the price and the revenue at that number.

1a) The objective function

The revenue is the price multiplied by the number of units sold:

\[ \begin{aligned} R(x) &= p\cdot x = (-0.04x + 60)x \\ &= -0.04x^2 + 60x,\qquad x \ge 0 \end{aligned} \]

2a) The first derivative and the critical point

The power rule gives

\[ R'(x) = -0.08x + 60 \]

The critical point comes from \(R'(x) = 0\):

\[ \begin{gathered} -0.08x + 60 = 0 \;\Longrightarrow\; 0.08x = 60 \\ \Longrightarrow\; x = 750 \end{gathered} \]

3a) The second derivative test

Differentiating once more,

\[ R''(x) = -0.08 \]

so \(R''(750) = -0.08 < 0\), and \(x = 750\) is a relative maximum point. So the revenue is largest when 750 units a week are sold.

4b) The price and the revenue

The price and the revenue at that number are

\[ p = -0.04\cdot 750 + 60 = 30 \] \[ R(750) = 30\cdot 750 = 22500 \]
Answer The revenue is largest when 750 units a week are sold. The price is then 30 euros a unit and the revenue is 22500 euros a week.
Example 2

The largest weekly profit

Problem A firm can sell \(x\) units of its product a week at the price \[ p = -0.02x + 90 \] euros a unit, and the total cost of producing them is \[ TC(x) = 0.03x^2 + 20x + 5000 \] euros.
  1. Find the output that gives the largest profit. Use the second derivative test, if possible.
  2. Find the price and the profit at that output.

1a) The objective function

The revenue is

\[ \begin{aligned} R(x) &= p\cdot x = (-0.02x + 90)x \\ &= -0.02x^2 + 90x \end{aligned} \]

and the profit is the revenue minus the total cost:

\[ \begin{aligned} P(x) &= -0.02x^2 + 90x \\ &\phantom{=}\; - \left(0.03x^2 + 20x + 5000\right) \\ &= -0.05x^2 + 70x - 5000,\quad x \ge 0 \end{aligned} \]

2a) The first derivative and the critical point

The power rule gives

\[ P'(x) = -0.1x + 70 \]

The critical point comes from \(P'(x) = 0\):

\[ \begin{gathered} -0.1x + 70 = 0 \;\Longrightarrow\; 0.1x = 70 \\ \Longrightarrow\; x = 700 \end{gathered} \]

3a) The second derivative test

Differentiating once more,

\[ P''(x) = -0.1 \]

so \(P''(700) = -0.1 < 0\), and \(x = 700\) is a relative maximum point. So the profit is largest at an output of 700 units a week.

4b) The price and the profit

The price and the profit at that output are

\[ p = -0.02\cdot 700 + 90 = 76 \] \[ \begin{aligned} P(700) &= -0.05\cdot 700^2 + 70\cdot 700 \\ &\phantom{=}\; - 5000 \\ &= -24500 + 49000 - 5000 \\ &= 19500 \end{aligned} \]
Answer The profit is largest at an output of 700 units a week. The price is then 76 euros a unit and the profit is 19500 euros a week.
Example 3

The smallest average cost

Problem The daily total cost of producing \(x\) units of a product is \[ TC(x) = 0.5x^2 + 40x + 7200 \] euros.
  1. Find the output at which the average cost is smallest. Use the second derivative test, if possible.
  2. Find that average cost.

1a) The objective function

The average cost is the total cost divided by the number of units. Dividing each term separately, we get

\[ \begin{aligned} ATC(x) &= \frac{0.5x^2 + 40x + 7200}{x} \\ &= 0.5x + 40 + \frac{7200}{x},\quad x > 0 \end{aligned} \]

2a) The first derivative

The last term is written as a power before it is differentiated: \(\dfrac{7200}{x} = 7200x^{-1}\). The power rule gives

\[ \begin{aligned} ATC'(x) &= 0.5 + 7200\cdot(-1)x^{-2} \\ &= 0.5 - \frac{7200}{x^2} \end{aligned} \]

3a) The critical point

The critical point comes from \(ATC'(x) = 0\). The derivative is a rational function, so it is first written as a single fraction:

\[ ATC'(x) = \frac{0.5x^2 - 7200}{x^2} \]

A fraction is zero only when its numerator is zero and its denominator is not:

\[ \frac{0.5x^2 - 7200}{x^2} = 0 \;\Longleftrightarrow\; \begin{cases} 0.5x^2 - 7200 = 0 \\ x^2 \neq 0 \end{cases} \]
\[ \begin{gathered} 0.5x^2 = 7200 \;\Longrightarrow\; x^2 = 14400 \\ \Longrightarrow\; x = \pm 120 \end{gathered} \]

The denominator is zero only at \(x = 0\), and this value is not a root of the equation. The root \(x = -120\) cannot be a number of units, so it is dropped. So the critical point is \(x = 120\).

4a) The second derivative test

Differentiating \(-7200x^{-2}\) once more, we get

\[ ATC''(x) = -7200\cdot(-2)x^{-3} = \frac{14400}{x^3} \]

so \(ATC''(120) = \dfrac{14400}{120^3} > 0\), and \(x = 120\) is a relative minimum point. So the average cost is smallest at an output of 120 units a day.

5b) The average cost

\[ \begin{aligned} ATC(120) &= 0.5\cdot 120 + 40 + \frac{7200}{120} \\ &= 60 + 40 + 60 = 160 \end{aligned} \]
Answer The average cost is smallest at an output of 120 units a day. It is then 160 euros a unit.
Example 4

The number of workers and profit

Problem A workshop that employs \(x\) workers produces \[ Q(x) = 30\sqrt{x} \] units a day. Each unit is sold for 8 euros, and each worker is paid 24 euros a day.
  1. Find the number of workers that gives the largest profit. Use the second derivative test, if possible.
  2. Find the output and the profit at that number.

1a) The objective function

The revenue is the price of a unit multiplied by the output, and the cost is the wage multiplied by the number of workers:

\[ \begin{aligned} P(x) &= 8\cdot Q(x) - 24x \\ &= 8\cdot 30\sqrt{x} - 24x \\ &= 240\sqrt{x} - 24x,\quad x > 0 \end{aligned} \]

2a) The first derivative

The derivative of the root is \(\left(\sqrt{x}\right)' = \dfrac{1}{2\sqrt{x}}\), so

\[ P'(x) = 240\cdot\frac{1}{2\sqrt{x}} - 24 = \frac{120}{\sqrt{x}} - 24 \]

3a) The critical point

The critical point comes from \(P'(x) = 0\). The derivative is a rational function, so it is first written as a single fraction:

\[ P'(x) = \frac{120 - 24\sqrt{x}}{\sqrt{x}} \]

A fraction is zero only when its numerator is zero and its denominator is not:

\[ \frac{120 - 24\sqrt{x}}{\sqrt{x}} = 0 \;\Longleftrightarrow\; \begin{cases} 120 - 24\sqrt{x} = 0 \\ \sqrt{x} \neq 0 \end{cases} \]
\[ 24\sqrt{x} = 120 \;\Longrightarrow\; \sqrt{x} = 5 \;\Longrightarrow\; x = 25 \]

At this root the denominator is \(\sqrt{25} = 5 \neq 0\), so the critical point is \(x = 25\).

4a) The second derivative test

For the second derivative the root is written as a power: \(\dfrac{120}{\sqrt{x}} = 120x^{-\frac{1}{2}}\). The power rule gives

\[ P''(x) = 120\cdot\left(-\frac{1}{2}\right)x^{-\frac{3}{2}} = -\frac{60}{\sqrt{x^3}} \]

At the critical point \(\sqrt{25^3} = \sqrt{15625} = 125\), so

\[ P''(25) = -\frac{60}{125} = -0.48 < 0 \]

So \(x = 25\) is a relative maximum point, and the profit is largest with 25 workers.

5b) The output and the profit

The output and the profit with 25 workers are

\[ Q(25) = 30\sqrt{25} = 150 \] \[ \begin{aligned} P(25) &= 240\cdot 5 - 24\cdot 25 \\ &= 1200 - 600 = 600 \end{aligned} \]
Answer The profit is largest with 25 workers. The workshop then produces 150 units a day and the profit is 600 euros a day.
Example 5

Revenue with an exponential demand function

Problem The weekly demand function of a product is \[ p = 150e^{-0.004x} \] euros a unit, where \(x\) is the number of units sold.
  1. Find the number of units that gives the largest revenue. Use the second derivative test, if possible.
  2. Find the price and the revenue at that number, to the nearest cent.

1a) The objective function

The revenue is the price multiplied by the number of units sold:

\[ R(x) = p\cdot x = 150x\cdot e^{-0.004x},\qquad x \ge 0 \]

2a) The first derivative

The revenue is a product, so the product rule is used, with \(u(x) = 150x\) and \(v(x) = e^{-0.004x}\). The first factor gives \(u'(x) = 150\). The second factor is a composite exponential function with the inner function \(-0.004x\), so the chain rule is used:

\[ \begin{aligned} v'(x) &= e^{-0.004x}\cdot(-0.004) \\ &= -0.004e^{-0.004x} \end{aligned} \]

Substituting into the product rule \(\big(u(x)\cdot v(x)\big)' = u'(x)\cdot v(x) + u(x)\cdot v'(x)\), we get

\[ \begin{aligned} R'(x) &= 150e^{-0.004x} \\ &\phantom{=}\; + 150x\cdot\left(-0.004e^{-0.004x}\right) \end{aligned} \]

The common factor \(150e^{-0.004x}\) is taken out:

\[ R'(x) = 150e^{-0.004x}(1 - 0.004x) \]

3a) The critical point

The exponential function is positive for every \(x\), so the product is zero only when the bracket is zero:

\[ \begin{gathered} 1 - 0.004x = 0 \;\Longrightarrow\; 0.004x = 1 \\ \Longrightarrow\; x = 250 \end{gathered} \]

4a) The second derivative test

The first derivative is again a product, so the product rule is used once more, with \(u(x) = 150e^{-0.004x}\) and \(v(x) = 1 - 0.004x\). Their derivatives are \(u'(x) = -0.6e^{-0.004x}\) and \(v'(x) = -0.004\). Substituting, we get

\[ \begin{aligned} R''(x) &= -0.6e^{-0.004x}(1 - 0.004x) \\ &\phantom{=}\; + 150e^{-0.004x}\cdot(-0.004) \end{aligned} \]

The second term is \(-0.6e^{-0.004x}\), so the common factor \(-0.6e^{-0.004x}\) is taken out:

\[ \begin{aligned} R''(x) &= -0.6e^{-0.004x}(1 - 0.004x + 1) \\ &= -0.6e^{-0.004x}(2 - 0.004x) \end{aligned} \]

At the critical point \(-0.004\cdot 250 = -1\) and \(2 - 0.004\cdot 250 = 1\), so

\[ R''(250) = -0.6e^{-1}\cdot 1 \approx -0.22 < 0 \]

So \(x = 250\) is a relative maximum point, and the revenue is largest when 250 units a week are sold.

5b) The price and the revenue

The price and the revenue at that number are

\[ p = 150e^{-1} \approx 55.18 \] \[ R(250) = 250\cdot 150e^{-1} \approx 13795.48 \]
Answer The revenue is largest when 250 units a week are sold. The price is then about 55.18 euros a unit and the revenue is about 13795.48 euros a week.
Example 6

Machine hours and profit

Problem A firm that uses \(x\) machine hours a day produces \[ Q(x) = \frac{100x}{x + 10} \] units a day. Each unit is sold for 12 euros, and a machine hour costs 30 euros.
  1. Find the number of machine hours that gives the largest profit. Use the second derivative test, if possible.
  2. Find the output and the profit at that number.

1a) The objective function

The revenue is the price of a unit multiplied by the output, and the cost is the price of a machine hour multiplied by the number of hours:

\[ \begin{aligned} P(x) &= 12\cdot\frac{100x}{x + 10} - 30x \\ &= \frac{1200x}{x + 10} - 30x,\qquad x > 0 \end{aligned} \]

2a) The first derivative

The first term is a quotient. Label the numerator \(u(x) = 1200x\) and the denominator \(v(x) = x + 10\). Then \(u'(x) = 1200\) and \(v'(x) = 1\). By the quotient rule we get

\[ \begin{aligned} \left(\frac{1200x}{x + 10}\right)' &= \frac{1200(x + 10) - 1200x\cdot 1}{(x + 10)^2} \\ &= \frac{1200x + 12000 - 1200x}{(x + 10)^2} \\ &= \frac{12000}{(x + 10)^2} \end{aligned} \]

so the first derivative of the profit is

\[ P'(x) = \frac{12000}{(x + 10)^2} - 30 \]

3a) The critical point

The critical point comes from \(P'(x) = 0\). The derivative is a rational function, so it is first written as a single fraction:

\[ P'(x) = \frac{12000 - 30(x + 10)^2}{(x + 10)^2} \]

A fraction is zero only when its numerator is zero and its denominator is not:

\[ \begin{gathered} \frac{12000 - 30(x + 10)^2}{(x + 10)^2} = 0 \\ \Longleftrightarrow\; \begin{cases} 12000 - 30(x + 10)^2 = 0 \\ (x + 10)^2 \neq 0 \end{cases} \end{gathered} \]
\[ \begin{gathered} 30(x + 10)^2 = 12000 \\ \Longrightarrow\; (x + 10)^2 = 400 \\ \Longrightarrow\; x + 10 = \pm 20 \end{gathered} \]

The denominator is zero only at \(x = -10\), and this value is not a root of the equation. The first root gives \(x = 10\), and the second one gives \(x = -30\). A number of hours cannot be negative, so the second root is dropped.

4a) The second derivative test

For the second derivative the first term is written as a power: \(\dfrac{12000}{(x + 10)^2} = 12000(x + 10)^{-2}\). The power form of the chain rule is used, \(\big((u(x))^n\big)' = n(u(x))^{n-1}\cdot u'(x)\), with the inner function \(u(x) = x + 10\) and \(u'(x) = 1\):

\[ \begin{aligned} P''(x) &= 12000\cdot(-2)(x + 10)^{-3}\cdot 1 \\ &= -\frac{24000}{(x + 10)^3} \end{aligned} \]

At the critical point we get

\[ P''(10) = -\frac{24000}{20^3} = -\frac{24000}{8000} = -3 < 0 \]

so \(x = 10\) is a relative maximum point. So the profit is largest at 10 machine hours a day.

5b) The output and the profit

The output and the profit at 10 machine hours are

\[ Q(10) = \frac{100\cdot 10}{20} = 50 \] \[ \begin{aligned} P(10) &= \frac{1200\cdot 10}{20} - 30\cdot 10 \\ &= 600 - 300 = 300 \end{aligned} \]
Answer The profit is largest at 10 machine hours a day. The firm then produces 50 units a day and the profit is 300 euros a day.

Practice problems

Write the solutions out as in the examples: write the objective function, find the critical point, apply the second derivative test and answer all the questions of the problem. The answer gives the objective function, the critical point and the final results – use them to check your work.

The weekly demand function of a product is

\[ p = -0.05x + 80 \]

euros a unit.

  1. Find the number of units that gives the largest weekly revenue. Use the second derivative test, if possible.
  2. Find the price and the revenue at that number.

The objective function:

\[ R(x) = p\cdot x = -0.05x^2 + 80x \]

The derivative and the critical point:

\[ \begin{gathered} R'(x) = -0.1x + 80 = 0 \\ \Longrightarrow\; x = 800 \end{gathered} \] \[ R''(x) = -0.1 < 0 \]

Answer. The revenue is largest when 800 units a week are sold. The price is then 40 euros a unit and the revenue is 32000 euros a week.

The weekly demand function of a product is \(p = -0.04x + 120\) euros a unit, and the weekly total cost of producing \(x\) units is

\[ TC(x) = 0.02x^2 + 30x + 7000 \]

euros.

  1. Find the output that gives the largest weekly profit. Use the second derivative test, if possible.
  2. Find the price and the profit at that output.

The objective function:

\[ \begin{aligned} P(x) &= R(x) - TC(x) \\ &= -0.06x^2 + 90x - 7000 \end{aligned} \]

The derivative and the critical point:

\[ \begin{gathered} P'(x) = -0.12x + 90 = 0 \\ \Longrightarrow\; x = 750 \end{gathered} \] \[ P''(x) = -0.12 < 0 \]

Answer. The profit is largest at an output of 750 units a week. The price is then 90 euros a unit and the profit is 26750 euros a week.

The daily total cost of producing \(x\) units of a product is

\[ TC(x) = 0.25x^2 + 60x + 4900 \]

euros.

  1. Find the output at which the average cost is smallest. Use the second derivative test, if possible.
  2. Find that average cost.

The objective function:

\[ \begin{aligned} ATC(x) &= \frac{TC(x)}{x} \\ &= 0.25x + 60 + \frac{4900}{x} \end{aligned} \]

Here \(x > 0\).

The derivative and the critical point:

\[ \begin{aligned} ATC'(x) &= 0.25 - \frac{4900}{x^2} \\ &= \frac{0.25x^2 - 4900}{x^2} = 0 \end{aligned} \] \[ \Longrightarrow\; x^2 = 19600 \;\Longrightarrow\; x = 140 \]

The root \(x = -140\) cannot be a number of units, so it is dropped; \(ATC''(x) = \dfrac{9800}{x^3} > 0\).

Answer. The average cost is smallest at an output of 140 units a day. It is then 130 euros a unit.

A workshop that employs \(x\) workers produces \(Q(x) = 80\sqrt{x}\) units a day. Each unit is sold for 6 euros, and each worker is paid 40 euros a day.

  1. Find the number of workers that gives the largest daily profit. Use the second derivative test, if possible.
  2. Find the output and the profit at that number.

The objective function:

\[ \begin{aligned} P(x) &= 6\cdot Q(x) - 40x \\ &= 480\sqrt{x} - 40x,\qquad x > 0 \end{aligned} \]

The derivative and the critical point:

\[ \begin{aligned} P'(x) &= \frac{240}{\sqrt{x}} - 40 \\ &= \frac{240 - 40\sqrt{x}}{\sqrt{x}} = 0 \end{aligned} \] \[ \Longrightarrow\; \sqrt{x} = 6 \;\Longrightarrow\; x = 36 \]

\(P''(x) = -\dfrac{120}{\sqrt{x^3}}\) and \(P''(36) = -\dfrac{120}{216} \approx -0.56 < 0\).

Answer. The profit is largest with 36 workers. The workshop then produces 480 units a day and the profit is 1440 euros a day.
