The Production Function

This section examines how output depends on the inputs used – labour, capital, land or raw materials – and how it changes when the amount of one input changes. The production function is also used to build the revenue, cost and profit functions with respect to the inputs.

The production function

Every firm turns resources into goods or services. A factory uses workers, machines and energy, a farm uses land, labour and fertiliser, a bakery uses bakers, ovens and flour. The resources used in production are called factor inputs, and the relation between the amounts of the inputs and the amount of output is described by a production function.

A production function \(z = f(x;\,y)\) indicates the amount of output that can be produced when \(x\) and \(y\) units of factor inputs are used.

The two inputs most often studied are labour, measured for example in workers or in hours of work, and capital, measured in machines, machine hours or euros invested. Any other resource can be an input as well: raw material, energy, land. A production function may also have three or more inputs, for example \(z = f(x;\,y;\,w)\).

Production functions are built from data, and different forms are used for different processes. The most common form is the Cobb-Douglas production function; polynomial functions, functions that contain other elementary functions, and the CES function are also used.

The Cobb-Douglas production function

The Cobb-Douglas production function is

\[ z = Ax^{\alpha}y^{\beta} \]

where

  • \(A\) is a positive constant representing the state of technology;
  • \(x\) and \(y\) are the amounts of factor inputs;
  • \(z\) is the amount of output;
  • \(\alpha\) and \(\beta\) are the partial elasticities of output with respect to the two inputs.

The exponents are usually positive numbers smaller than 1, for example \(z = 40x^{0.75}y^{0.25}\). The output then grows when either input grows, but more and more slowly. The sum \(\alpha + \beta\) shows what happens when both inputs are increased in the same proportion. If both are multiplied by a number \(k\), the output is multiplied by \(k^{\alpha + \beta}\):

  • if \(\alpha + \beta = 1\), the output grows in the same proportion as the inputs: twice as much labour and capital give twice as much output;
  • if \(\alpha + \beta < 1\), the output grows in a smaller proportion than the inputs;
  • if \(\alpha + \beta > 1\), the output grows in a larger proportion than the inputs.

The graph shows how the surface of the Cobb-Douglas function and its level curves depend on the exponents \(\alpha\) and \(\beta\).

Marginal product

The first order partial derivatives of a production function represent the marginal product with respect to the corresponding input:

  • \(f'_x(x;\,y)\) is the marginal product with respect to the first input;
  • \(f'_y(x;\,y)\) is the marginal product with respect to the second input.

When the inputs are labour and capital, the marginal products are called the marginal product of labour, \(MPL\), and the marginal product of capital, \(MPK\).

The derivative with respect to \(x\) is calculated with \(y\) held constant, so the marginal product with respect to the first input shows how the output changes when only the amount of the first input changes. If \(x\) increases by one unit from \(x_0\) and \(y\) stays equal to \(y_0\), the output changes by approximately \(f'_x(x_0;\,y_0)\) units. In the same way, if \(y\) increases by one unit from \(y_0\) and \(x\) stays equal to \(x_0\), the output changes by approximately \(f'_y(x_0;\,y_0)\) units.

The interpretation

A calculated marginal product has to be explained in the words of the problem, and that explanation is part of the answer. The explanation names the input that changes and says that the amount of the other input does not change:

If the amount of the first input increases by one unit from \(x_0\), while the amount of the second input stays \(y_0\), the output will change by approximately \(f'_x(x_0;\,y_0)\) units.
If the amount of the second input increases by one unit from \(y_0\), while the amount of the first input stays \(x_0\), the output will change by approximately \(f'_y(x_0;\,y_0)\) units.

A positive marginal product means that the output increases, a negative one means that it decreases: there is already so much of that input that one more unit gets in the way.

The marginal products of the Cobb-Douglas function

In the Cobb-Douglas function \(Ay^{\beta}\) is a constant multiplier with respect to \(x\), and \(Ax^{\alpha}\) is a constant multiplier with respect to \(y\). The power rule gives

\[ \begin{aligned} f'_x(x;\,y) &= \alpha Ax^{\alpha - 1}y^{\beta} \\ f'_y(x;\,y) &= \beta Ax^{\alpha}y^{\beta - 1} \end{aligned} \]

When \(\alpha < 1\), the exponent \(\alpha - 1\) is negative, so the marginal product of the first input becomes smaller as more of that input is used, and larger as more of the other input is used. The same holds for the second input when \(\beta < 1\).

How to solve

  1. Write the production function and say what each input means.
  2. Find the partial derivative with respect to each input. Every other input is a constant.
  3. Substitute the given amounts of the inputs.
  4. Interpret each value with the wording of the interpretation.

Revenue, cost and profit from a production function

The production function gives the amount of output. When the price of the output and the prices of the inputs are known, the revenue, the cost and the profit of the firm can be written as functions of the amounts of the inputs. The following notation is used:

  • \(p\) – the price of one unit of output;
  • \(c_1\) – the price of one unit of the first input; \(c_2\) – the price of one unit of the second input;
  • \(FC\) – the fixed cost.

The revenue is the price multiplied by the output, and the output is given by the production function. The cost is the amount paid for the inputs, together with the fixed cost. The profit is the revenue minus the cost:

\[ \begin{aligned} R(x;\,y) &= p\cdot f(x;\,y) \\ TC(x;\,y) &= c_1x + c_2y + FC \\ P(x;\,y) &= p\cdot f(x;\,y) - (c_1x + c_2y + FC) \end{aligned} \]
\[ \begin{aligned} R(x;\,y) &= p\cdot f(x;\,y) \\ TC(x;\,y) &= c_1x + c_2y + FC \\ P(x;\,y) &= p\cdot f(x;\,y) \\ &\phantom{=}\; {}- (c_1x + c_2y + FC) \end{aligned} \]

Marginal values with respect to the inputs

The partial derivatives of these functions show how the revenue, the cost and the profit change when the amount of one input changes. The price \(p\) is a constant multiplier, so

\[ \begin{aligned} R'_x &= p\cdot f'_x; &\qquad TC'_x &= c_1; &\qquad P'_x &= p\cdot f'_x - c_1 \\ R'_y &= p\cdot f'_y; &\qquad TC'_y &= c_2; &\qquad P'_y &= p\cdot f'_y - c_2 \end{aligned} \]
\[ \begin{aligned} R'_x &= p\cdot f'_x \\ R'_y &= p\cdot f'_y \end{aligned} \]\[ \begin{aligned} TC'_x &= c_1 \\ TC'_y &= c_2 \end{aligned} \]\[ \begin{aligned} P'_x &= p\cdot f'_x - c_1 \\ P'_y &= p\cdot f'_y - c_2 \end{aligned} \]

The marginal revenue with respect to an input is the price of the output multiplied by the marginal product of that input: one more unit of the input adds approximately \(f'_x\) units of output, and each of them is sold for \(p\) euros. The marginal cost with respect to an input is its price. The marginal profit is their difference.

The interpretation follows the wording for the marginal product, with the unit changed to euros:

If the amount of the first input increases by one unit from \(x_0\), while the amount of the second input stays \(y_0\), the revenue (cost, profit) will change by approximately \(R'_x(x_0;\,y_0)\) (\(TC'_x(x_0;\,y_0)\), \(P'_x(x_0;\,y_0)\)) euros.
If the amount of the second input increases by one unit from \(y_0\), while the amount of the first input stays \(x_0\), the revenue (cost, profit) will change by approximately \(R'_y(x_0;\,y_0)\) (\(TC'_y(x_0;\,y_0)\), \(P'_y(x_0;\,y_0)\)) euros.

How to solve

  1. Write the production function and name the inputs.
  2. Build the functions that are needed: \(R = p\cdot f(x;\,y)\), \(TC = c_1x + c_2y + FC\), \(P = R - TC\).
  3. Find the partial derivatives with respect to each input.
  4. Substitute the given amounts of the inputs.
  5. Interpret each value with the wording of this card.
!Common mistakes
  • The other input not mentioned in the interpretation. Name the input whose amount changes and say that the amount of the other input does not change.
  • Units confused. The marginal product is measured in units of output, while the marginal revenue, cost and profit are measured in euros.
  • Revenue without the production function. The revenue is the price multiplied by the output, \(p\cdot f(x;\,y)\), not the price multiplied by the amount of an input.
  • The marginal cost with respect to an input. When the cost function is linear, it is the price of one unit of the input, \(c_1\) or \(c_2\).
  • A negative marginal product. It means that there is already so much of that input that one more unit reduces the output.

A polynomial production function

Example 1

Machines and workers in a workshop

Problem The daily output of a workshop is
\[ Q(x;\,y) = 12x + 20y + 0.4xy - 0.3x^2 - 0.5y^2 \]
\[ \begin{aligned} Q(x;\,y) &= 12x + 20y + 0.4xy \\ &\phantom{=}\; {}- 0.3x^2 - 0.5y^2 \end{aligned} \]
units, where \(x\) is the number of machine hours and \(y\) is the number of labour hours used in a day. Find the marginal product with respect to each input when 20 machine hours and 25 labour hours are used, and interpret the results.

1The marginal products

With respect to \(x\), the terms \(20y\) and \(0.5y^2\) are constants and give 0, and in \(0.4xy\) the factor \(0.4y\) is a constant multiplier. With respect to \(y\) the roles change:

\[ \begin{aligned} Q'_x &= 12 + 0.4y - 0.6x \\ Q'_y &= 20 + 0.4x - y \end{aligned} \]

2The values

\[ \begin{aligned} Q'_x(20;\,25) &= 12 + 10 - 12 = 10 \\ Q'_y(20;\,25) &= 20 + 8 - 25 = 3 \end{aligned} \]
Answer

If the number of machine hours increases by one from 20, while the number of labour hours stays 25, the output will increase by approximately 10 units. If the number of labour hours increases by one from 25, while the number of machine hours stays 20, the output will increase by approximately 3 units.

The Cobb-Douglas production function

Example 2

Labour or capital?

Problem The monthly output of a firm is \(Q(x;\,y) = 40x^{0.75}y^{0.25}\) units when \(x\) units of labour and \(y\) units of capital are used. The firm currently uses 81 units of labour and 16 units of capital.
a) Find the marginal product of labour and the marginal product of capital, and interpret the results.
b) Which input should the firm increase if it wants to raise its output more?

1a) The marginal product of labour

With respect to \(x\) the factor \(40y^{0.25}\) is a constant multiplier, and the exponent of \(x\) becomes \(0.75 - 1 = -0.25\):

\[ MPL = Q'_x = 0.75\cdot 40x^{-0.25}y^{0.25} = 30x^{-0.25}y^{0.25} \]
\[ \begin{aligned} MPL = Q'_x &= 0.75\cdot 40x^{-0.25}y^{0.25} \\ &= 30x^{-0.25}y^{0.25} \end{aligned} \]

2a) The marginal product of capital

With respect to \(y\) the factor \(40x^{0.75}\) is a constant multiplier, and the exponent of \(y\) becomes \(0.25 - 1 = -0.75\):

\[ MPK = Q'_y = 0.25\cdot 40x^{0.75}y^{-0.75} = 10x^{0.75}y^{-0.75} \]
\[ \begin{aligned} MPK = Q'_y &= 0.25\cdot 40x^{0.75}y^{-0.75} \\ &= 10x^{0.75}y^{-0.75} \end{aligned} \]

3a) The values

Substituting \(x = 81\) and \(y = 16\):

\[ \begin{aligned} MPL(81;\,16) &= 30\cdot 81^{-0.25}\cdot 16^{0.25} = 20 \\[4pt] MPK(81;\,16) &= 10\cdot 81^{0.75}\cdot 16^{-0.75} = 33.75 \end{aligned} \]

4b) The comparison

The marginal product of capital is larger than the marginal product of labour: \(33.75 > 20\).

Answer

a) If the amount of labour increases by one unit from 81, while the amount of capital stays 16, the output will increase by approximately 20 units. If the amount of capital increases by one unit from 16, while the amount of labour stays 81, the output will increase by approximately 33.75 units.

b) The firm should increase capital, because one more unit of capital adds more output than one more unit of labour.

Example 3

Land, machinery and workers on a farm

Problem The yearly output of a farm is \(Q(x;\,y;\,z) = 2x^{0.5}y^{0.25}z^{0.25}\) tonnes of grain, where \(x\) is the land in hectares, \(y\) is the capital invested in machinery in euros, and \(z\) is the number of workers. Find the marginal product with respect to each input when the farm has 25 hectares of land, 10 000 euros invested in machinery and 16 workers, and interpret the results.

1The marginal products

The function has three inputs, so it has three partial derivatives. In each of them the other two inputs are constants:

\[ \begin{aligned} Q'_x &= 0.5\cdot 2x^{-0.5}y^{0.25}z^{0.25} = x^{-0.5}y^{0.25}z^{0.25} \\[4pt] Q'_y &= 0.25\cdot 2x^{0.5}y^{-0.75}z^{0.25} = 0.5x^{0.5}y^{-0.75}z^{0.25} \\[4pt] Q'_z &= 0.25\cdot 2x^{0.5}y^{0.25}z^{-0.75} = 0.5x^{0.5}y^{0.25}z^{-0.75} \end{aligned} \]
\[ \begin{aligned} Q'_x &= 0.5\cdot 2x^{-0.5}y^{0.25}z^{0.25} \\ &= x^{-0.5}y^{0.25}z^{0.25} \\[6pt] Q'_y &= 0.25\cdot 2x^{0.5}y^{-0.75}z^{0.25} \\ &= 0.5x^{0.5}y^{-0.75}z^{0.25} \\[6pt] Q'_z &= 0.25\cdot 2x^{0.5}y^{0.25}z^{-0.75} \\ &= 0.5x^{0.5}y^{0.25}z^{-0.75} \end{aligned} \]

2The values

Substituting \(x = 25\), \(y = 10\,000\) and \(z = 16\):

\[ \begin{aligned} Q'_x &= 25^{-0.5}\cdot 10\,000^{0.25}\cdot 16^{0.25} = 4 \\[4pt] Q'_y &= 0.5\cdot 25^{0.5}\cdot 10\,000^{-0.75}\cdot 16^{0.25} = 0.005 \\[4pt] Q'_z &= 0.5\cdot 25^{0.5}\cdot 10\,000^{0.25}\cdot 16^{-0.75} = 3.125 \end{aligned} \]
\[ \begin{aligned} Q'_x &= 25^{-0.5}\cdot 10\,000^{0.25}\cdot 16^{0.25} \\ &= 4 \\[6pt] Q'_y &= 0.5\cdot 25^{0.5}\cdot 10\,000^{-0.75}\cdot 16^{0.25} \\ &= 0.005 \\[6pt] Q'_z &= 0.5\cdot 25^{0.5}\cdot 10\,000^{0.25}\cdot 16^{-0.75} \\ &= 3.125 \end{aligned} \]
Answer

If the land increases by one hectare from 25, while the capital and the number of workers do not change, the output will increase by approximately 4 tonnes. If the capital increases by one euro from 10 000, while the land and the number of workers do not change, the output will increase by approximately 0.005 tonnes. If the number of workers increases by one from 16, while the land and the capital do not change, the output will increase by approximately 3.125 tonnes.

Production functions with other elementary functions

Example 4

A printing house

Problem The daily output of a printing house is \[ Q(x;\,y) = \frac{60xy}{x + 2y} \] thousand pages, where \(x\) is the number of labour hours and \(y\) is the number of machine hours used in a day. Find the marginal product with respect to each input when 30 labour hours and 15 machine hours are used, and interpret the results.

1With respect to \(x\)

The denominator contains both variables, so the quotient rule is needed for both derivatives. Label the numerator \(u = 60xy\) and the denominator \(v = x + 2y\). With respect to \(x\): \(u'_x = 60y\) and \(v'_x = 1\), so

\[ \begin{aligned} Q'_x &= \frac{60y(x + 2y) - 60xy\cdot 1}{(x + 2y)^2} \\[6pt] &= \frac{60xy + 120y^2 - 60xy}{(x + 2y)^2} = \frac{120y^2}{(x + 2y)^2} \end{aligned} \]
\[ \begin{aligned} Q'_x &= \frac{60y(x + 2y) - 60xy\cdot 1}{(x + 2y)^2} \\[6pt] &= \frac{60xy + 120y^2 - 60xy}{(x + 2y)^2} \\[6pt] &= \frac{120y^2}{(x + 2y)^2} \end{aligned} \]

2With respect to \(y\)

With respect to \(y\): \(u'_y = 60x\) and \(v'_y = 2\), so

\[ \begin{aligned} Q'_y &= \frac{60x(x + 2y) - 60xy\cdot 2}{(x + 2y)^2} \\[6pt] &= \frac{60x^2 + 120xy - 120xy}{(x + 2y)^2} = \frac{60x^2}{(x + 2y)^2} \end{aligned} \]
\[ \begin{aligned} Q'_y &= \frac{60x(x + 2y) - 60xy\cdot 2}{(x + 2y)^2} \\[6pt] &= \frac{60x^2 + 120xy - 120xy}{(x + 2y)^2} \\[6pt] &= \frac{60x^2}{(x + 2y)^2} \end{aligned} \]

3The values

At the point \((30;\,15)\) the denominator is \((30 + 30)^2 = 3600\):

\[ \begin{aligned} Q'_x(30;\,15) &= \frac{120\cdot 225}{3600} = 7.5 \\[6pt] Q'_y(30;\,15) &= \frac{60\cdot 900}{3600} = 15 \end{aligned} \]
Answer

If the number of labour hours increases by one from 30, while the number of machine hours stays 15, the output will increase by approximately 7.5 thousand pages. If the number of machine hours increases by one from 15, while the number of labour hours stays 30, the output will increase by approximately 15 thousand pages.

Example 5

A laboratory

Problem A laboratory analyses \[ Q(x;\,y) = 50\ln(1 + xy) \] samples a day, where \(x\) is the number of technicians and \(y\) is the number of analysers in use. Find the marginal product with respect to each input when 9 technicians and 11 analysers are working, and interpret the results.

1The marginal products

The function is composite: the outer function is the logarithm and the inner one is \(u = 1 + xy\), with \(u'_x = y\) and \(u'_y = x\). By the rule \(\big(\ln u\big)'_x = \frac{u'_x}{u}\):

\[ Q'_x = \frac{50y}{1 + xy};\qquad Q'_y = \frac{50x}{1 + xy} \]

2The values

At the point \((9;\,11)\) the denominator is \(1 + 9\cdot 11 = 100\):

\[ \begin{aligned} Q'_x(9;\,11) &= \frac{50\cdot 11}{100} = 5.5 \\[6pt] Q'_y(9;\,11) &= \frac{50\cdot 9}{100} = 4.5 \end{aligned} \]
Answer

If the number of technicians increases by one from 9, while the number of analysers stays 11, the number of samples will increase by approximately 5.5 a day. If the number of analysers increases by one from 11, while the number of technicians stays 9, the number of samples will increase by approximately 4.5 a day.

The CES production function

Example 6

Workers and machines in a factory

Problem The weekly output of a factory is given by the CES production function \[ Q(x;\,y) = 30\left[0.25x^{-1} + 0.75y^{-1}\right]^{-1} \] where \(Q\) is measured in units, \(x\) is the number of workers and \(y\) is the number of machines. Find the marginal product of labour and the marginal product of capital when the factory has 10 workers and 30 machines, and interpret the results.

1The structure of the function

The outer function is the power with the exponent \(-1\), and the inner function is the bracket

\[ u = 0.25x^{-1} + 0.75y^{-1} \]

whose partial derivatives are found by the power rule:

\[ u'_x = -0.25x^{-2};\qquad u'_y = -0.75y^{-2} \]

2The marginal products

The power form of the chain rule, \(\big(u^n\big)'_x = nu^{n-1}\cdot u'_x\), is used with \(n = -1\). The bracket is written in place of \(u\), and its partial derivatives in place of \(u'_x\) and \(u'_y\):

\[ \begin{aligned} MPL = Q'_x &= 30\cdot(-1)\left[0.25x^{-1} + 0.75y^{-1}\right]^{-2}\cdot\left(-0.25x^{-2}\right) \\[6pt] &= \frac{7.5}{x^2\left[0.25x^{-1} + 0.75y^{-1}\right]^2} \\[14pt] MPK = Q'_y &= 30\cdot(-1)\left[0.25x^{-1} + 0.75y^{-1}\right]^{-2}\cdot\left(-0.75y^{-2}\right) \\[6pt] &= \frac{22.5}{y^2\left[0.25x^{-1} + 0.75y^{-1}\right]^2} \end{aligned} \]
\[ \begin{aligned} MPL &= Q'_x \\ &= 30\cdot(-1)\left[0.25x^{-1} + 0.75y^{-1}\right]^{-2} \\ &\phantom{=}\;\cdot\left(-0.25x^{-2}\right) \\[6pt] &= \frac{7.5}{x^2\left[0.25x^{-1} + 0.75y^{-1}\right]^2} \\[14pt] MPK &= Q'_y \\ &= 30\cdot(-1)\left[0.25x^{-1} + 0.75y^{-1}\right]^{-2} \\ &\phantom{=}\;\cdot\left(-0.75y^{-2}\right) \\[6pt] &= \frac{22.5}{y^2\left[0.25x^{-1} + 0.75y^{-1}\right]^2} \end{aligned} \]

3The values

At the point \((10;\,30)\) the bracket is

\[ \frac{0.25}{10} + \frac{0.75}{30} = 0.025 + 0.025 = 0.05 \]

This value is substituted into the marginal products:

\[ \begin{aligned} MPL(10;\,30) &= \frac{7.5}{10^2\cdot 0.05^2} = \frac{7.5}{0.25} = 30 \\[8pt] MPK(10;\,30) &= \frac{22.5}{30^2\cdot 0.05^2} = \frac{22.5}{2.25} = 10 \end{aligned} \]
\[ \begin{aligned} MPL(10;\,30) &= \frac{7.5}{10^2\cdot 0.05^2} \\[6pt] &= \frac{7.5}{0.25} = 30 \\[8pt] MPK(10;\,30) &= \frac{22.5}{30^2\cdot 0.05^2} \\[6pt] &= \frac{22.5}{2.25} = 10 \end{aligned} \]
Answer

If the number of workers increases by one from 10, while the number of machines stays 30, the output will increase by approximately 30 units a week. If the number of machines increases by one from 30, while the number of workers stays 10, the output will increase by approximately 10 units a week.

Revenue, cost and profit

Example 7

The revenue, cost and profit of a workshop

Problem A workshop produces \(Q(x;\,y) = 12\sqrt{xy}\) units a day, where \(x\) is the number of labour hours and \(y\) is the number of machine hours. Each unit is sold for 5 euros, a labour hour costs 12 euros, a machine hour costs 40 euros, and the fixed costs are 300 euros a day. Find the marginal revenue, the marginal cost and the marginal profit with respect to each input when 64 labour hours and 16 machine hours are used, and interpret the results.

1The functions

The production function is a Cobb-Douglas function, \(Q = 12x^{0.5}y^{0.5}\). Therefore

\[ \begin{aligned} R(x;\,y) &= 5\cdot 12x^{0.5}y^{0.5} = 60x^{0.5}y^{0.5} \\ TC(x;\,y) &= 12x + 40y + 300 \\ P(x;\,y) &= 60x^{0.5}y^{0.5} - 12x - 40y - 300 \end{aligned} \]

2The marginal revenue

With respect to \(x\) the factor \(60y^{0.5}\) is a constant multiplier, and with respect to \(y\) the factor \(60x^{0.5}\):

\[ \begin{aligned} R'_x &= 30x^{-0.5}y^{0.5} = \frac{30\sqrt{y}}{\sqrt{x}} \\[6pt] R'_y &= 30x^{0.5}y^{-0.5} = \frac{30\sqrt{x}}{\sqrt{y}} \end{aligned} \] \[ \begin{aligned} R'_x(64;\,16) &= \frac{30\cdot 4}{8} = 15 \\[6pt] R'_y(64;\,16) &= \frac{30\cdot 8}{4} = 60 \end{aligned} \]

3The marginal cost

The cost is linear, so the marginal costs are the prices of the inputs:

\[ TC'_x = 12;\qquad TC'_y = 40 \]

4The marginal profit

By the formulas for the marginal values with respect to the inputs it is the difference of the marginal revenue and the marginal cost:

\[ \begin{aligned} P'_x(64;\,16) &= 15 - 12 = 3 \\ P'_y(64;\,16) &= 60 - 40 = 20 \end{aligned} \]
Answer

If the number of labour hours increases by one from 64, while the number of machine hours stays 16, the revenue will increase by approximately 15 euros, the cost by 12 euros and the profit by approximately 3 euros. If the number of machine hours increases by one from 16, while the number of labour hours stays 64, the revenue will increase by approximately 60 euros, the cost by 40 euros and the profit by approximately 20 euros.

Example 8

The marginal profit of a factory

Problem The daily output of a factory is
\[ Q(x;\,y) = 30x + 40y + 0.2xy - 0.5x^2 - 0.4y^2 \]
\[ \begin{aligned} Q(x;\,y) &= 30x + 40y + 0.2xy \\ &\phantom{=}\; {}- 0.5x^2 - 0.4y^2 \end{aligned} \]
units, where \(x\) is the number of workers and \(y\) is the number of machines in use. Each unit is sold for 8 euros, a worker costs 60 euros a day, a machine costs 100 euros a day, and the fixed costs are 400 euros a day. Find the marginal profit with respect to each input when 20 workers and 40 machines are used, and interpret the results.

1The profit function

The revenue is \(8\cdot Q(x;\,y)\) and the cost is \(60x + 100y + 400\), so

\[ \begin{aligned} P(x;\,y) &= 8(30x + 40y + 0.2xy - 0.5x^2 - 0.4y^2) - 60x - 100y - 400 \\ &= 180x + 220y + 1.6xy - 4x^2 - 3.2y^2 - 400 \end{aligned} \]
\[ \begin{aligned} P(x;\,y) &= 8(30x + 40y + 0.2xy \\ &\phantom{=}\; {}- 0.5x^2 - 0.4y^2) \\ &\phantom{=}\; {}- 60x - 100y - 400 \\ &= 180x + 220y + 1.6xy \\ &\phantom{=}\; {}- 4x^2 - 3.2y^2 - 400 \end{aligned} \]

2The marginal profit

\[ \begin{aligned} P'_x &= 180 + 1.6y - 8x \\ P'_y &= 220 + 1.6x - 6.4y \end{aligned} \] \[ \begin{aligned} P'_x(20;\,40) &= 180 + 64 - 160 = 84 \\ P'_y(20;\,40) &= 220 + 32 - 256 = -4 \end{aligned} \]

3The check

The same values follow from the formulas for the marginal values with respect to the inputs: the marginal products are \(Q'_x = 30 + 0.2y - x = 18\) and \(Q'_y = 40 + 0.2x - 0.8y = 12\), so \(P'_x = 8\cdot 18 - 60 = 84\) and \(P'_y = 8\cdot 12 - 100 = -4\).

Answer

If the number of workers increases by one from 20, while the number of machines stays 40, the profit will increase by approximately 84 euros. If the number of machines increases by one from 40, while the number of workers stays 20, the profit will decrease by approximately 4 euros.

Example 9

Greenhouse tomatoes

Problem A greenhouse produces \[ Q(x;\,y) = 400\sqrt{x}\left(1 - e^{-0.05y}\right) \] kilograms of tomatoes a week, where \(x\) is the number of labour hours and \(y\) is the amount of fertiliser in kilograms. The tomatoes are sold for 3 euros a kilogram, a labour hour costs 18 euros, a kilogram of fertiliser costs 2 euros, and the fixed costs are 1500 euros a week. Find the marginal profit with respect to each input when 100 labour hours and 20 kilograms of fertiliser are used, and interpret the results.

1The profit function

\[ \begin{aligned} P(x;\,y) &= 3\cdot 400\sqrt{x}\left(1 - e^{-0.05y}\right) - 18x - 2y - 1500 \\ &= 1200\sqrt{x}\left(1 - e^{-0.05y}\right) - 18x - 2y - 1500 \end{aligned} \]
\[ \begin{aligned} P(x;\,y) &= 3\cdot 400\sqrt{x}\left(1 - e^{-0.05y}\right) \\ &\phantom{=}\; {}- 18x - 2y - 1500 \\ &= 1200\sqrt{x}\left(1 - e^{-0.05y}\right) \\ &\phantom{=}\; {}- 18x - 2y - 1500 \end{aligned} \]

2With respect to \(x\)

The bracket does not contain \(x\), so it is a constant multiplier, and \(\left(\sqrt{x}\right)'_x = \frac{1}{2\sqrt{x}}\):

\[ \begin{aligned} P'_x &= 1200\cdot\frac{1}{2\sqrt{x}}\left(1 - e^{-0.05y}\right) - 18 \\[6pt] &= \frac{600\left(1 - e^{-0.05y}\right)}{\sqrt{x}} - 18 \end{aligned} \]

3With respect to \(y\)

The factor \(1200\sqrt{x}\) is a constant multiplier. The exponential function is composite with the inner function \(-0.05y\), so \(\left(e^{-0.05y}\right)'_y = -0.05e^{-0.05y}\) and the derivative of the bracket is \(0.05e^{-0.05y}\):

\[ \begin{aligned} P'_y &= 1200\sqrt{x}\cdot 0.05e^{-0.05y} - 2 \\ &= 60\sqrt{x}\cdot e^{-0.05y} - 2 \end{aligned} \]

4The values

At the point \((100;\,20)\) the values are \(\sqrt{100} = 10\) and \(e^{-0.05\cdot 20} = e^{-1} \approx 0.3679\):

\[ \begin{aligned} P'_x(100;\,20) &= \frac{600\left(1 - e^{-1}\right)}{10} - 18 = 60\left(1 - e^{-1}\right) - 18 \approx 19.93 \\[8pt] P'_y(100;\,20) &= 60\cdot 10\cdot e^{-1} - 2 = 600e^{-1} - 2 \approx 218.73 \end{aligned} \]
\[ \begin{aligned} P'_x(100;\,20) &= \frac{600\left(1 - e^{-1}\right)}{10} - 18 \\[6pt] &= 60\left(1 - e^{-1}\right) - 18 \approx 19.93 \\[8pt] P'_y(100;\,20) &= 60\cdot 10\cdot e^{-1} - 2 \\ &= 600e^{-1} - 2 \approx 218.73 \end{aligned} \]
Answer

If the number of labour hours increases by one from 100, while the amount of fertiliser stays 20 kilograms, the profit will increase by approximately 19.93 euros. If the amount of fertiliser increases by one kilogram from 20, while the number of labour hours stays 100, the profit will increase by approximately 218.73 euros.

A logistics centre handles

\[ Q(x;\,y) = 50x^{0.8}y^{0.2} \]

parcels a week, where \(x\) is the number of hours of labour and \(y\) is the capital invested in equipment, in thousands of euros. Find the marginal product of labour and the marginal product of capital when 1024 hours of labour and 32 thousand euros of capital are used, and interpret the results.

The derivatives:

\[ \begin{aligned} MPL = Q'_x &= 40x^{-0.2}y^{0.2} \\ MPK = Q'_y &= 10x^{0.8}y^{-0.8} \end{aligned} \]

The values:

\[ \begin{aligned} MPL(1024;\,32) &= 40\cdot 1024^{-0.2}\cdot 32^{0.2} = 20 \\[4pt] MPK(1024;\,32) &= 10\cdot 1024^{0.8}\cdot 32^{-0.8} = 160 \end{aligned} \]
\[ \begin{aligned} MPL(1024;\,32) &= 40\cdot 1024^{-0.2}\cdot 32^{0.2} \\ &= 20 \\[6pt] MPK(1024;\,32) &= 10\cdot 1024^{0.8}\cdot 32^{-0.8} \\ &= 160 \end{aligned} \]

Answer. If the labour increases by one hour from 1024, while the capital stays 32 thousand euros, the centre will handle approximately 20 more parcels a week. If the capital increases by one thousand euros from 32, while the labour stays 1024 hours, it will handle approximately 160 more parcels a week.

A car wash with \(x\) workers and \(y\) washing lines serves

\[ Q(x;\,y) = 12x + 15y + 0.3xy - 0.4x^2 - 0.5y^2 \]
\[ \begin{aligned} Q(x;\,y) &= 12x + 15y + 0.3xy \\ &\phantom{=}\; {}- 0.4x^2 - 0.5y^2 \end{aligned} \]

cars a day. Find the marginal products when 20 workers and 6 washing lines are used, and interpret the results.

The derivatives:

\[ \begin{aligned} Q'_x &= 12 + 0.3y - 0.8x \\ Q'_y &= 15 + 0.3x - y \end{aligned} \]

The values:

\[ \begin{aligned} Q'_x(20;\,6) &= 12 + 1.8 - 16 = -2.2 \\ Q'_y(20;\,6) &= 15 + 6 - 6 = 15 \end{aligned} \]

Answer. If the number of workers increases by one from 20, while the number of washing lines stays 6, the number of cars served will decrease by approximately 2.2 a day. If the number of washing lines increases by one from 6, while the number of workers stays 20, the number of cars served will increase by approximately 15 a day.

A recycling plant with \(x\) workers and \(y\) sorting machines processes

\[ Q(x;\,y) = 400\left(1 - e^{-0.01xy}\right) \]

tonnes of waste a day. Find the marginal products when 10 workers and 20 machines are used, and interpret the results.

The derivatives (the chain rule):

\[ \begin{aligned} Q'_x &= 4ye^{-0.01xy} \\ Q'_y &= 4xe^{-0.01xy} \end{aligned} \]

The values:

\[ \begin{aligned} Q'_x(10;\,20) &= 80e^{-2} \approx 10.83 \\ Q'_y(10;\,20) &= 40e^{-2} \approx 5.41 \end{aligned} \]

Answer. If the number of workers increases by one from 10, while the number of machines stays 20, the plant will process approximately 10.83 more tonnes a day. If the number of machines increases by one from 20, while the number of workers stays 10, it will process approximately 5.41 more tonnes a day.

A pottery workshop makes

\[ Q(x;\,y) = 20x^{0.25}y^{0.75} \]

mugs a week, where \(x\) is the number of hours of potters’ work and \(y\) is the number of hours the kiln is used. A mug is sold for 2 euros, an hour of potters’ work costs 30 euros, an hour of the kiln costs 12 euros, and the fixed cost is 400 euros a week.

Find the profit function and the marginal profits with respect to both inputs when 16 hours of work and 81 hours of the kiln are used. Interpret the results.

The function:

\[ \begin{aligned} P(x;\,y) &= 2\cdot 20x^{0.25}y^{0.75} - (30x + 12y + 400) \\ &= 40x^{0.25}y^{0.75} - 30x - 12y - 400 \end{aligned} \]
\[ \begin{aligned} P(x;\,y) &= 2\cdot 20x^{0.25}y^{0.75} \\ &\phantom{=}\; {}- (30x + 12y + 400) \\ &= 40x^{0.25}y^{0.75} \\ &\phantom{=}\; {}- 30x - 12y - 400 \end{aligned} \]

The derivatives and the values:

\[ \begin{aligned} P'_x &= 10x^{-0.75}y^{0.75} - 30 \\ P'_y &= 30x^{0.25}y^{-0.25} - 12 \end{aligned} \]
\[ \begin{aligned} P'_x(16;\,81) &= 10\cdot 16^{-0.75}\cdot 81^{0.75} - 30 = 3.75 \\[4pt] P'_y(16;\,81) &= 30\cdot 16^{0.25}\cdot 81^{-0.25} - 12 = 8 \end{aligned} \]
\[ \begin{aligned} P'_x(16;\,81) &= 10\cdot 16^{-0.75}\cdot 81^{0.75} - 30 \\ &= 3.75 \\[6pt] P'_y(16;\,81) &= 30\cdot 16^{0.25}\cdot 81^{-0.25} - 12 \\ &= 8 \end{aligned} \]

Answer. If the potters’ work increases by one hour from 16, while the kiln is used 81 hours, the weekly profit will increase by approximately 3.75 euros. If the use of the kiln increases by one hour from 81, while the potters’ work stays 16 hours, the profit will increase by approximately 8 euros.
