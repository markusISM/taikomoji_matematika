Linear Depreciation

Straight-line depreciation assumes that the asset loses the same amount of value in every period, so its is a falling straight line.

  • Model
  • Examples
  • Check yourself

The model

What data are used

  • \(V(0)\)the original value of the asset;
  • \(V(T)\)the residual / scrap value of the asset;
  • \(T\)the useful life of the asset;
  • \(V(t)\)the book value of the asset at the end of year \(t\).

In the reverse variant the original value is not known. Instead, two book values at two moments are given – two points \((t_1;\,V_1)\) and \((t_2;\,V_2)\).

What is computed

Depreciation rate (a positive number, in euros per period)

\[ D = \frac{V(0) - V(T)}{T} \]

Value function – the with \(m = -D\) and \(b = V(0)\)

\[ \begin{gathered} V(t) = V(0) - \frac{V(0) - V(T)}{T}\cdot t, \\ 0 \le t \le T \end{gathered} \]
?Why \(m = -D\)?

The value of the asset decreases, so the line falls and its is negative. The depreciation rate \(D\), however, is written as a positive number – the amount by which the value falls in one period. Therefore \(m = -D\).

?Why \(b = V(0)\)?

The equals the value of the function at \(t = 0\). At the start the asset has its original value, i.e. the point \((0;\,V(0))\) lies on the line, so immediately \(b = V(0)\).

How to solve

  1. Write down what is given: \(V(0)\), \(V(T)\), \(T\). In the reverse variant – two book values at two moments, as two points \((t_1;\,V_1)\) and \((t_2;\,V_2)\).
  2. Find the slope: \(m = -D = -\dfrac{V(0) - V(T)}{T}\). In the reverse variant: \(m = \dfrac{V_2 - V_1}{t_2 - t_1}\), and \(D = -m\).
  3. Find the intercept. When the original value is given, the point \((0;\,V(0))\) gives \(b = V(0)\) immediately. In the reverse variant: \(b = -m t_1 + V_1\).
  4. Write \(V(t) = V(0) - D\cdot t\) and state the \(0 \le t \le T\).
  5. Answer the question. A book value – substitute \(t\). A moment in time – solve \(V(t) = A\) or the inequality \(V(t) < A\).
!Common mistakes
  • The inequality sign. When dividing an inequality by a negative number, reverse the inequality sign.
  • The end of the year. The book value of an asset is recorded at the end of the year. If you get \(t > 5.43\), the value first falls below the given amount at the end of the sixth year, not the fifth.
  • Signs. The depreciation rate \(D\) is a positive number, while the slope of the line \(m = -D\) is negative.
What you must write in the exam
  1. When constructing a linear model (for example, a model of linear depreciation, a profit function, or break-even analysis), it is required to state what data are given in the problem.
  2. When introducing new variables not specified in lectures or the problem, or when changing measurement units, this must be explicitly written in the solution.
  3. If the problem includes several questions, answers to all of them must be clearly presented.

Worked examples

Try to solve the problem yourself first, then reveal the solution one step at a time.

Example 1

Dough mixer

Problem A commercial dough mixer has an original value of 24000 EUR and is to be depreciated linearly over 8 years with a 4000 EUR scrap value. What is the rate of depreciation of the mixer? Find an expression giving the book value at the end of year \(t\). What will be the book value of the mixer at the end of the third year?

1The given data

Initial value: \(V(0) = 24000\).
: \(T = 8\).
: \(V(8) = 4000\).

2The depreciation rate

\[ \begin{aligned} D &= \frac{V(0) - V(T)}{T} = \frac{24000 - 4000}{8} \\ &= \frac{20000}{8} = 2500 \end{aligned} \]

The mixer loses 2500 euros of its value every year.

3The book value at the end of year \(t\)

\[ \begin{aligned} V(t) &= V(0) - \frac{V(0) - V(T)}{T}\cdot t \\ &= 24000 - 2500t, \quad 0 \le t \le 8 \end{aligned} \]

4The book value at the end of the third year

\[ \begin{aligned} V(3) &= 24000 - 2500\cdot 3 \\ &= 24000 - 7500 = 16500 \end{aligned} \]
Answer The rate of depreciation is 2500 euros per year; the book value at the end of year \(t\) is \(V(t) = 24000 - 2500t\); at the end of the third year the mixer is worth 16500 euros.
Example 2

Delivery van

Problem A delivery van purchased at a cost of 34000 euros is depreciated linearly over 8 years, with a scrap value of 6000 euros. Find the rate of linear depreciation and the book value at the end of year \(t\). Find the book value at the end of the fifth year. At the end of which year does the book value first fall below 15000 euros?

1The given data

Initial value: \(V(0) = 34000\).
Expected usage time: \(T = 8\).
Residual value: \(V(8) = 6000\).

2The depreciation rate

\[ D = \frac{34000 - 6000}{8} = \frac{28000}{8} = 3500 \]

3The intercept is the original value

\[ b = V(0) = 34000 \]

4The value function

\[ V(t) = -3500t + 34000, \quad 0 \le t \le 8 \]

5The value at the end of the fifth year

\[ \begin{aligned} V(5) &= -3500\cdot 5 + 34000 \\ &= 16500 \text{ EUR} \end{aligned} \]

6When does the value fall below 15000 EUR?

Solve the inequality; dividing by \(-3500\) reverses the sign:

\[ \begin{aligned} &{-}3500t + 34000 < 15000 \\ \Longrightarrow\;& {-}3500t < -19000 \\ \Longrightarrow\;& t > \frac{19000}{3500} \approx 5.43 \end{aligned} \]

Book values are recorded at year ends, so the first one below 15000 EUR is \(V(6) = -21000 + 34000 = 13000\) EUR, while \(V(5) = 16500\) EUR is still above.

Answer 3500 EUR per year; \(V(t) = -3500t + 34000\) EUR, \(0 \le t \le 8\); 16500 EUR at the end of the fifth year; the book value first falls below 15000 EUR at the end of the sixth year.
Example 3 · Reverse problem

Machine

Problem A machine is depreciated by the straight-line method. Its book value at the end of the third year is 46000 euros and at the end of the seventh year 26000 euros. Find the annual rate of depreciation, the original value of the machine and the depreciation equation. If the useful life is 10 years, what is the scrap value?

1Two points of the line

The original value is not given, so the line is built from the two points \((3;\,46000)\) and \((7;\,26000)\).

2The slope and the rate

\[ \begin{aligned} m &= \frac{26000 - 46000}{7 - 3} \\ &= \frac{-20000}{4} = -5000 \\ D &= 5000 \end{aligned} \]

3The intercept, using the point \((3;\,46000)\)

\[ \begin{aligned} b &= -m t_1 + V_1 = -(-5000)\cdot 3 + 46000 \\ &= 15000 + 46000 = 61000 \end{aligned} \]

4The value function

\[ V(t) = -5000t + 61000 \]

5The scrap value with \(T = 10\)

Domain: \(0 \le t \le 10\).

\[ V(10) = -5000\cdot 10 + 61000 = 11000 \]
Answer The rate is 5000 EUR per year, the original value is 61000 EUR, \(V(t) = -5000t + 61000\) EUR, \(0 \le t \le 10\), and the scrap value after 10 years is 11000 EUR.

Check yourself

In the linear depreciation model \(V(t) = V(0) - D\cdot t\), what does the coefficient \(D\) represent?

  1. The book value after one year.
  2. The annual depreciation rate – the amount the asset loses in value each year.
  3. The residual value.
  4. The number of years of use.

A print shop buys a laminator for 6000 €. It is expected to last 4 years, with a residual value of 800 €. What is the annual depreciation rate \(D\)?

  1. 1300 €
  2. 1450 €
  3. 800 €
  4. 1500 €
\[ D = \frac{6000 - 800}{4} = 1300 \]

An office equipment item is purchased for 52000 EUR and depreciated linearly over 8 years to a residual value of 4000 EUR. Determine the book value at the end of year 3. Enter the value in EUR, as a whole number.

34000

The book value of a CNC machine was 52000 € after 3 years and 28000 € after 9 years. Depreciation is calculated by the straight-line method. Find the original value of the machine.

64000 EUR
