The Quotient Rule

In this section you will find examples of calculating partial derivatives with the quotient rule, together with practice problems. Try to solve each problem yourself first, then reveal the solution one step at a time.

  • Examples
  • Practice

The rules used

The quotient rule of Topic 6 is used as it is, with every derivative taken with respect to the chosen variable:

\[ \begin{aligned} \left(\frac{u}{v}\right)'_x &= \frac{u'_x\cdot v - u\cdot v'_x}{v^2} \\[12pt] \left(\frac{u}{v}\right)'_y &= \frac{u'_y\cdot v - u\cdot v'_y}{v^2} \end{aligned} \]

Label the numerator \(u\) and the denominator \(v\). Before the rule is used, it is worth checking that it is really needed, because a letter that is held constant often turns a fraction into a simple constant multiplier.

1The denominator depends on the variable

The quotient rule is needed with respect to a variable only if the denominator contains that variable.

2The denominator does not depend on the variable

Otherwise the denominator is a constant. The fraction can be written as a constant multiplied by a power, as in Example 3 of Section 1.

The quotient rule is explained in the quotient rule card on the Topic 6 page, and the steps of calculating partial derivatives are given in the card “The steps of the calculation” on the Topic 8 page.

Examples

Example 1

The quotient of two linear expressions

Problem Find the first order partial derivatives of the function \(z = \dfrac{2x + y}{x - 3y}\).

1The numerator and the denominator

The denominator contains both \(x\) and \(y\), so the quotient rule is needed for each derivative. Let

\[ u = 2x + y;\qquad v = x - 3y \]

2With respect to \(x\)

The numerator and the denominator give \(u'_x = 2\) and \(v'_x = 1\):

\[ \begin{aligned} z'_x &= \frac{2(x - 3y) - (2x + y)\cdot 1}{(x - 3y)^2} \\[6pt] &= \frac{2x - 6y - 2x - y}{(x - 3y)^2} = -\frac{7y}{(x - 3y)^2} \end{aligned} \]

3With respect to \(y\)

The numerator and the denominator give \(u'_y = 1\) and \(v'_y = -3\):

\[ \begin{aligned} z'_y &= \frac{1\cdot(x - 3y) - (2x + y)\cdot(-3)}{(x - 3y)^2} \\[6pt] &= \frac{x - 3y + 6x + 3y}{(x - 3y)^2} = \frac{7x}{(x - 3y)^2} \end{aligned} \]
Answer \[ \begin{aligned} z'_x &= -\frac{7y}{(x - 3y)^2} \\[10pt] z'_y &= \frac{7x}{(x - 3y)^2} \end{aligned} \]
Example 2

A product in the numerator, a sum of squares in the denominator

Problem Find the first order partial derivatives of the function \(z = \dfrac{xy}{x^2 + y^2}\).

1The numerator and the denominator

Let

\[ u = xy;\qquad v = x^2 + y^2 \]

2With respect to \(x\)

In the numerator \(y\) is a constant multiplier, so \(u'_x = y\); in the denominator \(y^2\) is a constant term, so \(v'_x = 2x\):

\[ \begin{aligned} z'_x &= \frac{y(x^2 + y^2) - xy\cdot 2x}{(x^2 + y^2)^2} \\[6pt] &= \frac{x^2y + y^3 - 2x^2y}{(x^2 + y^2)^2} \\[6pt] &= \frac{y^3 - x^2y}{(x^2 + y^2)^2} \end{aligned} \]

3With respect to \(y\)

In the same way \(u'_y = x\) and \(v'_y = 2y\):

\[ \begin{aligned} z'_y &= \frac{x(x^2 + y^2) - xy\cdot 2y}{(x^2 + y^2)^2} \\[6pt] &= \frac{x^3 + xy^2 - 2xy^2}{(x^2 + y^2)^2} \\[6pt] &= \frac{x^3 - xy^2}{(x^2 + y^2)^2} \end{aligned} \]
Answer \[ \begin{aligned} z'_x &= \frac{y^3 - x^2y}{(x^2 + y^2)^2} \\[10pt] z'_y &= \frac{x^3 - xy^2}{(x^2 + y^2)^2} \end{aligned} \]

Practice problems

Write the solutions out as in the examples: for each variable check whether the denominator depends on it, find the derivatives of the numerator and the denominator, apply the quotient rule and simplify the numerator. Then check your answer.

Find the first order partial derivatives of the function \(z = \dfrac{3x - y}{x + 4y}\).

\(z'_x = \dfrac{13y}{(x + 4y)^2}\);   \(z'_y = -\dfrac{13x}{(x + 4y)^2}\)

Find the first order partial derivatives of the function \(z = \dfrac{x^2}{x + y}\).

\(z'_x = \dfrac{x^2 + 2xy}{(x + y)^2}\);   \(z'_y = -\dfrac{x^2}{(x + y)^2}\)

Find the first order partial derivatives of the function \(z = \dfrac{y}{x^2 + y^2}\).

\(z'_x = -\dfrac{2xy}{(x^2 + y^2)^2}\);   \(z'_y = \dfrac{x^2 - y^2}{(x^2 + y^2)^2}\)

Find the first order partial derivatives of the function \(z = \dfrac{x^2 - 2y^2}{x^2 + y^2}\).

\(z'_x = \dfrac{6xy^2}{(x^2 + y^2)^2}\);   \(z'_y = -\dfrac{6x^2y}{(x^2 + y^2)^2}\)

Find the first order partial derivatives of the function \(z = \dfrac{e^x}{x + y}\).

\(z'_x = \dfrac{e^x(x + y - 1)}{(x + y)^2}\);   \(z'_y = -\dfrac{e^x}{(x + y)^2}\)

Find the values of the first order partial derivatives of the function \(f(x;\,y) = \dfrac{x}{x + 2y}\) at the point \((2;\,1)\).

\(f'_x(x;\,y) = \dfrac{2y}{(x + 2y)^2}\);   \(f'_y(x;\,y) = -\dfrac{2x}{(x + 2y)^2}\)

\(f'_x(2;\,1) = 0.125\);   \(f'_y(2;\,1) = -0.25\)
