The rules used

A composite function has an inner function inside an outer one: \(z = g(u)\), where \(u = u(x;\,y)\). The outer function \(g\) is differentiated as in Topic 6, and the result is multiplied by the partial derivative of the inner function:

\[ \begin{aligned} z'_x &= g'(u)\cdot u'_x \\ z'_y &= g'(u)\cdot u'_y \end{aligned} \]

The derivative of the outer function is the same in both formulas. Only the last factor, the partial derivative of the inner function, depends on the variable that was chosen. The formulas used most often:

1A power and a root
  • \(\big(u^n\big)'_x = nu^{n-1}\cdot u'_x\)
  • \(\left(\sqrt{u}\right)'_x = \dfrac{u'_x}{2\sqrt{u}}\)
2The exponential and the logarithmic function
  • \(\left(e^u\right)'_x = e^u\cdot u'_x\)
  • \(\big(\ln u\big)'_x = \dfrac{u'_x}{u}\)

The same four formulas hold with \(y\) in place of \(x\). Sometimes one function needs several rules, for example the product rule and the chain rule (Example 4).

The chain rule is explained in the chain rule card on the Topic 6 page, and the steps of calculating partial derivatives are given in the card “The steps of the calculation” on the Topic 8 page.

Examples

Example 1

A composite power function

Problem Find the first order partial derivatives of the function \(z = (x^2 + 3y)^5\).

1The outer and the inner function

The outer function is the fifth power, \(g(u) = u^5\), and the inner function is \(u = x^2 + 3y\). By the power form of the chain rule the outer function gives \(5(x^2 + 3y)^4\) in both derivatives, and this is multiplied by the partial derivative of the inner function.

2With respect to \(x\)

The inner function gives \(u'_x = 2x\):

\[ z'_x = 5(x^2 + 3y)^4\cdot 2x = 10x(x^2 + 3y)^4 \]

3With respect to \(y\)

The inner function gives \(u'_y = 3\):

\[ z'_y = 5(x^2 + 3y)^4\cdot 3 = 15(x^2 + 3y)^4 \]
Answer \[ \begin{aligned} z'_x &= 10x(x^2 + 3y)^4 \\ z'_y &= 15(x^2 + 3y)^4 \end{aligned} \]
Example 2

A composite exponential function

Problem Find the first order partial derivatives of the function \(z = e^{x^3 - 2xy}\).

1The outer and the inner function

The outer function is the exponential function, \(g(u) = e^u\), and the inner function is \(u = x^3 - 2xy\). The exponential function is its own derivative, so the outer function gives \(e^{x^3 - 2xy}\) in both derivatives. The inner function gives

\[ u'_x = 3x^2 - 2y;\qquad u'_y = -2x \]

2The partial derivatives

By the rule \(\left(e^u\right)'_x = e^u\cdot u'_x\) and the same rule for \(y\):

\[ \begin{aligned} z'_x &= e^{x^3 - 2xy}\cdot(3x^2 - 2y) \\ &= (3x^2 - 2y)e^{x^3 - 2xy} \\[6pt] z'_y &= e^{x^3 - 2xy}\cdot(-2x) = -2xe^{x^3 - 2xy} \end{aligned} \]
Answer \[ \begin{aligned} z'_x &= (3x^2 - 2y)e^{x^3 - 2xy} \\ z'_y &= -2xe^{x^3 - 2xy} \end{aligned} \]
Example 3

A logarithm and a square root

Problem Find the first order partial derivatives of the functions: a) \(z = \ln(x^2 + 5y)\); b) \(z = \sqrt{4x + y^2}\).

1a) The logarithm

The outer function is the logarithm and the inner function is \(u = x^2 + 5y\), with \(u'_x = 2x\) and \(u'_y = 5\). By the rule \(\big(\ln u\big)'_x = \frac{u'_x}{u}\):

\[ \begin{aligned} z'_x &= \frac{2x}{x^2 + 5y} \\[8pt] z'_y &= \frac{5}{x^2 + 5y} \end{aligned} \]

2b) The square root

The outer function is the square root and the inner function is \(u = 4x + y^2\), with \(u'_x = 4\) and \(u'_y = 2y\). By the rule \(\left(\sqrt{u}\right)'_x = \frac{u'_x}{2\sqrt{u}}\):

\[ \begin{aligned} z'_x &= \frac{4}{2\sqrt{4x + y^2}} = \frac{2}{\sqrt{4x + y^2}} \\[12pt] z'_y &= \frac{2y}{2\sqrt{4x + y^2}} = \frac{y}{\sqrt{4x + y^2}} \end{aligned} \]
Answer \[ \begin{aligned} \text{a)}\quad z'_x &= \frac{2x}{x^2 + 5y} \\[8pt] z'_y &= \frac{5}{x^2 + 5y} \\[16pt] \text{b)}\quad z'_x &= \frac{2}{\sqrt{4x + y^2}} \\[8pt] z'_y &= \frac{y}{\sqrt{4x + y^2}} \end{aligned} \]
Example 4

The product rule and the chain rule together

Problem Find the first order partial derivatives of the function \(z = x\cdot e^{xy}\).

1With respect to \(x\): the derivatives of the factors

This function needs two rules at once. Both factors, \(x\) and \(e^{xy}\), contain \(x\), so the product rule is needed, with \(u = x\) and \(v = e^{xy}\). The first factor gives \(u'_x = 1\). The second factor is a composite function with the inner function \(xy\), whose derivative with respect to \(x\) is \(y\), so

\[ v'_x = e^{xy}\cdot y \]

2With respect to \(x\): the product rule

Substituting into the product rule:

\[ z'_x = 1\cdot e^{xy} + x\cdot ye^{xy} = e^{xy}(1 + xy) \]

3With respect to \(y\)

The factor \(x\) does not contain \(y\), so it is a constant multiplier and the product rule is not needed. Only \(e^{xy}\) is differentiated, and the derivative of its inner function \(xy\) with respect to \(y\) is \(x\):

\[ z'_y = x\cdot e^{xy}\cdot x = x^2e^{xy} \]
Answer \[ \begin{aligned} z'_x &= e^{xy}(1 + xy) \\ z'_y &= x^2e^{xy} \end{aligned} \]

Practice problems

Write the solutions out as in the examples: identify the outer and the inner function, find the partial derivatives of the inner function and multiply them by the derivative of the outer function. If the function is a product or a quotient, first check whether the product rule or the quotient rule is needed. Then check your answer.

Composite functions

Find the first order partial derivatives of the function \(z = (3x - 2y)^4\).

\(z'_x = 12(3x - 2y)^3\);   \(z'_y = -8(3x - 2y)^3\)

Find the first order partial derivatives of the function \(z = (x^2 + y^3)^6\).

\(z'_x = 12x(x^2 + y^3)^5\);   \(z'_y = 18y^2(x^2 + y^3)^5\)

Find the first order partial derivatives of the function \(z = e^{4x - y^2}\).

\(z'_x = 4e^{4x - y^2}\);   \(z'_y = -2ye^{4x - y^2}\)

Find the first order partial derivatives of the function \(z = e^{xy^3}\).

\(z'_x = y^3e^{xy^3}\);   \(z'_y = 3xy^2e^{xy^3}\)

Find the first order partial derivatives of the function \(z = \ln(3x + y^2)\).

\(z'_x = \dfrac{3}{3x + y^2}\);   \(z'_y = \dfrac{2y}{3x + y^2}\)

Find the first order partial derivatives of the function \(z = \ln(x^2y + 1)\).

\(z'_x = \dfrac{2xy}{x^2y + 1}\);   \(z'_y = \dfrac{x^2}{x^2y + 1}\)

Find the first order partial derivatives of the function \(z = \sqrt{x^2 + 6y}\).

\(z'_x = \dfrac{x}{\sqrt{x^2 + 6y}}\);   \(z'_y = \dfrac{3}{\sqrt{x^2 + 6y}}\)

Find the first order partial derivatives of the function \(z = \dfrac{5}{(2x + y)^2}\).

\(z'_x = -\dfrac{20}{(2x + y)^3}\);   \(z'_y = -\dfrac{10}{(2x + y)^3}\)

Several rules in one function

Find the first order partial derivatives of the function \(z = x^2\cdot e^{x - y}\).

\(z'_x = e^{x - y}(2x + x^2)\);   \(z'_y = -x^2e^{x - y}\)

Find the first order partial derivatives of the function \(z = x\cdot\ln(x + y)\).

\(z'_x = \ln(x + y) + \dfrac{x}{x + y}\);   \(z'_y = \dfrac{x}{x + y}\)

Find the first order partial derivatives of the function \(z = y\cdot\sqrt{x^2 + y}\).

\(z'_x = \dfrac{xy}{\sqrt{x^2 + y}}\);   \(z'_y = \sqrt{x^2 + y} + \dfrac{y}{2\sqrt{x^2 + y}}\)

Find the first order partial derivatives of the function \(z = \dfrac{e^{2x}}{x + y^2}\).

\(z'_x = \dfrac{e^{2x}(2x + 2y^2 - 1)}{(x + y^2)^2}\);   \(z'_y = -\dfrac{2ye^{2x}}{(x + y^2)^2}\)

Find the first order partial derivatives of the function \(z = \ln\dfrac{x}{y}\).

\(z'_x = \dfrac{1}{x}\);   \(z'_y = -\dfrac{1}{y}\)

The values of the partial derivatives at a point

Find the values of the first order partial derivatives of the function \(f(x;\,y) = \sqrt{2x + y^2}\) at the point \((6;\,2)\).

\(f'_x(x;\,y) = \dfrac{1}{\sqrt{2x + y^2}}\);   \(f'_y(x;\,y) = \dfrac{y}{\sqrt{2x + y^2}}\)

\(f'_x(6;\,2) = 0.25\);   \(f'_y(6;\,2) = 0.5\)

Find the values of the first order partial derivatives of the function \(f(x;\,y) = y^2e^{x - 1}\) at the point \((1;\,3)\).

\(f'_x(x;\,y) = y^2e^{x - 1}\);   \(f'_y(x;\,y) = 2ye^{x - 1}\)

\(f'_x(1;\,3) = 9\);   \(f'_y(1;\,3) = 6\)
