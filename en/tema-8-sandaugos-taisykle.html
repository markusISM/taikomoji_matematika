The Product Rule

In this section you will find examples of calculating partial derivatives with the product rule, together with practice problems. Try to solve each problem yourself first, then reveal the solution one step at a time.

  • Examples

The rules used

The product rule of Topic 6 is used as it is, with every derivative taken with respect to the chosen variable:

\[ \begin{aligned} (u\cdot v)'_x &= u'_x\cdot v + u\cdot v'_x \\ (u\cdot v)'_y &= u'_y\cdot v + u\cdot v'_y \end{aligned} \]

Here \(u\) and \(v\) are functions of \(x\) and \(y\). Before the rule is used, it is worth checking that it is really needed, because a letter that is held constant often turns a product into a simple constant multiplier.

1Both factors depend on the variable

With respect to \(x\), the product rule is needed only if both factors contain \(x\); with respect to \(y\), only if both factors contain \(y\).

2One factor does not depend on the variable

A factor that does not contain the variable of differentiation is a constant multiplier. It stays where it is, and only the other factor is differentiated – the product rule is not needed.

The product rule is explained in the product rule card on the Topic 6 page, and the steps of calculating partial derivatives are given in the card “The steps of the calculation” on the Topic 8 page.

Examples

Example 1

The product of a power and a logarithm

Problem Find the first order partial derivatives of the function \(z = x^2y\cdot\ln x\).

1With respect to \(x\): the derivatives of the factors

Both \(x^2y\) and \(\ln x\) contain \(x\), so the product rule is needed. Let \(u = x^2y\) and \(v = \ln x\). With \(y\) held constant,

\[ u'_x = 2xy;\qquad v'_x = \frac{1}{x} \]

2With respect to \(x\): the product rule

Substituting into the rule:

\[ \begin{aligned} z'_x &= 2xy\cdot\ln x + x^2y\cdot\frac{1}{x} \\ &= 2xy\ln x + xy \end{aligned} \]

3With respect to \(y\)

Only the factor \(y\) contains \(y\). The rest of the function, \(x^2\ln x\), is a constant multiplier, and the derivative of \(y\) is 1. The product rule is not needed:

\[ z'_y = x^2\ln x\cdot(y)'_y = x^2\ln x \]
Answer \[ \begin{aligned} z'_x &= 2xy\ln x + xy \\ z'_y &= x^2\ln x \end{aligned} \]
Example 2

The product of two brackets

Problem Find the first order partial derivatives of the function \(z = (3x - y^2)(x^2 + 4y)\).

1The factors

Both brackets contain \(x\) and both contain \(y\), so the product rule is needed for each derivative. Let

\[ u = 3x - y^2;\qquad v = x^2 + 4y \]

2With respect to \(x\)

The factors give \(u'_x = 3\) and \(v'_x = 2x\):

\[ \begin{aligned} z'_x &= 3(x^2 + 4y) + (3x - y^2)\cdot 2x \\ &= 3x^2 + 12y + 6x^2 - 2xy^2 \\ &= 9x^2 - 2xy^2 + 12y \end{aligned} \]

3With respect to \(y\)

The factors give \(u'_y = -2y\) and \(v'_y = 4\):

\[ \begin{aligned} z'_y &= -2y(x^2 + 4y) + (3x - y^2)\cdot 4 \\ &= -2x^2y - 8y^2 + 12x - 4y^2 \\ &= -2x^2y - 12y^2 + 12x \end{aligned} \]
Answer \[ \begin{aligned} z'_x &= 9x^2 - 2xy^2 + 12y \\ z'_y &= -2x^2y - 12y^2 + 12x \end{aligned} \]

Practice problems

Write the solutions out as in the examples: for each variable check whether both factors depend on it, find the derivatives of the factors, apply the product rule and simplify the result. Then check your answer.

Find the first order partial derivatives of the function \(z = (x^2 + y)(3x - 2y^2)\).

\(z'_x = 9x^2 - 4xy^2 + 3y\);   \(z'_y = 3x - 4x^2y - 6y^2\)

Find the first order partial derivatives of the function \(z = xy^2\cdot e^x\).

\(z'_x = y^2e^x(1 + x)\);   \(z'_y = 2xye^x\)

Find the first order partial derivatives of the function \(z = x^3y\cdot\ln y\).

\(z'_x = 3x^2y\ln y\);   \(z'_y = x^3(\ln y + 1)\)

Find the first order partial derivatives of the function \(z = (2x - y)e^y\).

\(z'_x = 2e^y\);   \(z'_y = e^y(2x - y - 1)\)

Find the first order partial derivatives of the function \(z = \sqrt{x}\cdot(x + y^2)\).

\(z'_x = \dfrac{x + y^2}{2\sqrt{x}} + \sqrt{x}\);   \(z'_y = 2y\sqrt{x}\)
