The Chain Rule

In this section you will find examples of calculating derivatives with the chain rule, together with practice problems. Try to solve each problem yourself first, then reveal the solution one step at a time.

  • Examples
  • Practice

The rules used

\[ \big(g(u(x))\big)' = g'\big(u(x)\big)\cdot u'(x) \]

Here \(g(u)\) is the outer function and \(u(x)\) is the inner function. For the functions in the table, this gives the following formulas:

1Power and root
  • \(\big((u(x))^n\big)' = n(u(x))^{n-1}\cdot u'(x)\)
  • \(\left(\sqrt{u(x)}\right)' = \dfrac{u'(x)}{2\sqrt{u(x)}}\)
2Exponential and logarithmic functions
  • \(\left(e^{u(x)}\right)' = e^{u(x)}\cdot u'(x)\)
  • \(\big(\ln u(x)\big)' = \dfrac{u'(x)}{u(x)}\)
3Sine and cosine
  • \(\big(\sin u(x)\big)' = \cos u(x)\cdot u'(x)\)
  • \(\big(\cos u(x)\big)' = -\sin u(x)\cdot u'(x)\)

The rule, with examples of how to identify the outer and the inner function, is explained in the chain rule card on the Topic 6 page.

Examples

Example 1

A power

Problem Find \(f'(x)\) if \(f(x) = (3x^2 - 5)^4\).

1The outer and the inner function

The function is composite, so apply the chain rule. Outer: the fourth power. Inner: \(u(x) = 3x^2 - 5\), whose derivative is \(u'(x) = 6x\).

2Differentiation

Apply the power rule to the whole bracket: bring down the exponent and reduce it by one. Keep the expression inside the bracket unchanged, then multiply by its derivative:

\[ \begin{aligned} f'(x) &= 4(3x^2 - 5)^3\cdot 6x \\ &= 24x(3x^2 - 5)^3 \end{aligned} \]
Answer \[ f'(x) = 24x(3x^2 - 5)^3 \]
Example 2

An exponential function

Problem Find \(f'(x)\) if \(f(x) = e^{2x^3 - x}\).

1The outer and the inner function

The function is composite, so apply the chain rule. Outer: \(e^u\). Inner: \(u(x) = 2x^3 - x\), whose derivative is \(u'(x) = 6x^2 - 1\).

2Differentiation

The derivative of an exponential with base \(e\) retains the original exponential factor. Multiply it by the derivative of the exponent, keeping that derivative in brackets:

\[ f'(x) = e^{2x^3 - x}\cdot(6x^2 - 1) \]
Answer \[ f'(x) = (6x^2 - 1)\,e^{2x^3 - x} \]
Example 3

A logarithm

Problem Find \(f'(x)\) if \(f(x) = \ln(x^2 + 4)\).

1The outer and the inner function

The function is composite, so apply the chain rule. Outer: \(\ln u\). Inner: \(u(x) = x^2 + 4\), whose derivative is \(u'(x) = 2x\).

2Differentiation

The derivative of the logarithm is the reciprocal of its input. Multiplying by the inner derivative places that derivative in the numerator and the original inner expression in the denominator:

\[ f'(x) = \frac{1}{x^2 + 4}\cdot 2x = \frac{2x}{x^2 + 4} \]
Answer \[ f'(x) = \dfrac{2x}{x^2 + 4} \]
Example 4

A square root

Problem Find \(f'(x)\) if \(f(x) = \sqrt{4x + 7}\).

1The outer and the inner function

The function is composite, so apply the chain rule. Outer: the square root. Inner: \(u(x) = 4x + 7\), whose derivative is \(u'(x) = 4\).

2Differentiation

Use the square root derivative with the entire inner expression under the root, then multiply by four. Simplify the numerical coefficient only after applying the chain rule:

\[ f'(x) = \frac{4}{2\sqrt{4x + 7}} = \frac{2}{\sqrt{4x + 7}} \]
Answer \[ f'(x) = \dfrac{2}{\sqrt{4x + 7}} \]
Example 5

A cosine

Problem Find \(f'(x)\) if \(f(x) = \cos(3x^2)\).

1The outer and the inner function

The function is composite, so apply the chain rule. Outer: \(\cos u\). Inner: \(u(x) = 3x^2\), whose derivative is \(u'(x) = 6x\).

2Differentiation

Differentiating cosine gives negative sine. Retain the original inner expression as the sine argument, then multiply by the inner derivative. Keep the minus sign throughout the calculation:

\[ \begin{aligned} f'(x) &= -\sin(3x^2)\cdot 6x \\ &= -6x\sin(3x^2) \end{aligned} \]
Answer \[ f'(x) = -6x\sin(3x^2) \]
Example 6

A root in the exponent

Problem Find \(f'(x)\) if \(f(x) = e^{\sqrt{x}}\).

1The rules

Apply the chain rule. The outer function is \(e^u\); the inner function is \(u(x) = \sqrt{x}\), with derivative \(u'(x) = \dfrac{1}{2\sqrt{x}}\).

2Differentiation

Differentiating the outer exponential leaves it unchanged. Multiply this exponential by the derivative of the square root, then write the product as a single fraction:

\[ f'(x) = e^{\sqrt{x}}\cdot\frac{1}{2\sqrt{x}} = \frac{e^{\sqrt{x}}}{2\sqrt{x}} \]

The derivative is valid for \(x > 0\); it is not finite at \(x = 0\).

Answer \[ f'(x) = \frac{e^{\sqrt{x}}}{2\sqrt{x}} \]

Practice problems

Write the solutions out as in the examples: identify the structure of the function, choose the rule, differentiate and simplify the result. Then check your answer.

Find \(f'(x)\) if \(f(x) = (2x^2 + 5)^6\).

\(f'(x) = 24x(2x^2 + 5)^5\)

Find \(f'(x)\) if \(f(x) = e^{3x^2 - 4x}\).

\(f'(x) = (6x - 4)\,e^{3x^2 - 4x}\)

Find \(f'(x)\) if \(f(x) = \sqrt{6x - 1}\).

\(f'(x) = \dfrac{3}{\sqrt{6x - 1}}\)
