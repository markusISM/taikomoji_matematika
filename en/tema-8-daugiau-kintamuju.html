Topic 8 · Calculating partial derivatives · Section 5

Partial Derivatives of Functions of More Than Two Variables

In this section you will find examples of calculating the partial derivatives of functions of three variables, together with practice problems. Try to solve each problem yourself first, then reveal the solution one step at a time.

  • Rules
  • Examples
  • Practice

The rules used

Nothing changes when there are three or more independent variables. A function \(w = f(x;\,y;\,z)\) has three first order partial derivatives, \(w'_x\), \(w'_y\) and \(w'_z\). In each of them one letter is the variable and all the other letters are constants.

DerivativeVariableConstants
\(w'_x\)\(x\)\(y,\ z\)
\(w'_y\)\(y\)\(x,\ z\)
\(w'_z\)\(z\)\(x,\ y\)

The same rules are used as for functions of two variables: the basic rules, the product rule, the quotient rule and the chain rule. The steps of calculating partial derivatives are given in the card “The steps of the calculation” on the Topic 8 page.

Examples

Example 1

A polynomial in three variables and its values at a point

Problem Find the first order partial derivatives of the function \(w = x^2y + yz^3 - 4xz\) and their values at the point \((1;\,2;\,-1)\).

1With respect to \(x\)

Here \(y\) and \(z\) are constants. The term \(yz^3\) does not contain \(x\):

\[ w'_x = 2x\cdot y + 0 - 4z = 2xy - 4z \]

2With respect to \(y\)

Here \(x\) and \(z\) are constants. The term \(4xz\) does not contain \(y\):

\[ w'_y = x^2\cdot 1 + z^3 - 0 = x^2 + z^3 \]

3With respect to \(z\)

Here \(x\) and \(y\) are constants. The term \(x^2y\) does not contain \(z\):

\[ w'_z = 0 + y\cdot 3z^2 - 4x = 3yz^2 - 4x \]

4The values at the point

At the point \((1;\,2;\,-1)\) the values are

\[ \begin{aligned} w'_x &= 2\cdot 1\cdot 2 - 4\cdot(-1) = 8 \\ w'_y &= 1^2 + (-1)^3 = 0 \\ w'_z &= 3\cdot 2\cdot(-1)^2 - 4\cdot 1 = 2 \end{aligned} \]
Answer \[ \begin{aligned} w'_x &= 2xy - 4z \\ w'_y &= x^2 + z^3 \\ w'_z &= 3yz^2 - 4x \end{aligned} \]

At the point \((1;\,2;\,-1)\): \(w'_x = 8\), \(w'_y = 0\), \(w'_z = 2\).

Example 2

A composite function and a constant multiplier

Problem Find the first order partial derivatives of the function \(w = z^2\cdot\ln(x + 2y)\).

1With respect to \(x\)

The factor \(z^2\) is a constant multiplier. The logarithm is a composite function with the inner function \(x + 2y\), whose derivative with respect to \(x\) is 1:

\[ w'_x = z^2\cdot\frac{1}{x + 2y} = \frac{z^2}{x + 2y} \]

2With respect to \(y\)

The only difference is the derivative of the inner function, which is now 2:

\[ w'_y = z^2\cdot\frac{2}{x + 2y} = \frac{2z^2}{x + 2y} \]

3With respect to \(z\)

The logarithm does not contain \(z\), so it is a constant multiplier, and only \(z^2\) is differentiated:

\[ w'_z = 2z\cdot\ln(x + 2y) \]
Answer \[ \begin{aligned} w'_x &= \frac{z^2}{x + 2y} \\[10pt] w'_y &= \frac{2z^2}{x + 2y} \\[10pt] w'_z &= 2z\ln(x + 2y) \end{aligned} \]

Practice problems

Write the solutions out as in the examples: for each partial derivative decide which letter is the variable and which letters are constants, and apply the rules that are needed. Then check your answer.

Find the first order partial derivatives of the function \(w = x^2y - 3yz^2 + 4xz\).

\(w'_x = 2xy + 4z\);   \(w'_y = x^2 - 3z^2\);   \(w'_z = -6yz + 4x\)

Find the first order partial derivatives of the function \(w = 4xy^2z^3\).

\(w'_x = 4y^2z^3\);   \(w'_y = 8xyz^3\);   \(w'_z = 12xy^2z^2\)

Find the first order partial derivatives of the function \(w = e^{x + 2y - 3z}\).

\(w'_x = e^{x + 2y - 3z}\);   \(w'_y = 2e^{x + 2y - 3z}\);   \(w'_z = -3e^{x + 2y - 3z}\)

Find the first order partial derivatives of the function \(w = \ln(x^2 + yz)\).

\(w'_x = \dfrac{2x}{x^2 + yz}\);   \(w'_y = \dfrac{z}{x^2 + yz}\);   \(w'_z = \dfrac{y}{x^2 + yz}\)

Find the first order partial derivatives of the function \(w = \dfrac{xy}{z}\).

\(w'_x = \dfrac{y}{z}\);   \(w'_y = \dfrac{x}{z}\);   \(w'_z = -\dfrac{xy}{z^2}\)

Find the values of the first order partial derivatives of the function \(f(x;\,y;\,z) = x^2z + y\ln z\) at the point \((2;\,3;\,1)\).

\(f'_x(x;\,y;\,z) = 2xz\);   \(f'_y(x;\,y;\,z) = \ln z\);   \(f'_z(x;\,y;\,z) = x^2 + \dfrac{y}{z}\)

\(f'_x(2;\,3;\,1) = 4\);   \(f'_y(2;\,3;\,1) = 0\);   \(f'_z(2;\,3;\,1) = 7\)
