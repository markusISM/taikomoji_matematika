Sudėtinės funkcijos išvestinės taisyklė

Šiame skyriuje rasite dalinių išvestinių skaičiavimo pavyzdžių, kuriuose taikoma sudėtinės funkcijos išvestinės taisyklė, ir uždavinių savarankiškam darbui. Pirmiausia pabandykite išspręsti patys, tada sprendimą atskleiskite žingsnis po žingsnio.

  • Pavyzdžiai

Taikomos taisyklės

Sudėtinę funkciją sudaro išorinė ir vidinė funkcijos: \(z = g(u)\), kai \(u = u(x;\,y)\). Išorinę funkciją \(g\) diferencijuojame kaip 6 temoje, o rezultatą dauginame iš vidinės funkcijos dalinės išvestinės:

\[ \begin{aligned} z'_x &= g'(u)\cdot u'_x \\ z'_y &= g'(u)\cdot u'_y \end{aligned} \]

Išorinės funkcijos išvestinė abiejose formulėse yra tokia pati. Nuo pasirinkto kintamojo priklauso tik paskutinis daugiklis – vidinės funkcijos dalinė išvestinė. Dažniausiai naudojamos šios formulės:

1Laipsnis ir šaknis
  • \(\big(u^n\big)'_x = nu^{n-1}\cdot u'_x\)
  • \(\left(\sqrt{u}\right)'_x = \dfrac{u'_x}{2\sqrt{u}}\)
2Rodiklinė ir logaritminė funkcijos
  • \(\left(e^u\right)'_x = e^u\cdot u'_x\)
  • \(\big(\ln u\big)'_x = \dfrac{u'_x}{u}\)

Tos pačios keturios formulės galioja ir pagal \(y\), juo pakeitus \(x\). Kartais vienai funkcijai reikia kelių taisyklių, pavyzdžiui, sandaugos ir sudėtinės funkcijos (4 pavyzdys).

Sudėtinės funkcijos išvestinės taisyklės paaiškinimas pateiktas 6 temos puslapio sudėtinės funkcijos išvestinės taisyklės kortelėje, o dalinių išvestinių skaičiavimo eiga – 8 temos puslapio kortelėje „Skaičiavimo eiga“.

Pavyzdžiai

1 pavyzdys

Sudėtinė laipsninė funkcija

Sąlyga Raskite funkcijos \(z = (x^2 + 3y)^5\) pirmos eilės dalines išvestines.

1Išorinė ir vidinė funkcijos

Išorinė funkcija yra penktasis laipsnis \(g(u) = u^5\), o vidinė – \(u = x^2 + 3y\). Pagal sudėtinės laipsninės funkcijos išvestinės formulę abiem atvejais gauname \(5(x^2 + 3y)^4\) ir dauginame iš vidinės funkcijos dalinės išvestinės.

2Pagal \(x\)

Vidinės funkcijos išvestinė yra \(u'_x = 2x\):

\[ z'_x = 5(x^2 + 3y)^4\cdot 2x = 10x(x^2 + 3y)^4 \]

3Pagal \(y\)

Vidinės funkcijos išvestinė yra \(u'_y = 3\):

\[ z'_y = 5(x^2 + 3y)^4\cdot 3 = 15(x^2 + 3y)^4 \]
Atsakymas \[ \begin{aligned} z'_x &= 10x(x^2 + 3y)^4 \\ z'_y &= 15(x^2 + 3y)^4 \end{aligned} \]
2 pavyzdys

Sudėtinė rodiklinė funkcija

Sąlyga Raskite funkcijos \(z = e^{x^3 - 2xy}\) pirmos eilės dalines išvestines.

1Išorinė ir vidinė funkcijos

Išorinė funkcija yra rodiklinė funkcija \(g(u) = e^u\), o vidinė – \(u = x^3 - 2xy\). Rodiklinės funkcijos su pagrindu e išvestinė sutampa su pačia funkcija, todėl abiem atvejais gauname \(e^{x^3 - 2xy}\). Vidinės funkcijos dalinės išvestinės yra

\[ u'_x = 3x^2 - 2y;\qquad u'_y = -2x \]

2Dalinės išvestinės

Pagal formulę \(\left(e^u\right)'_x = e^u\cdot u'_x\) ir analogišką formulę pagal \(y\) gauname

\[ \begin{aligned} z'_x &= e^{x^3 - 2xy}\cdot(3x^2 - 2y) \\ &= (3x^2 - 2y)e^{x^3 - 2xy} \\[6pt] z'_y &= e^{x^3 - 2xy}\cdot(-2x) = -2xe^{x^3 - 2xy} \end{aligned} \]
Atsakymas \[ \begin{aligned} z'_x &= (3x^2 - 2y)e^{x^3 - 2xy} \\ z'_y &= -2xe^{x^3 - 2xy} \end{aligned} \]
3 pavyzdys

Logaritmas ir kvadratinė šaknis

Sąlyga Raskite funkcijų pirmos eilės dalines išvestines: a) \(z = \ln(x^2 + 5y)\); b) \(z = \sqrt{4x + y^2}\).

1a) Logaritmas

Išorinė funkcija yra logaritmas, o vidinė – \(u = x^2 + 5y\); jos dalinės išvestinės yra \(u'_x = 2x\) ir \(u'_y = 5\). Pagal formulę \(\big(\ln u\big)'_x = \frac{u'_x}{u}\) gauname

\[ \begin{aligned} z'_x &= \frac{2x}{x^2 + 5y} \\[8pt] z'_y &= \frac{5}{x^2 + 5y} \end{aligned} \]

2b) Kvadratinė šaknis

Išorinė funkcija yra kvadratinė šaknis, o vidinė – \(u = 4x + y^2\); jos dalinės išvestinės yra \(u'_x = 4\) ir \(u'_y = 2y\). Pagal formulę \(\left(\sqrt{u}\right)'_x = \frac{u'_x}{2\sqrt{u}}\) gauname

\[ \begin{aligned} z'_x &= \frac{4}{2\sqrt{4x + y^2}} = \frac{2}{\sqrt{4x + y^2}} \\[12pt] z'_y &= \frac{2y}{2\sqrt{4x + y^2}} = \frac{y}{\sqrt{4x + y^2}} \end{aligned} \]
Atsakymas \[ \begin{aligned} \text{a)}\quad z'_x &= \frac{2x}{x^2 + 5y} \\[8pt] z'_y &= \frac{5}{x^2 + 5y} \\[16pt] \text{b)}\quad z'_x &= \frac{2}{\sqrt{4x + y^2}} \\[8pt] z'_y &= \frac{y}{\sqrt{4x + y^2}} \end{aligned} \]
4 pavyzdys

Sandaugos ir sudėtinės funkcijos taisyklės kartu

Sąlyga Raskite funkcijos \(z = x\cdot e^{xy}\) pirmos eilės dalines išvestines.

1Pagal \(x\): daugiklių išvestinės

Šiai funkcijai diferencijuoti reikia dviejų taisyklių. Abu daugikliai \(x\) ir \(e^{xy}\) priklauso nuo \(x\), todėl taikome sandaugos taisyklę, kai \(u = x\) ir \(v = e^{xy}\). Pirmojo daugiklio išvestinė yra \(u'_x = 1\). Antrasis yra sudėtinė funkcija, kurios vidinė funkcija \(xy\). Jos išvestinė pagal \(x\) lygi \(y\), todėl

\[ v'_x = e^{xy}\cdot y \]

2Pagal \(x\): sandaugos taisyklė

Įstatę į sandaugos taisyklės formulę, gauname

\[ z'_x = 1\cdot e^{xy} + x\cdot ye^{xy} = e^{xy}(1 + xy) \]

3Pagal \(y\)

Daugiklis \(x\) nepriklauso nuo \(y\), todėl jis yra pastovus ir sandaugos taisyklės nereikia. Diferencijuojame tik \(e^{xy}\); vidinės funkcijos \(xy\) išvestinė pagal \(y\) lygi \(x\):

\[ z'_y = x\cdot e^{xy}\cdot x = x^2e^{xy} \]
Atsakymas \[ \begin{aligned} z'_x &= e^{xy}(1 + xy) \\ z'_y &= x^2e^{xy} \end{aligned} \]

Uždaviniai savarankiškam darbui

Sprendimus užrašykite taip pat kaip pavyzdžiuose: nustatykite išorinę ir vidinę funkcijas, raskite vidinės funkcijos dalines išvestines ir padauginkite iš išorinės funkcijos išvestinės. Jei funkcija yra sandauga arba dalmuo, pirmiausia patikrinkite, ar reikia sandaugos arba dalmens taisyklės. Tada pasitikrinkite atsakymą.

Sudėtinė funkcija

Raskite funkcijos \(z = (3x - 2y)^4\) pirmos eilės dalines išvestines.

\(z'_x = 12(3x - 2y)^3\);   \(z'_y = -8(3x - 2y)^3\)

Raskite funkcijos \(z = (x^2 + y^3)^6\) pirmos eilės dalines išvestines.

\(z'_x = 12x(x^2 + y^3)^5\);   \(z'_y = 18y^2(x^2 + y^3)^5\)

Raskite funkcijos \(z = e^{4x - y^2}\) pirmos eilės dalines išvestines.

\(z'_x = 4e^{4x - y^2}\);   \(z'_y = -2ye^{4x - y^2}\)

Raskite funkcijos \(z = e^{xy^3}\) pirmos eilės dalines išvestines.

\(z'_x = y^3e^{xy^3}\);   \(z'_y = 3xy^2e^{xy^3}\)

Raskite funkcijos \(z = \ln(3x + y^2)\) pirmos eilės dalines išvestines.

\(z'_x = \dfrac{3}{3x + y^2}\);   \(z'_y = \dfrac{2y}{3x + y^2}\)

Raskite funkcijos \(z = \ln(x^2y + 1)\) pirmos eilės dalines išvestines.

\(z'_x = \dfrac{2xy}{x^2y + 1}\);   \(z'_y = \dfrac{x^2}{x^2y + 1}\)

Raskite funkcijos \(z = \sqrt{x^2 + 6y}\) pirmos eilės dalines išvestines.

\(z'_x = \dfrac{x}{\sqrt{x^2 + 6y}}\);   \(z'_y = \dfrac{3}{\sqrt{x^2 + 6y}}\)

Raskite funkcijos \(z = \dfrac{5}{(2x + y)^2}\) pirmos eilės dalines išvestines.

\(z'_x = -\dfrac{20}{(2x + y)^3}\);   \(z'_y = -\dfrac{10}{(2x + y)^3}\)

Kelių taisyklių taikymas vienai funkcijai

Raskite funkcijos \(z = x^2\cdot e^{x - y}\) pirmos eilės dalines išvestines.

\(z'_x = e^{x - y}(2x + x^2)\);   \(z'_y = -x^2e^{x - y}\)

Raskite funkcijos \(z = x\cdot\ln(x + y)\) pirmos eilės dalines išvestines.

\(z'_x = \ln(x + y) + \dfrac{x}{x + y}\);   \(z'_y = \dfrac{x}{x + y}\)

Raskite funkcijos \(z = y\cdot\sqrt{x^2 + y}\) pirmos eilės dalines išvestines.

\(z'_x = \dfrac{xy}{\sqrt{x^2 + y}}\);   \(z'_y = \sqrt{x^2 + y} + \dfrac{y}{2\sqrt{x^2 + y}}\)

Raskite funkcijos \(z = \dfrac{e^{2x}}{x + y^2}\) pirmos eilės dalines išvestines.

\(z'_x = \dfrac{e^{2x}(2x + 2y^2 - 1)}{(x + y^2)^2}\);   \(z'_y = -\dfrac{2ye^{2x}}{(x + y^2)^2}\)

Raskite funkcijos \(z = \ln\dfrac{x}{y}\) pirmos eilės dalines išvestines.

\(z'_x = \dfrac{1}{x}\);   \(z'_y = -\dfrac{1}{y}\)

Dalinių išvestinių reikšmės taške

Apskaičiuokite funkcijos \(f(x;\,y) = \sqrt{2x + y^2}\) pirmos eilės dalinių išvestinių reikšmes taške \((6;\,2)\).

\(f'_x(x;\,y) = \dfrac{1}{\sqrt{2x + y^2}}\);   \(f'_y(x;\,y) = \dfrac{y}{\sqrt{2x + y^2}}\)

\(f'_x(6;\,2) = 0{,}25\);   \(f'_y(6;\,2) = 0{,}5\)

Apskaičiuokite funkcijos \(f(x;\,y) = y^2e^{x - 1}\) pirmos eilės dalinių išvestinių reikšmes taške \((1;\,3)\).

\(f'_x(x;\,y) = y^2e^{x - 1}\);   \(f'_y(x;\,y) = 2ye^{x - 1}\)

\(f'_x(1;\,3) = 9\);   \(f'_y(1;\,3) = 6\)
