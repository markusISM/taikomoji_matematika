Daugiau nei dviejų kintamųjų funkcijos dalinės išvestinės

Šiame skyriuje rasite trijų kintamųjų funkcijų dalinių išvestinių skaičiavimo pavyzdžių ir uždavinių savarankiškam darbui. Pirmiausia pabandykite išspręsti patys, tada sprendimą atskleiskite žingsnis po žingsnio.

Taikomos taisyklės

Kai nepriklausomų kintamųjų yra trys ar daugiau, metodas nesikeičia. Funkcija \(w = f(x;\,y;\,z)\) turi tris pirmos eilės dalines išvestines: \(w'_x\), \(w'_y\) ir \(w'_z\). Skaičiuojant kiekvieną iš jų, viena raidė žymi kintamąjį, o visos kitos – konstantas.

IšvestinėKintamasisKonstantos
\(w'_x\)\(x\)\(y,\ z\)
\(w'_y\)\(y\)\(x,\ z\)
\(w'_z\)\(z\)\(x,\ y\)

Taikomos tos pačios taisyklės kaip dviejų kintamųjų funkcijoms: pagrindinės taisyklės, sandaugos, dalmens ir sudėtinės funkcijos išvestinės taisyklės. Dalinių išvestinių skaičiavimo eiga pateikta 8 temos puslapio kortelėje „Skaičiavimo eiga“.

Pavyzdžiai

1 pavyzdys

Trijų kintamųjų daugianaris ir reikšmės taške

Sąlyga Raskite funkcijos \(w = x^2y + yz^3 - 4xz\) pirmos eilės dalines išvestines ir jų reikšmes taške \((1;\,2;\,-1)\).

1Pagal \(x\)

Čia \(y\) ir \(z\) yra konstantos. Naryje \(yz^3\) nėra \(x\):

\[ w'_x = 2x\cdot y + 0 - 4z = 2xy - 4z \]

2Pagal \(y\)

Čia \(x\) ir \(z\) yra konstantos. Naryje \(4xz\) nėra \(y\):

\[ w'_y = x^2\cdot 1 + z^3 - 0 = x^2 + z^3 \]

3Pagal \(z\)

Čia \(x\) ir \(y\) yra konstantos. Naryje \(x^2y\) nėra \(z\):

\[ w'_z = 0 + y\cdot 3z^2 - 4x = 3yz^2 - 4x \]

4Reikšmės taške

Taške \((1;\,2;\,-1)\) gauname reikšmes

\[ \begin{aligned} w'_x &= 2\cdot 1\cdot 2 - 4\cdot(-1) = 8 \\ w'_y &= 1^2 + (-1)^3 = 0 \\ w'_z &= 3\cdot 2\cdot(-1)^2 - 4\cdot 1 = 2 \end{aligned} \]
Atsakymas \[ \begin{aligned} w'_x &= 2xy - 4z \\ w'_y &= x^2 + z^3 \\ w'_z &= 3yz^2 - 4x \end{aligned} \]

Taške \((1;\,2;\,-1)\): \(w'_x = 8\), \(w'_y = 0\), \(w'_z = 2\).

2 pavyzdys

Sudėtinė funkcija ir pastovus daugiklis

Sąlyga Raskite funkcijos \(w = z^2\cdot\ln(x + 2y)\) pirmos eilės dalines išvestines.

1Pagal \(x\)

Daugiklis \(z^2\) yra pastovus. Logaritmas yra sudėtinė funkcija, kurios vidinė funkcija \(x + 2y\). Jos išvestinė pagal \(x\) lygi 1:

\[ w'_x = z^2\cdot\frac{1}{x + 2y} = \frac{z^2}{x + 2y} \]

2Pagal \(y\)

Skiriasi tik vidinės funkcijos išvestinė: dabar ji lygi 2:

\[ w'_y = z^2\cdot\frac{2}{x + 2y} = \frac{2z^2}{x + 2y} \]

3Pagal \(z\)

Logaritmas nepriklauso nuo \(z\), todėl jis yra pastovus daugiklis. Diferencijuojame tik \(z^2\):

\[ w'_z = 2z\cdot\ln(x + 2y) \]
Atsakymas \[ \begin{aligned} w'_x &= \frac{z^2}{x + 2y} \\[10pt] w'_y &= \frac{2z^2}{x + 2y} \\[10pt] w'_z &= 2z\ln(x + 2y) \end{aligned} \]

Uždaviniai savarankiškam darbui

Sprendimus užrašykite taip pat kaip pavyzdžiuose: skaičiuodami kiekvieną dalinę išvestinę, nustatykite, kuri raidė žymi kintamąjį, o kurios – konstantas, ir taikykite reikiamas taisykles. Tada pasitikrinkite atsakymą.

Raskite funkcijos \(w = x^2y - 3yz^2 + 4xz\) pirmos eilės dalines išvestines.

\(w'_x = 2xy + 4z\);   \(w'_y = x^2 - 3z^2\);   \(w'_z = -6yz + 4x\)

Raskite funkcijos \(w = 4xy^2z^3\) pirmos eilės dalines išvestines.

\(w'_x = 4y^2z^3\);   \(w'_y = 8xyz^3\);   \(w'_z = 12xy^2z^2\)

Raskite funkcijos \(w = e^{x + 2y - 3z}\) pirmos eilės dalines išvestines.

\(w'_x = e^{x + 2y - 3z}\);   \(w'_y = 2e^{x + 2y - 3z}\);   \(w'_z = -3e^{x + 2y - 3z}\)

Raskite funkcijos \(w = \ln(x^2 + yz)\) pirmos eilės dalines išvestines.

\(w'_x = \dfrac{2x}{x^2 + yz}\);   \(w'_y = \dfrac{z}{x^2 + yz}\);   \(w'_z = \dfrac{y}{x^2 + yz}\)

Raskite funkcijos \(w = \dfrac{xy}{z}\) pirmos eilės dalines išvestines.

\(w'_x = \dfrac{y}{z}\);   \(w'_y = \dfrac{x}{z}\);   \(w'_z = -\dfrac{xy}{z^2}\)

Apskaičiuokite funkcijos \(f(x;\,y;\,z) = x^2z + y\ln z\) pirmos eilės dalinių išvestinių reikšmes taške \((2;\,3;\,1)\).

\(f'_x(x;\,y;\,z) = 2xz\);   \(f'_y(x;\,y;\,z) = \ln z\);   \(f'_z(x;\,y;\,z) = x^2 + \dfrac{y}{z}\)

\(f'_x(2;\,3;\,1) = 4\);   \(f'_y(2;\,3;\,1) = 0\);   \(f'_z(2;\,3;\,1) = 7\)
