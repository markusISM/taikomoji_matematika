Naudingosios integravimo formulės

Šiame skyriuje rasite integralų, kurių pointegrinės funkcijos argumentas yra tiesinė funkcija \(ax + b\), skaičiavimo pavyzdžių ir uždavinių savarankiškam darbui. Pirmiausia pabandykite išspręsti patys, tada sprendimą atskleiskite žingsnis po žingsnio.

Taikomos formulės

Pointegrinės funkcijos argumentas vietoje \(x\) gali būti tiesinė funkcija \(ax + b\), pavyzdžiui, \((3x - 2)^5\), \(e^{2 - x}\) ar \(\cos\frac{x}{2}\). Visiems tokiems integralams taikoma viena taisyklė (išsamiau – 10 temos puslapio kortelėje „Naudingosios integravimo formulės“).

Jei \(F(u)\) yra funkcijos \(f(u)\) pirmykštė ir \(a \ne 0\), tai

\[ \int f(ax + b)\, dx = \frac{1}{a}F(ax + b) + C \]

Pagrindinę formulę taikome taip, lyg \(ax + b\) būtų integravimo kintamasis, o rezultatą dalijame iš koeficiento \(a\) prie \(x\). Laisvasis narys \(b\) daliklio nekeičia. Pritaikę taisyklę pagrindinėms formulėms, gauname naudingąsias integravimo formules:

1Laipsnis, šaknis ir trupmena
  • \(\displaystyle\int (ax + b)^n\, dx = \frac{1}{a}\cdot\frac{(ax + b)^{n+1}}{n+1} + C\)\(\displaystyle\begin{aligned} &\int (ax + b)^n\, dx \\ &= \frac{1}{a}\cdot\frac{(ax + b)^{n+1}}{n+1} + C\end{aligned}\)
  • \(\displaystyle\int \frac{1}{\sqrt{ax + b}}\, dx = \frac{1}{a}\cdot 2\sqrt{ax + b} + C\)\(\displaystyle\begin{aligned} &\int \frac{1}{\sqrt{ax + b}}\, dx \\ &= \frac{1}{a}\cdot 2\sqrt{ax + b} + C\end{aligned}\)
  • \(\displaystyle\int \frac{1}{ax + b}\, dx = \frac{1}{a}\ln|ax + b| + C\)\(\displaystyle\begin{aligned} &\int \frac{1}{ax + b}\, dx \\ &= \frac{1}{a}\ln|ax + b| + C\end{aligned}\)

Laipsnio formulėje \(n \ne -1\).

2Rodiklinė funkcija
  • \(\displaystyle\int e^{ax + b}\, dx = \frac{1}{a}e^{ax + b} + C\)\(\displaystyle\begin{aligned} &\int e^{ax + b}\, dx \\ &= \frac{1}{a}e^{ax + b} + C\end{aligned}\)

Rodiklinės funkcijos \(k^{mx + n}\) integravimo formulė pateikta temos puslapio formulių sąraše.

3Trigonometrinės funkcijos
  • \(\displaystyle\int \sin(ax + b)\, dx = -\frac{1}{a}\cos(ax + b) + C\)\(\displaystyle\begin{aligned} &\int \sin(ax + b)\, dx \\ &= -\frac{1}{a}\cos(ax + b) + C\end{aligned}\)
  • \(\displaystyle\int \cos(ax + b)\, dx = \frac{1}{a}\sin(ax + b) + C\)\(\displaystyle\begin{aligned} &\int \cos(ax + b)\, dx \\ &= \frac{1}{a}\sin(ax + b) + C\end{aligned}\)
  • \(\displaystyle\int \frac{1}{\cos^2(ax + b)}\, dx = \frac{1}{a}\operatorname{tg}(ax + b) + C\)\(\displaystyle\begin{aligned} &\int \frac{1}{\cos^2(ax + b)}\, dx \\ &= \frac{1}{a}\operatorname{tg}(ax + b) + C\end{aligned}\)
  • \(\displaystyle\int \frac{1}{\sin^2(ax + b)}\, dx = -\frac{1}{a}\operatorname{ctg}(ax + b) + C\)\(\displaystyle\begin{aligned} &\int \frac{1}{\sin^2(ax + b)}\, dx \\ &= -\frac{1}{a}\operatorname{ctg}(ax + b) + C\end{aligned}\)

Kada formulės netinka. Naudingąsias formules taikome tik tada, kai vidinė funkcija tiesinė. Reiškiniuose \(\left(x^2 + 1\right)^3\) ir \(e^{x^2}\) vidinė funkcija netiesinė, todėl tokius integralus skaičiuojame keisdami kintamąjį (10 temos puslapio 9 kortelė) arba atskliausdami.

Sprendimo eiga

Pavyzdžiuose žingsniai pavadinti taip pat kaip šiame sąraše.

  1. Pertvarkymas. Jei reikia, pointegrinę funkciją užrašykite kaip narių sumą, o šaknis ir trupmenas – laipsniais, pavyzdžiui, \(\sqrt{2x + 1} = (2x + 1)^{\frac{1}{2}}\), \(\frac{1}{(5 - 2x)^3} = (5 - 2x)^{-3}\). Jei to daryti nereikia, šį žingsnį praleiskite.
  2. Vidinė funkcija. Nustatykite vidinę tiesinę funkciją \(ax + b\) ir koeficientą \(a\) prie \(x\). Atsižvelkite į koeficiento ženklą.
  3. Integravimas. Išorinę funkciją integruokite pagal pagrindinę formulę, argumentą \(ax + b\) palikdami nepakeistą. Rezultatą padalykite iš \(a\) (padauginkite iš \(\frac{1}{a}\)), suprastinkite ir pridėkite integravimo konstantą \(C\).
  4. Patikrinimas. Gautą funkciją diferencijuokite pagal sudėtinės funkcijos išvestinės taisyklę. Vidinės funkcijos išvestinė \(a\) susiprastina su dalikliu, ir gaunama pointegrinė funkcija.

Kaip nustatyti koeficientą \(a\)

Koeficientas \(a\) – tai skaičius, iš kurio dauginamas \(x\). Jis gali būti neigiamas arba trupmeninis:

Vidinė funkcija\(a\)Dalyba iš \(a\)
\(3x - 2\)\(3\)daugyba iš \(\frac{1}{3}\)
\(5 - 2x\)\(-2\)daugyba iš \(-\frac{1}{2}\)
\(2 - x\)\(-1\)ženklo pakeitimas
\(\frac{x}{2} = \frac{1}{2}x\)\(\frac{1}{2}\)daugyba iš \(2\)
\(-0{,}5x\)\(-0{,}5\)daugyba iš \(-2\)
!Tipinės klaidos
  • Dauginama iš \(a\), o ne dalijama. Diferencijuojant vidinės funkcijos išvestinė \(a\) atsiranda kaip daugiklis, todėl integruojant iš \(a\) reikia dalyti: \(\int e^{5x}\, dx = \frac{1}{5}e^{5x} + C\), o ne \(5e^{5x} + C\).
  • Pamirštas koeficiento ženklas. Vidinės funkcijos \(2 - x\) koeficientas yra \(a = -1\), todėl \(\int e^{2 - x}\, dx\) \(= -e^{2 - x} + C\).
  • Dalijama iš laisvojo nario. Dalijama tik iš koeficiento prie \(x\). Laisvasis narys \(b\) į daliklį neįeina.
  • Pakeičiamas argumentas. Integruojant argumentas \(ax + b\) paliekamas toks pat: \(\int\cos(4x - 1)\, dx\) \(= \frac{1}{4}\sin(4x - 1) + C\).
  • Formulė taikoma netiesinei vidinei funkcijai. Pavyzdžiui, \(\int e^{x^2}\, dx\) \(\ne \frac{1}{2x}e^{x^2} + C\).

Pavyzdžiai

Tiesinės funkcijos laipsniai ir šaknys

1 pavyzdys

Tiesinės funkcijos laipsnis

Sąlyga Apskaičiuokite integralą \(\displaystyle\int (3x - 2)^5\, dx\).

1Vidinė funkcija

Išorinė funkcija yra penktasis laipsnis, o vidinė – tiesinė funkcija \(3x - 2\). Koeficientas prie \(x\) yra \(a = 3\).

2Integravimas

Taikome laipsninės funkcijos integravimo formulę, reiškinį \(3x - 2\) laikydami vienu kintamuoju: rodiklį padidiname vienetu ir dalijame iš 6. Tada rezultatą dalijame iš \(a = 3\):

\[ \begin{aligned} &\int (3x - 2)^5\, dx \\ &= \frac{1}{3}\cdot\frac{(3x - 2)^6}{6} + C \\ &= \frac{(3x - 2)^6}{18} + C \end{aligned} \]

3Patikrinimas

Diferencijuodami pagal sudėtinės funkcijos išvestinės taisyklę, gauname vidinės funkcijos išvestinę 3, kuri susiprastina su daliklio daugikliu:

\[ \begin{aligned} &\left(\frac{(3x - 2)^6}{18}\right)' \\ &= \frac{6(3x - 2)^5\cdot 3}{18} = (3x - 2)^5 \end{aligned} \]

Atskleidę \((3x - 2)^5\) ir integravę daugianario narius, gautume tą pačią pirmykščių funkcijų šeimą, tačiau skaičiuoti reikėtų daug ilgiau.

Atsakymas \[ \begin{aligned} &\int (3x - 2)^5\, dx \\ &= \frac{(3x - 2)^6}{18} + C \end{aligned} \]
2 pavyzdys

Kvadratinė šaknis

Sąlyga Apskaičiuokite integralą \(\displaystyle\int \sqrt{2x + 1}\, dx\).

1Pertvarkymas

Šaknį užrašome laipsniu:

\[ \sqrt{2x + 1} = (2x + 1)^{\frac{1}{2}} \]

2Vidinė funkcija

Vidinė funkcija yra \(2x + 1\), todėl \(a = 2\).

3Integravimas

Naujas laipsnio rodiklis yra \(\frac{1}{2} + 1 = \frac{3}{2}\). Dalyba iš \(\frac{3}{2}\) – tai daugyba iš \(\frac{2}{3}\), o \(\frac{1}{2}\cdot\frac{2}{3} = \frac{1}{3}\):

\[ \begin{aligned} &\int (2x + 1)^{\frac{1}{2}}\, dx \\ &= \frac{1}{2}\cdot\frac{(2x + 1)^{\frac{3}{2}}}{\frac{3}{2}} + C \\ &= \frac{1}{3}(2x + 1)^{\frac{3}{2}} + C \\ &= \frac{1}{3}(2x + 1)\sqrt{2x + 1} + C \end{aligned} \]

Paskutinėje eilutėje pritaikėme lygybę \((2x + 1)^{\frac{3}{2}} = (2x + 1)\cdot(2x + 1)^{\frac{1}{2}}\).

4Patikrinimas

\[ \begin{aligned} &\left(\frac{1}{3}(2x + 1)^{\frac{3}{2}}\right)' \\ &= \frac{1}{3}\cdot\frac{3}{2}(2x + 1)^{\frac{1}{2}}\cdot 2 = \sqrt{2x + 1} \end{aligned} \]
Atsakymas \[ \begin{aligned} &\int \sqrt{2x + 1}\, dx \\ &= \frac{1}{3}(2x + 1)\sqrt{2x + 1} + C \end{aligned} \]
3 pavyzdys

Neigiamas koeficientas prie \(x\)

Sąlyga Apskaičiuokite integralą \(\displaystyle\int \frac{1}{(5 - 2x)^3}\, dx\).

1Pertvarkymas

Trupmeną užrašome laipsniu su neigiamu rodikliu:

\[ \frac{1}{(5 - 2x)^3} = (5 - 2x)^{-3} \]

2Vidinė funkcija

Vidinė funkcija \(5 - 2x = -2x + 5\), todėl koeficientas prie \(x\) yra neigiamas: \(a = -2\). Dalydami iš \(a\), minuso ženklą išlaikome.

3Integravimas

Naujas laipsnio rodiklis yra \(-3 + 1 = -2\). Dalijame iš \(-2\) (naujojo rodiklio) ir iš \(a = -2\). Du neigiami dalikliai duoda teigiamą rezultatą: \((-2)\cdot(-2) = 4\):

\[ \begin{aligned} &\int (5 - 2x)^{-3}\, dx \\ &= \frac{1}{-2}\cdot\frac{(5 - 2x)^{-2}}{-2} + C \\ &= \frac{1}{4(5 - 2x)^2} + C \end{aligned} \]

4Patikrinimas

\[ \begin{aligned} &\left(\frac{1}{4}(5 - 2x)^{-2}\right)' \\ &= \frac{1}{4}\cdot(-2)(5 - 2x)^{-3}\cdot(-2) \\ &= (5 - 2x)^{-3} \end{aligned} \]
Atsakymas \[ \begin{aligned} &\int \frac{1}{(5 - 2x)^3}\, dx \\ &= \frac{1}{4(5 - 2x)^2} + C \end{aligned} \]

Trupmena, rodiklinė ir trigonometrinė funkcijos

4 pavyzdys

Tiesinė funkcija vardiklyje

Sąlyga Apskaičiuokite integralą \(\displaystyle\int \frac{6}{3 - 4x}\, dx\).

1Vidinė funkcija

Pointegrinė funkcija yra \(6\cdot\frac{1}{3 - 4x}\). Pastovųjį daugiklį 6 iškeliame. Vidinė funkcija yra \(3 - 4x\), todėl \(a = -4\).

2Integravimas

Funkcijos \(\frac{1}{u}\) pirmykštė yra \(\ln|u|\). Argumentą \(3 - 4x\) paliekame nepakeistą ir dalijame iš \(-4\):

\[ \begin{aligned} &\int \frac{6}{3 - 4x}\, dx \\ &= 6\cdot\frac{1}{-4}\ln|3 - 4x| + C \\ &= -\frac{3}{2}\ln|3 - 4x| + C \end{aligned} \]

3Patikrinimas

\[ \begin{aligned} &\left(-\frac{3}{2}\ln|3 - 4x|\right)' \\ &= -\frac{3}{2}\cdot\frac{1}{3 - 4x}\cdot(-4) = \frac{6}{3 - 4x} \end{aligned} \]
Atsakymas \[ \begin{aligned} &\int \frac{6}{3 - 4x}\, dx \\ &= -\frac{3}{2}\ln|3 - 4x| + C \end{aligned} \]
5 pavyzdys

Rodiklinė funkcija

Sąlyga Apskaičiuokite integralą \(\displaystyle\int e^{2 - x}\, dx\).

1Vidinė funkcija

Vidinė funkcija yra rodiklis \(2 - x\). Prie \(x\) parašytas tik minuso ženklas, todėl \(a = -1\).

2Integravimas

Funkcijos \(e^u\) pirmykštė yra \(e^u\). Dalyba iš \(-1\) pakeičia ženklą:

\[ \begin{aligned} \int e^{2 - x}\, dx &= \frac{1}{-1}e^{2 - x} + C \\ &= -e^{2 - x} + C \end{aligned} \]

3Patikrinimas

\[ \left(-e^{2 - x}\right)' = -e^{2 - x}\cdot(-1) = e^{2 - x} \]
Atsakymas \[ \int e^{2 - x}\, dx = -e^{2 - x} + C \]
6 pavyzdys

Trigonometrinė funkcija

Sąlyga Apskaičiuokite integralą \(\displaystyle\int \cos\frac{x}{2}\, dx\).

1Vidinė funkcija

Kadangi \(\frac{x}{2} = \frac{1}{2}x\), vidinės funkcijos koeficientas yra \(a = \frac{1}{2}\).

2Integravimas

Kosinuso pirmykštė yra sinusas. Dalybą iš \(\frac{1}{2}\) pakeičiame daugyba iš 2:

\[ \begin{aligned} \int \cos\frac{x}{2}\, dx &= \frac{1}{\frac{1}{2}}\sin\frac{x}{2} + C \\ &= 2\sin\frac{x}{2} + C \end{aligned} \]

3Patikrinimas

\[ \left(2\sin\frac{x}{2}\right)' = 2\cos\frac{x}{2}\cdot\frac{1}{2} = \cos\frac{x}{2} \]
Atsakymas \[ \int \cos\frac{x}{2}\, dx = 2\sin\frac{x}{2} + C \]

7 pavyzdys

Kelių narių suma

Sąlyga Apskaičiuokite integralą \(\displaystyle\int\left(8e^{-0{,}5x} + \frac{4}{2x + 1} - 6\cos 3x\right) dx\).

1Vidinė funkcija

Sumos narius integruojame atskirai. Kiekvienas narys turi savo vidinę funkciją ir koeficientą:

  • \(8e^{-0{,}5x}\): vidinė funkcija \(-0{,}5x\), \(a = -0{,}5\);
  • \(\frac{4}{2x + 1}\): vidinė funkcija \(2x + 1\), \(a = 2\);
  • \(6\cos 3x\): vidinė funkcija \(3x\), \(a = 3\).

2Integravimas

Iškeliame pastoviuosius daugiklius ir kiekvienam nariui taikome atitinkamą formulę:

\[ \begin{aligned} &= 8\cdot\frac{1}{-0{,}5}e^{-0{,}5x} + 4\cdot\frac{1}{2}\ln|2x + 1| \\ &\phantom{=}\; {}- 6\cdot\frac{1}{3}\sin 3x + C \end{aligned} \]

Suprastiname: \(8 : (-0{,}5) = -16\), \(4\cdot\frac{1}{2} = 2\), \(6\cdot\frac{1}{3} = 2\):

\[ \begin{aligned} &= -16e^{-0{,}5x} + 2\ln|2x + 1| \\ &\phantom{=}\; {}- 2\sin 3x + C \end{aligned} \]

3Patikrinimas

Diferencijuojame kiekvieną narį:

  • \(\left(-16e^{-0{,}5x}\right)' = -16\cdot(-0{,}5)e^{-0{,}5x}\) \(= 8e^{-0{,}5x}\);
  • \(\big(2\ln|2x + 1|\big)' = 2\cdot\dfrac{2}{2x + 1}\) \(= \dfrac{4}{2x + 1}\);
  • \(\left(-2\sin 3x\right)' = -2\cdot 3\cos 3x\) \(= -6\cos 3x\).

Išvestinių suma lygi pointegrinei funkcijai.

Atsakymas
\[ \begin{aligned} &\int\left(8e^{-0{,}5x} + \frac{4}{2x + 1} - 6\cos 3x\right) dx \\ &= -16e^{-0{,}5x} + 2\ln|2x + 1| - 2\sin 3x + C \end{aligned} \]
\[ \begin{aligned} &\int\Big(8e^{-0{,}5x} + \frac{4}{2x + 1} \\ &\qquad {}- 6\cos 3x\Big)\, dx \\ &= -16e^{-0{,}5x} + 2\ln|2x + 1| \\ &\phantom{=}\; {}- 2\sin 3x + C \end{aligned} \]
8 pavyzdys

Pertvarkymas prieš integruojant

Sąlyga Apskaičiuokite integralą \(\displaystyle\int \frac{e^{2x} + 1}{e^x}\, dx\).

1Pertvarkymas

Vardiklyje yra vienas narys, todėl kiekvieną skaitiklio narį dalijame iš \(e^x\). Dalydami laipsnius su tuo pačiu pagrindu, rodiklius atimame:

\[ \frac{e^{2x} + 1}{e^x} = \frac{e^{2x}}{e^x} + \frac{1}{e^x} = e^x + e^{-x} \]

2Vidinė funkcija

Pirmajam nariui \(e^x\) taikome pagrindinę formulę. Antrojo nario vidinė funkcija yra \(-x\), todėl \(a = -1\).

3Integravimas

\[ \begin{aligned} &\int\left(e^x + e^{-x}\right) dx \\ &= e^x + \frac{1}{-1}e^{-x} + C \\ &= e^x - e^{-x} + C \end{aligned} \]

4Patikrinimas

\[ \begin{aligned} \left(e^x - e^{-x}\right)' &= e^x - e^{-x}\cdot(-1) \\ &= e^x + e^{-x} \end{aligned} \]

Gavome pertvarkytą pointegrinę funkciją.

Atsakymas \[ \int \frac{e^{2x} + 1}{e^x}\, dx = e^x - e^{-x} + C \]

Uždaviniai savarankiškam darbui

Sprendimus užrašykite taip pat kaip pavyzdžiuose: jei reikia, pertvarkykite pointegrinę funkciją, nustatykite vidinę funkciją ir koeficientą \(a\), integruokite ir pridėkite konstantą \(C\). Atsakymą patikrinkite diferencijuodami.

Apskaičiuokite integralą \(\displaystyle\int (5x + 1)^4\, dx\).

\(a = 5\). Atsakymas: \(\dfrac{(5x + 1)^5}{25} + C\)

Apskaičiuokite integralą \(\displaystyle\int \sqrt{3x - 2}\, dx\).

\(\sqrt{3x - 2} = (3x - 2)^{\frac{1}{2}}\), \(a = 3\).

Atsakymas: \(\dfrac{2}{9}(3x - 2)\sqrt{3x - 2} + C\)

Apskaičiuokite integralą \(\displaystyle\int \frac{8}{(4x + 3)^3}\, dx\).

\(\dfrac{8}{(4x + 3)^3} = 8(4x + 3)^{-3}\), \(a = 4\).

Atsakymas: \(-\dfrac{1}{(4x + 3)^2} + C\)

Apskaičiuokite integralą \(\displaystyle\int \frac{6}{1 - 2x}\, dx\).

\(a = -2\). Atsakymas: \(-3\ln|1 - 2x| + C\)

Apskaičiuokite integralą \(\displaystyle\int e^{3 - 4x}\, dx\).

\(a = -4\). Atsakymas: \(-\dfrac{1}{4}e^{3 - 4x} + C\)

Apskaičiuokite integralą \(\displaystyle\int \cos(4x - 1)\, dx\).

\(a = 4\). Atsakymas: \(\dfrac{1}{4}\sin(4x - 1) + C\)

Apskaičiuokite integralą \(\displaystyle\int\left(e^{\frac{x}{2}} - \sin 3x + \frac{4}{\sqrt{2x + 1}}\right) dx\).

Koeficientai: \(a = \frac{1}{2}\), \(a = 3\), \(a = 2\).

Atsakymas: \(2e^{\frac{x}{2}} + \dfrac{1}{3}\cos 3x + 4\sqrt{2x + 1} + C\)

Suprastinkite pointegrinę funkciją ir apskaičiuokite integralą \(\displaystyle\int e^{3x}\cdot e^{1 - x}\, dx\).

\(e^{3x}\cdot e^{1 - x} = e^{2x + 1}\), \(a = 2\).

Atsakymas: \(\dfrac{1}{2}e^{2x + 1} + C\)
